# P-4 문헌 분석 — 제4장 프롬프트 패키지

> 연결 장: 제4장 AI PDF 독해 · 워크북: [W-2](../workbook/W2_문헌수집과참고문헌관리.md)
> 사용법: 복사 → [대괄호] 교체 → 실행 → 검증 프롬프트로 재확인

---

## 언제 쓰나

- 논문 PDF 한 편을 처음 읽을 때 — 연구목적·방법·결과를 8칸 표로 빠르게 정리하고 싶을 때
- 선행연구 5~10편을 읽은 뒤 — 공통 가설·방법·한계를 한눈에 비교하고 연구 빈틈(Gap)을 찾고 싶을 때
- 서론·이론적 배경·연구방법·Discussion 초안을 쓰기 전에 — 어떤 논문을 어디서 어떻게 인용할지 결정해야 할 때
- NotebookLM·SciSpace 등 업로드 기반 도구를 쓸 때 — AI가 제시한 출처가 원문과 실제로 일치하는지 확인하는 프레임이 필요할 때

## 프롬프트 1 — 논문 8칸 정밀 분석

무엇을 얻나: 첨부 논문 한 편을 연구목적·이론·변수·데이터·방법·결과·한계·연결점 8개 항목으로 표준화한 분석 카드. 원문 근거 여부와 본문 배치 지점(서론/이론적배경/연구방법/Discussion)을 함께 표시하여 즉시 집필에 활용할 수 있는 형태로 출력된다.

```text
Role: 너는 학술 문헌 분석 전문가다.
Context: 나는 [연구주제 1문장 — 예: "SNS 이용 강도가 대학생의 학업 자기효능감에 미치는 영향"]을 연구 중이다.
Task: 첨부한 논문(또는 아래에 붙여넣은 전문)을 내 연구주제와 연결하여 아래 8개 항목으로 정리하라.

항목 순서:
1. 연구목적 — 저자가 풀고자 한 핵심 질문
2. 이론(핵심개념) — 사용한 이론·모델·핵심 개념
3. 변수 — 독립·종속·매개·조절 변수
4. 데이터와 표본 — 표본 크기·기간·수집 방식
5. 연구방법 — 분석 기법·실험 설계·질적 방법
6. 핵심결과 — 핵심 발견 2~3개 (수치 포함)
7. 한계 — 저자가 인정한 한계 + 내가 추가로 본 한계
8. 내 연구와의 연결점 — 서론·이론적배경·연구방법·Discussion 중 어디에 활용할지

표기 규칙:
- 원문에 근거가 있는 내용: 그대로 기술하고 해당 페이지·섹션을 괄호로 표시 (예: p.5, Table 2)
- 원문에 명시되지 않아 추론이 필요한 내용: 문장 끝에 [추정] 표시
- 확인이 필요한 수치·인용: [확인 필요] 표시

마지막에 이 논문에서 도출되는 Gap 문장 3개를 작성하라. 형식: "선행연구는 X를 밝혔지만, Y에 대해서는 아직 충분히 검토되지 않았다."
Format: 번호 있는 표 또는 항목별 단락. 한국어로 작성.
```

입력 예시:
- NotebookLM에 PDF를 업로드한 뒤 위 프롬프트를 질문창에 붙여넣기
- SciSpace Copilot에서 논문을 열고 위 프롬프트를 입력란에 붙여넣기
- Claude·ChatGPT에서 PDF를 첨부하거나 본문 텍스트를 붙여넣은 뒤 실행

기대 출력(요약):
8개 항목이 구조화된 표 또는 단락으로 정리된다. 각 항목에 "(p.X)" 형태의 원문 위치가 붙고, 추론 내용에는 [추정] 표시가 달린다. 마지막 Gap 3문장은 내 연구의 서론 초안으로 바로 활용할 수 있는 형태다.

검증 프롬프트:

```text
방금 네가 정리한 8칸 분석 중 수치(표본 크기, 통계값, 연도)가 들어간 항목만 다시 나열하라.
각 수치 옆에 원문의 정확한 위치(섹션명 또는 페이지)를 함께 표시하라.
원문 위치를 확인하지 못한 수치는 [확인 필요]로 표시하라.
```

## 프롬프트 2 — Gap 문장 생성 (선행연구 빈틈 → 내 기여)

무엇을 얻나: 여러 편의 선행연구를 종합한 뒤, 아직 밝혀지지 않은 연구 빈틈(Gap)을 학술적 문장으로 3~5개 생성한다. 각 Gap 문장은 서론의 "연구의 필요성" 단락에 바로 삽입할 수 있는 형태로 출력된다.

```text
Role: 너는 학술 논문의 서론 작성을 돕는 연구 방법론 전문가다.
Context: 나는 [연구주제 1문장]을 연구 중이다.
아래는 내가 분석한 선행연구 요약이다 (논문별로 연구목적·결과·한계를 간략히 정리해 붙여넣을 것):

[선행연구 요약 — 각 논문을 2~3줄로 정리하여 여기에 붙여넣기]

Task:
1. 위 선행연구들이 공통적으로 다루는 핵심 주제와 가설을 2~3줄로 요약하라.
2. 선행연구들이 다루지 않은 공백(Gap)을 3~5개 도출하라. 각 Gap은 아래 형식으로 작성하라:
   - "선행연구는 [밝혀진 것]을 확인하였으나, [빠진 것/제한된 맥락]에 대해서는 충분히 검토되지 않았다. 본 연구는 [내 기여]를 통해 이 공백을 메우고자 한다."
3. 각 Gap이 내 논문의 서론·이론적배경·연구방법 중 어디에 배치하기에 적합한지 표시하라.
4. 원문에서 직접 근거를 찾을 수 없는 Gap에는 [확인 필요] 표시를 붙여라.

Format: 번호 있는 목록. 한국어로 작성.
```

입력 예시:
- 프롬프트 1로 각 논문의 8칸 분석을 마친 뒤, 각 논문의 "한계"와 "연결점" 항목만 모아 붙여넣기
- NotebookLM에서 "이 자료들이 다루지 않은 빈 영역 3가지는?"을 먼저 질문하여 힌트를 얻은 뒤, 그 결과를 이 프롬프트의 [선행연구 요약] 란에 추가하여 더 정교화

기대 출력(요약):
"선행연구는 X를 밝혔지만 Y는 미검토"라는 형식의 Gap 문장 3~5개와 각 문장의 배치 위치(서론/이론적배경/연구방법)가 함께 출력된다. [확인 필요] 표시가 붙은 Gap은 원문을 직접 열어 확인한다.

검증 프롬프트:

```text
방금 도출한 Gap 문장 각각에 대해, 그 Gap을 뒷받침하는 근거가 위 선행연구 요약 중 어느 논문의 어느 부분에서 왔는지 밝혀라.
근거를 특정할 수 없는 Gap에는 [출처 없음 — 삭제 또는 원문 확인 필요]라고 표시하라.
```

## 프롬프트 3 — 여러 편 문헌 비교표 생성

무엇을 얻나: 선행연구 N편을 공통 가설·연구방법·데이터·한계 4축으로 비교한 표. SciSpace Literature Review의 자동 비교표를 보완하거나, 직접 논문을 입력한 경우 처음부터 생성할 때 모두 사용할 수 있다.

```text
Role: 너는 학술 문헌 비교 분석 전문가다.
Context: 나는 [연구주제 1문장]을 연구 중이다.
아래 [N]편의 논문을 비교 분석한다.

논문 목록 (각 논문의 저자·연도·제목·핵심 내용을 간략히 기재):
1. [저자(연도). 제목. — 내용 2~3줄]
2. [저자(연도). 제목. — 내용 2~3줄]
...
N. [저자(연도). 제목. — 내용 2~3줄]

Task: 위 논문들을 아래 4개 축으로 비교하는 표를 작성하라.
- 공통 가설 또는 이론적 전제
- 연구방법 (분석 기법·실험 설계·질적 방법)
- 데이터·표본 (규모·기간·수집 방식)
- 한계 및 후속 연구 제언

표 형식: 행 = 논문(저자·연도), 열 = 4개 축.
표 아래에 다음을 추가하라:
① 4개 축 전반에서 반복적으로 등장하는 공통 패턴 2~3가지
② 논문 간 가장 큰 방법론적 차이점 1~2가지
③ [연구주제]에 가장 직접적으로 답하는 논문 1~2편과 그 이유

표기 규칙: 원문에서 직접 확인한 내용은 그대로, 요약·추론이 필요한 내용은 [추정] 표시.
Format: 마크다운 표 + 항목별 단락. 한국어로 작성.
```

입력 예시:
- SciSpace Literature Review에서 자동 생성된 비교표를 CSV로 내려받은 뒤, 각 논문 정보를 위 형식으로 붙여넣기
- NotebookLM에서 10편을 업로드한 뒤 위 프롬프트를 질문창에 입력하면 출처 기반으로 표가 생성됨

기대 출력(요약):
N행×4열의 비교표와 공통 패턴·방법론적 차이·핵심 논문 해설이 함께 출력된다. 이 표는 논문의 이론적 배경 절에 직접 삽입하거나 인용·재정리의 기초 자료로 활용할 수 있다.

검증 프롬프트:

```text
방금 작성한 비교표에서 [추정] 표시 없이 기술된 내용 중 수치(표본 크기, 연도, 통계값)를 모두 추출하라.
각 수치에 대해 해당 논문의 원문 섹션이나 페이지를 명시하라.
확인할 수 없는 수치에는 [확인 필요 — 원문 대조 바람]으로 표시하라.
```

## ✅ 연구자 체크

- [ ] 8칸 분석 결과에서 수치(표본 크기, 통계값, 연도)를 원문 PDF와 직접 대조했는가?
- [ ] AI가 생성한 인용 정보("이 논문은 X를 인용했다")를 원문 참고문헌 목록에서 확인했는가?
- [ ] Gap 문장에 [확인 필요] 표시가 있다면 해당 논문 원문에서 근거를 찾아 표시를 제거하거나 문장을 삭제했는가?
- [ ] "X가 Y에 영향을 미친다"(인과)와 "X와 Y가 상관관계가 있다"(상관)의 차이를 원문 주장 강도대로 유지했는가?
- [ ] 비교표의 [추정] 항목 수가 전체의 30% 이하인가? 초과라면 원문 재독 후 재작성했는가?
- [ ] NotebookLM·SciSpace 출력에서 인용 위치(페이지·섹션)를 실제로 열어 일치 여부를 눈으로 확인했는가?

## ⚠️ 흔한 실패 패턴

| 실패 패턴 | 왜 생기나 | 대처법 |
|---|---|---|
| AI가 없는 수치를 만들어 냄 (할루시네이션) | LLM이 문맥에서 그럴듯한 숫자를 생성함. NotebookLM도 출처 표시가 있어도 인용 오류 가능 | 검증 프롬프트로 수치만 별도 추출 후 원문 PDF에서 페이지 번호 직접 확인 |
| Gap 문장이 내 연구가 아니라 다른 연구를 가리킴 | [연구주제] 자리를 너무 짧게 또는 모호하게 입력함 | 프롬프트 Context에 RQ를 1~2문장으로 구체적으로 기술하고 재실행 |
| 비교표가 모든 논문을 비슷하게 기술함 | 입력한 논문 요약이 너무 짧거나 동일 키워드로만 구성됨 | 각 논문의 방법·데이터 정보를 2~3줄 이상으로 늘려 다시 입력 |
