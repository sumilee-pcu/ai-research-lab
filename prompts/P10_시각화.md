## 언제 쓰나

논문에 들어갈 그림을 처음 설계하거나, 개별 그림의 캡션을 작성하거나, AI 생성 이미지와 실제 데이터 그래프의 구분·명시가 필요할 때 사용한다. 제10장 6주차 산출물(Figure 3종)을 만들기 전 AI와 협업 계획을 세우는 단계에 특히 유용하다.

> 핵심 원칙 — 이 패키지 전체에 적용
> - 실제 연구 데이터로 만드는 결과 그래프는 반드시 코드 기반 도구(matplotlib, seaborn 등)로 작성해야 한다.
> - AI 이미지 생성 도구(Napkin AI, DALL-E 등)로 데이터 수치를 나타내는 그래프를 만드는 것은 연구 부정행위에 해당한다.
> - 두 유형은 논문 본문과 캡션에서 항상 명확히 구분·명시해야 한다.

## 프롬프트 1 — Figure 패키지 설계

무엇을 얻나: 논문 전체 구조(서론·이론적 배경·연구방법·Results·Discussion)에서 어떤 그림이 필요한지 체계적으로 파악하고, 각 그림의 유형·도구·캡션 초안·검증 기준을 표 형태로 한번에 설계한다.

```text
역할: 논문 시각화 설계 전문가
맥락: 나는 [연구 주제]를 다루는 [학위논문 / 학술지 논문]을 작성 중이다. 현재 논문 구조는 서론-이론적 배경-연구방법-결과(Results)-논의(Discussion)로 구성된다.
과제: 내 연구주제 [연구 주제]를 논문용 Figure 패키지로 설계하라.
형식: 아래 지침을 따라 표를 작성한다.

1. 각 장(서론·이론적 배경·연구방법·Results·Discussion)에서 필요한 그림을 판단한다.
2. 각 그림을 다음 4가지 유형 중 하나로 분류한다.
   - 시스템 다이어그램 (개념·구조·플로우 → Napkin AI)
   - 정보형 인포그래픽 (비교·관계·타임라인 → Napkin AI)
   - 설명용 이미지 (개념 예시·실험 환경 사진 등)
   - 실제 데이터 정량 그래프 (분포·상관·추세 → matplotlib/seaborn 코드 필수)
3. 각 그림마다 아래 항목을 표로 제시한다.
   | 번호 | 그림 제목 | 유형 | 핵심 메시지 | 추천 도구 | 필요 입력 | 본문 연결 위치 | 캡션 초안 | 검증 사항 |
4. 실제 데이터 그래프 행에는 "⚠️ 코드 기반 도구 필수 — AI 이미지 도구 사용 금지" 표시를 추가한다.
5. AI 생성 이미지(Napkin AI 등) 행에는 "AI 생성 — 출처 명시 필요" 표시를 추가한다.

할루시네이션 방지 조건: 내가 제공하지 않은 데이터 수치, 인용 문헌, 연구 결과를 임의로 생성하지 마라. 불확실한 정보는 [확인 필요]로 표시하라.
```

입력 예시:

- 연구 주제: SNS 알고리즘 노출이 청소년의 정치적 태도에 미치는 영향
- 논문 유형: 석사학위논문

기대 출력(요약):

논문 5개 장 전체에 걸쳐 필요한 Figure 목록(약 4~7개)을 표로 제시한다. 각 행에는 그림 번호·제목·유형·핵심 메시지·추천 도구·본문 연결 위치·캡션 초안·검증 사항이 담기며, 데이터 그래프 행에는 코드 기반 도구 필수 경고가 명시된다.

검증 프롬프트:

```text
방금 제안한 Figure 패키지를 다음 기준으로 점검하라.

1. 각 그림의 유형 분류가 적절한가? (데이터가 있는 그림을 AI 이미지 도구로 분류하지 않았는가)
2. 같은 메시지를 전달하는 그림이 중복되지 않는가?
3. Results 섹션에 코드 기반 통계 그래프가 반드시 포함되어 있는가?
4. 각 그림이 본문의 특정 문단과 연결되어 있는가?
5. AI 생성 이미지와 실제 데이터 그래프가 명확히 구분되어 있는가?

문제가 있는 항목은 수정안과 함께 제시하라.
```

## 프롬프트 2 — 그림 캡션 작성

무엇을 얻나: 번호·핵심 메시지·출처를 포함한 APA 양식 Figure 캡션을 자동 생성한다. AI 생성 도구 사용 여부에 따른 출처 명시 문구도 함께 제안받는다.

```text
역할: 학술 논문 편집 전문가
맥락: 나는 [연구 주제] 논문의 Figure [번호]에 대한 캡션을 작성해야 한다.
과제: 아래 정보를 바탕으로 APA 7판 양식의 Figure 캡션을 작성하라.

그림 정보:
- 그림 번호: Figure [번호]
- 그림 제목(가제): [그림 제목]
- 그림 유형: [시스템 다이어그램 / 인포그래픽 / 통계 그래프 / 사진]
- 핵심 메시지: [이 그림이 말하는 핵심 1문장]
- 생성 방법: [직접 제작(코드) / Napkin AI / 기타 AI 도구 / 외부 이미지 인용]
- 데이터 출처(해당 시): [데이터셋 이름 또는 출처]

형식:
1. APA 양식 캡션 (Note 포함)
2. AI 도구를 사용한 경우: "본 그림은 [도구명]을 활용하여 작성되었음" 명시 문구 추가
3. 외부 이미지 인용인 경우: 저작권 허가 여부 확인 메모 추가
4. 캡션 한국어 버전 + 영문 저널 제출용 영어 버전 모두 제시

할루시네이션 방지 조건: 내가 제공하지 않은 표본 수, p값, 통계 결과를 임의로 삽입하지 마라. 통계 정보가 필요한 경우 [n=?], [p=?] 형식으로 표시하라.
```

입력 예시:

- 그림 번호: Figure 3
- 그림 제목(가제): SNS 알고리즘 노출 빈도에 따른 정치적 태도 점수 분포
- 그림 유형: 통계 그래프(Boxplot)
- 핵심 메시지: 알고리즘 노출 빈도가 높은 집단일수록 정치적 양극화 점수가 유의미하게 높다
- 생성 방법: 직접 제작(seaborn 코드)
- 데이터 출처: 자체 설문 데이터(n=247)

기대 출력(요약):

APA 양식 캡션(Note 포함), 한국어·영어 2개 버전, 통계 정보 미기입 항목은 [n=247], [p=?] 형식으로 표시된 초안을 제공한다.

검증 프롬프트:

```text
방금 작성한 Figure 캡션을 다음 기준으로 점검하라.

1. APA 7판 캡션 형식(Figure 번호, 이탤릭 제목, Note)이 맞는가?
2. 핵심 메시지가 캡션 안에 명확히 담겨 있는가?
3. 데이터 출처와 생성 방법이 Note에 명시되어 있는가?
4. AI 도구 사용 명시 문구가 누락되지 않았는가?
5. [n=?], [p=?] 등 미입력 항목이 모두 표시되어 있는가?

수정이 필요한 부분은 수정 캡션을 제시하라.
```

## 프롬프트 3 — AI 생성 이미지 표시·구분

무엇을 얻나: 논문에 포함된 AI 생성 이미지와 실제 데이터 그래프를 명확히 분류하고, 학술지·기관 제출 기준에 맞는 AI 사용 명시 문구를 생성한다. 데이터 위조·오용 위험을 사전에 점검한다.

```text
역할: 연구 윤리 및 논문 작성 전문가
맥락: 나는 [연구 주제] 논문에 총 [N]개의 그림을 사용할 예정이다. 이 중 일부는 AI 도구로 생성했고, 일부는 실제 데이터를 코드로 시각화한 것이다.
과제: 아래 그림 목록을 검토하여 AI 사용 명시 방법과 위험 요소를 안내하라.

그림 목록:
[번호] | [제목] | [생성 방법] | [데이터 포함 여부]
예시: Figure 1 | 연구 프레임워크 다이어그램 | Napkin AI | 데이터 없음(개념도)
예시: Figure 2 | 집단별 점수 분포 Boxplot | seaborn 코드(자체 데이터) | 실제 데이터 포함
예시: Figure 3 | 선행연구 비교 인포그래픽 | Napkin AI | 데이터 없음(문헌 정리)

형식:
1. 각 그림을 세 가지 범주로 분류한다.
   - A. 실제 데이터 정량 그래프 (코드 기반 도구 필수)
   - B. AI 생성 개념도·인포그래픽 (출처 명시 필요)
   - C. 외부 이미지 인용 (저작권 확인 필요)
2. A 범주 그림 중 AI 이미지 도구를 사용한 항목이 있으면 즉시 경고를 표시한다.
   "⛔ 실제 데이터를 AI 이미지 도구로 시각화하는 것은 연구 부정행위입니다. matplotlib/seaborn 등 코드 기반 도구로 재작성하십시오."
3. 각 범주별 논문 내 AI 사용 명시 문구 초안을 제시한다.
4. 제출 기관(학위논문 / 학술지)별 추가 확인 사항을 안내한다.

할루시네이션 방지 조건: 학술지 이름, 기관명, 정책 링크를 임의로 만들지 마라. 일반 원칙만 제시하고, 구체적 정책은 [해당 기관 공식 가이드라인 확인 필요]로 표시하라.
```

입력 예시:

- 연구 주제: SNS 알고리즘 노출이 청소년 정치적 태도에 미치는 영향
- 그림 3종: ① 연구 프레임워크 다이어그램(Napkin AI, 개념도) ② Boxplot(seaborn, 실제 데이터) ③ 선행연구 비교 인포그래픽(Napkin AI, 개념)

기대 출력(요약):

그림 3종의 범주 분류표, 각 범주별 AI 사용 명시 문구 초안(한국어), 실제 데이터 그래프에 AI 이미지 도구를 사용할 경우의 즉각 경고 메시지, 제출 유형별(학위논문/학술지) 추가 확인 사항을 제공한다.

검증 프롬프트:

```text
방금 작성한 AI 사용 명시 및 분류 결과를 다음 기준으로 점검하라.

1. 실제 데이터 그래프(A 범주)가 모두 코드 기반 도구로 생성되었는가?
2. AI 이미지 도구로 만든 그림 중 수치 데이터를 포함한 항목이 없는가?
3. 각 그림의 명시 문구가 누락 없이 작성되었는가?
4. 부속자료 라(AI 사용 명시 문구 표준 양식)와 형식이 일치하는가?
5. 외부 인용 이미지의 저작권 확인 항목이 빠지지 않았는가?

문제 항목은 수정 방법과 함께 제시하라.
```

## ✓ 연구자 체크

논문에 그림을 넣기 전 아래 항목을 반드시 확인한다.

- [ ] 결과(Results) 섹션의 모든 수치 그래프는 matplotlib, seaborn, R ggplot2 등 코드 기반 도구로 작성했다
- [ ] 실제 데이터를 AI 이미지 생성 도구(Napkin AI, DALL-E, Midjourney 등)로 시각화하지 않았다 — 이는 데이터 조작에 준하는 연구 부정행위다
- [ ] AI 생성 다이어그램·인포그래픽의 출처(생성 도구명)를 캡션 Note에 명시했다
- [ ] 각 그림이 본문의 특정 문단과 연결되어 있고, 캡션만으로 핵심 메시지를 파악할 수 있다
- [ ] 통계 그래프에 축 제목·단위·표본 수·범례·신뢰구간이 모두 포함되어 있다
- [ ] 색상 팔레트가 색맹 친화(viridis, ColorBrewer Safe 등)이고 흑백 출력에서도 판독 가능하다
- [ ] 해상도가 300dpi 이상이다
- [ ] 타 논문의 그림을 인용한 경우 출처 명시 및 저작권 허가를 확인했다
- [ ] AI 사용 명시 문구가 부속자료 라의 표준 양식과 일치한다

> 데이터 그래프 위조 금지
> AI 이미지 도구는 숫자를 이해하지 못한다. AI 도구로 생성된 "그래프처럼 보이는 이미지"는 실제 데이터와 무관한 허위 시각화다. 논문 심사·동료 검토 과정에서 원본 데이터와 그래프의 불일치가 발견되면 논문 철회 및 연구 부정 판정의 사유가 된다.

## ※ 흔한 실패 패턴

| 실패 패턴 | 증상 | 해결 방법 |
|---|---|---|
| AI 그래프로 데이터 시각화 | "그래프가 예쁘게 나왔는데 수치가 원본 데이터와 다르다" | Results의 모든 수치 그래프를 matplotlib/seaborn 코드로 재작성하고, 코드와 데이터 파일을 함께 보관한다 |
| 장식 과잉 다이어그램 | "Napkin AI 결과가 화려해서 그대로 썼더니 심사위원이 지적했다" | 색상을 흑·회·진청 위주로 제한하고, 박스당 텍스트를 한 문장 이하로 줄인 단순화 버전으로 교체한다 |
| 캡션에 AI 사용 미명시 | "AI 생성 다이어그램임을 캡션에 적지 않았다" | 프롬프트 3을 실행하여 전체 그림 목록의 AI 사용 명시 문구를 일괄 점검하고 Note에 추가한다 |
