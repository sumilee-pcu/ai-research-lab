## 언제 쓰나

| 상황 | 추천 프롬프트 |
|---|---|
| 국문 학술 문체가 거칠거나 번역투가 섞여 있을 때 | 프롬프트 1 |
| 영문 초록을 처음 작성하거나 6문장 구조로 재편해야 할 때 | 프롬프트 2 |
| AI 사용 명시 문구를 학술지·학위논문에 삽입해야 할 때 | 프롬프트 3 |

핵심 원칙: **AI는 도구이지 공저자가 아니다.** 표절·자기표절 책임은 연구자 본인에게 있으며, 학술지·학교 규정이 모든 AI 가이드라인보다 우선한다.

## 프롬프트 1 — 국문 학술체 교정

**무엇을 얻나:** 번역투·과장·근거 부족·용어 불일치·자기복제 위험 문장을 표시하고, 학위논문 수준의 교정문을 반환한다. AI 사용 명시가 필요한 부분까지 함께 판단해 준다.

```text
아래 문단을 학위논문 문체로 교정하라. 의미는 바꾸지 말고, 긴 문장은 나누고,
주어·서술어를 분명히 하라.

다음 항목을 표시하고 수정 방향을 제시하라:
① 번역투(과도한 수동태, it/this의 직역, "할 수 있다는 것이다" 등)
② 과장·근거 부족 표현("매우", "혁신적", "상당히" 등)
③ 용어 불일치(같은 개념을 여러 단어로 표현한 경우)
④ 표절·자기표절 위험 문장 [자기복제 위험]으로 표시
⑤ AI 사용 명시가 필요한 부분 [규정 확인 필요]로 표시

마지막에 교정 요약표(원문 문제 | 수정 방향)를 작성하라.

원문:
[교정할 문단을 여기에 붙여넣기]
```

**입력 예시:**

```text
원문:
본 연구는 딥러닝을 활용하여 데이터를 처리하는 것으로써 혁신적인 결과를 얻을
수 있다는 것이다. 데이터를 수집하고 분석하는 것을 진행하였으며, 이를 통해
매우 높은 정확도를 달성했다. 또한 이전 연구에서 제시된 바와 같이 본 접근은
기존 방법과 차별화되는 특성을 가진다.
```

**기대 출력(요약):**

- 번역투·과장 구문을 [번역투], [과장] 태그로 표시
- 교정문 제시("할 수 있다는 것이다" → "할 수 있다", "진행하였다" → "하였다")
- 용어 통일 제안, 자기복제 의심 문장 경고
- 교정 요약표(원문 문제 | 수정 방향) 출력

**검증 프롬프트:**

```text
위 교정문에서 학술체 교정 5요소(정확성·간결성·객관성·일관성·흐름) 기준으로
미흡한 부분이 아직 남아 있다면 지적하라. 없으면 "교정 완료"로 답하라.
```

## 프롬프트 2 — 영문 초록 6문장 공식

**무엇을 얻나:** Background → Problem → Method → Result → Implication → Future의 6문장 구조로 영문 초록을 작성 또는 재편한다. 각 문장의 시제 준수 여부도 함께 검토한다.

```text
다음 한국어 초록 또는 본문 요약을 영문 초록 6문장 공식으로 재구성하라.

6문장 구조와 시제 규칙:
① Background  — 일반 배경·중요성 (현재시제)
② Problem     — 본 연구가 풀려는 문제 (현재시제)
③ Method      — 연구 방법·절차 (과거시제)
④ Result      — 주요 발견 (과거시제)
⑤ Implication — 결과의 의미·기여 (현재시제)
⑥ Future      — 다음 단계·한계 (미래 또는 현재시제)

추가 조건:
- 전체 250–300단어 이내
- 1인칭 we/I 최소화, 가능하면 수동태 또는 3인칭 전환
- 약어는 첫 등장 시 전체 표기(full form) 병기
- 목표 학술지 스타일: [IEEE / APA / KCI 중 선택]

입력 초록 또는 요약:
[초록 또는 핵심 내용을 여기에 붙여넣기]
```

**입력 예시:**

```text
목표 학술지 스타일: APA

입력 초록:
본 연구는 국내 중소기업의 AI 도입 장벽을 분석하고, 정책적 지원 방향을
제안하는 것을 목적으로 한다. 설문조사(n=240)와 심층 인터뷰(n=12)를 통해
데이터를 수집하였으며, 비용·인력·데이터 부족이 주요 장벽으로 확인되었다.
정부 지원 확대와 교육 인프라 구축이 시급함을 제안한다.
```

**기대 출력(요약):**

- 6문장 번호 표시 영문 초록 (①~⑥)
- 각 문장 옆에 [시제: 현재/과거/미래] 태그
- 단어 수 카운트 명시
- 수정이 필요한 시제 오류 또는 1인칭 표현 경고

**검증 프롬프트:**

```text
위 영문 초록이 6문장 공식(Background·Problem·Method·Result·Implication·Future)과
시제 규칙을 모두 충족하는지 항목별로 확인하라. 문제가 있으면 해당 문장을
수정하고, 없으면 "공식 준수 완료"로 답하라.
```

## 프롬프트 3 — AI 사용 명시 문구(도구·목적·검증 책임)

**무엇을 얻나:** 학술지·학위논문 규정에 맞는 AI 사용 명시 문구 초안을 작성한다. 도구명·버전·사용 목적·최종 검증 책임자를 포함하며, 규정 확인이 필요한 항목을 [규정 확인 필요]로 표시한다.

```text
다음 AI 사용 내역을 바탕으로 학술 문서에 삽입할 AI 사용 명시 문구를 작성하라.

명시 문구에 반드시 포함할 요소:
① AI 도구명 및 버전 (예: Claude 3.7 Sonnet, ChatGPT-4o)
② 사용 목적 (예: 국문 교정, 영문 번역, 코드 생성, 통계 해석 등)
③ 사용 섹션 또는 작업 범위
④ 최종 검증·수정 책임자 (저자 본인)

출력 형식:
- 학위논문 각주용 1문장 버전
- 학술지 저자 기여(Author Contribution) 섹션용 2–3문장 버전
- 규정 확인이 필요한 항목은 [규정 확인 필요]로 표시

사용 내역:
- 도구명·버전: [AI 도구명과 버전 입력]
- 사용 목적: [국문 교정 / 영문 번역 / 코드 생성 / 데이터 시각화 / 기타]
- 사용 섹션: [논문의 해당 섹션명 또는 작업 범위]
- 제출 대상: [학위논문 / 학술지명 / 학회명]
```

**입력 예시:**

```text
사용 내역:
- 도구명·버전: Claude 3.7 Sonnet (2025년 3월)
- 사용 목적: 3장 연구방법 국문 교정, 영문 초록 1차 번역
- 사용 섹션: 3장 전체 및 Abstract
- 제출 대상: 한국경영학회 춘계 학술대회 투고 논문
```

**기대 출력(요약):**

- 각주용 1문장: "본 논문 3장 및 Abstract의 국문 교정과 영문 번역은 Claude 3.7 Sonnet(Anthropic, 2025.03)을 활용하였으며, 최종 검증·수정은 저자가 직접 수행하였다."
- 저자 기여 섹션용 2–3문장 버전 별도 제공
- [규정 확인 필요] 항목: 한국경영학회 AI 사용 명시 세부 기준

**검증 프롬프트:**

```text
위 AI 사용 명시 문구가 ① 도구명·버전, ② 사용 목적, ③ 사용 범위, ④ 검증 책임자
네 가지 요소를 모두 포함하는지 확인하라. 누락된 요소가 있으면 보완하고,
없으면 "명시 요건 충족"으로 답하라.
```

## ✅ 연구자 체크 — AI 사용 고지·표절 책임

제출 전 아래 항목을 직접 확인한다.

- [ ] **AI 도구 사용 내역** 문서화 완료 (도구명·버전·목적·섹션)
- [ ] **학술지 또는 학과 AI 사용 가이드라인** 최신본 확인 (규정은 수시로 변경)
- [ ] **카피킬러 또는 Turnitin** 유사도 점검 완료 (학과 기준치 이하 확인)
- [ ] **자기표절** 여부 점검 — 이전 제출 논문과 중복 여부 확인
- [ ] AI 생성 텍스트의 **의미 변형·오류** 여부 저자 본인이 최종 검토
- [ ] **재현성 패키지 7요소** 준비 완료 (본문 PDF·데이터·코드·프롬프트 로그·시각화·유사도 보고서·AI 명시 문서)
- [ ] 영문 초록 시제 규칙(현재/과거) 및 단어 수(250–300) 준수 확인

> AI는 도구다. 논문의 모든 주장·데이터·윤리 책임은 저자 본인에게 있다.

## ⚠️ 흔한 실패 패턴

| 실패 패턴 | 원인 | 해결 방법 |
|---|---|---|
| AI 교정 후 의미가 바뀌었다 | 프롬프트에 "의미는 바꾸지 말라" 조건 미삽입, 또는 검토 생략 | 교정 전·후 원문 대조 필수; 검증 프롬프트 실행 |
| 유사도가 임계치를 초과했다 | 인용 처리 미흡, 자기복제 문장 포함, AI 생성 문장이 기존 논문과 유사 | 출처 인용 보완; 부속 사 대응 워크플로우 참조 |
| AI 사용 명시를 제출 후에 추가하려 한다 | 집필 단계에서 사용 내역 미기록 | 작업 직후 즉시 기록; 프롬프트 3을 집필 단계에 사용 |
