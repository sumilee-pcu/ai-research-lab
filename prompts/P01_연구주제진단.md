# P-1 연구주제 진단 — 제1장 프롬프트 패키지

> 연결 장: 제1장 AI 연구의 원리 · 워크북: [W-1](../workbook/W1_연구출발점과도구스택.md) · 부록: [A](../appendix/A_자주쓰는프롬프트30종.md)
> 사용법: 복사 → [대괄호] 교체 → 실행 → 검증 프롬프트로 재확인

---

## 언제 쓰나

- 연구주제가 있긴 한데 논문으로 쓸 수 있는 건지 아직 확신이 서지 않을 때
- 주제는 정해졌지만 데이터 확보·분석 방법·기여 방향이 막막할 때
- AI에게 얼마나 맡기고, 어디서부터 내가 책임져야 하는지 경계를 그려두고 싶을 때
- 지도교수 면담이나 논문 계획서 초안 작성 전 아이디어를 점검하고 싶을 때

## 프롬프트 1. DIKW 기반 연구주제 진단

무엇을 얻나: 연구주제를 데이터·정보·지식·지혜 4층으로 해부한 진단표 + 위험요소 + 7일 실행과제

```text
## Role
당신은 학위논문 연구설계 코치이자 AI 활용 윤리 점검자입니다.

## Context
내 연구주제는 [주제]입니다.
소속: [대학원 과정 및 전공], 연구 단계: [초기 아이디어 / 연구계획서 작성 중 / 본 연구 진행 중]
활용 가능한 주요 데이터·자료: [예: 설문 계획, 공공 통계, 기업 내부 자료 등]

## Task
1. 위 연구주제를 학위논문에 적합한 한 문장으로 정교화하라.
   형식: "본 연구는 (대상)에 대해 (방법)을 통해 (목적)을 달성하고자 한다. 이는 학술적으로 (신규성)에 기여하며, 실무에서는 (가치)로 이어진다."
2. DIKW 관점에서 이 주제를 아래 표 형식으로 분석하라.

| 층 | 정의 | 이 연구에서 필요한 자료 | AI가 도울 수 있는 일 | 연구자가 직접 책임질 판단 | 검증 방법 | 예상 산출물 |
|---|---|---|---|---|---|---|
| 데이터(Data) | | | | | | |
| 정보(Information) | | | | | | |
| 지식(Knowledge) | | | | | | |
| 지혜(Wisdom) | | | | | | |

3. 위험요소 5가지를 번호를 붙여 제시하라. (데이터 접근성, 윤리 심의, 변수 측정 가능성, 시간 제약, 선행연구 공백 여부 등 관점에서)
4. 7일 안에 실행할 과제 3가지를 구체적으로 제시하라.

## Format
- 표는 마크다운 형식으로 작성
- 각 항목은 2~3문장 이내로 간결하게
- 위험요소는 "위험 내용 / 대응 방향" 쌍으로 제시
- 실행과제는 "D+N일까지 / 구체적 행동" 형식

## 할루시네이션 방지 조건
- 없는 선행연구나 통계 수치를 만들지 말 것. 모르는 경우 [확인 필요]로 표시
- 추론 근거가 있는 진술은 "~으로 볼 수 있음", 확인된 사실은 출처를 명시
- 표 작성 후 자기검증: "어떤 항목이 가장 불확실한가?"를 마지막에 한 줄로 밝힐 것
```

입력 예시:
> 내 연구주제는 "중소 제조기업의 생성형 AI 도입이 업무 효율성에 미치는 영향"입니다. 소속: 경영학과 석사과정, 연구 단계: 연구계획서 작성 중. 활용 가능한 주요 자료: 중소기업 실태조사 공공 데이터, 기업 인터뷰 예정.

기대 출력(요약):
- 정교화된 논문 주제 1문장 (대상·방법·목적·신규성·실무가치 포함)
- DIKW 4층 분석표 (각 층마다 필요 자료, AI 역할, 연구자 책임, 검증법, 산출물)
- 위험요소 5개 (위험 내용 + 대응 방향 쌍)
- 7일 실행과제 3개 (D+N일 형식)

검증 프롬프트:
```text
방금 작성한 DIKW 진단표에서 [확인 필요]로 표시된 항목을 모두 나열하고,
각 항목을 실제로 확인하려면 어떤 1차 자료나 데이터베이스를 봐야 하는지 안내하라.
없는 자료를 만들지 말고, 확인 경로가 불분명한 경우도 그렇다고 밝혀라.
```

## 프롬프트 2. 연구주제 1문장 정교화

무엇을 얻나: 막연한 관심사를 측정 가능하고 심사 통과 가능한 1문장으로 압축

```text
## Role
당신은 학위논문 연구설계 전문 코치입니다. 연구대상·변수·분석 방향이 명확한 논문 주제문을 함께 다듬는 역할을 합니다.

## Context
내가 처음 생각한 연구 관심사는 다음과 같습니다:
[막연한 관심사 또는 초안 주제문 — 예: "AI가 중소기업에 미치는 영향"]

연구 분야: [예: 경영학 / 교육학 / 사회복지학]
연구 방법 선호: [예: 양적 연구(설문·통계) / 질적 연구(인터뷰·사례) / 혼합방법]
연구 맥락: [예: 국내 중소 제조기업, 규모 50인 이하, 2024~2025년]

## Task
1. 내 관심사의 문제점을 진단하라: 범위·측정 가능성·분석 단위·신규성 관점에서 각각 한 줄씩.
2. 다음 형식에 맞는 연구주제 1문장 후보 3가지를 제시하라.
   형식: "본 연구는 (연구대상)에 대해 (독립변수/조건)이 (종속변수/결과)에 미치는 영향을 (분석 방법)으로 분석한다."
3. 후보 3가지 각각에 대해 아래 항목을 채워라.

| 항목 | 후보 A | 후보 B | 후보 C |
|---|---|---|---|
| 연구대상(누구/무엇) | | | |
| 독립변수 | | | |
| 종속변수 | | | |
| 분석 방법 | | | |
| 데이터 확보 가능성 | | | |
| 선행연구 공백 여부 | | | |
| 추천 이유 | | | |

4. 세 후보 중 하나를 추천하고 이유를 2~3문장으로 밝혀라.

## Format
- 진단은 번호 없이 항목별 한 줄
- 후보 문장은 완전한 한 문장으로
- 비교표는 마크다운 형식

## 할루시네이션 방지 조건
- "선행연구 공백 여부" 항목에서 구체적 연구 제목·저자를 임의로 생성하지 말 것
- 선행연구 존재 여부가 불분명하면 [확인 필요 — DBpia·RISS 검색 권장]으로 표시
- 추천 이유는 논리 근거를 한 문장씩 명시하고, 추측은 "~으로 예상됨"으로 구분
```

입력 예시:
> 내가 처음 생각한 연구 관심사: "AI가 중소기업에 미치는 영향"
> 연구 분야: 경영학, 연구 방법 선호: 양적 연구(설문·회귀분석), 연구 맥락: 국내 중소 제조기업, 2024~2025년

기대 출력(요약):
- 기존 주제의 문제점 진단 (범위·측정 가능성·분석 단위·신규성 4항목)
- 주제 1문장 후보 3가지 (완성형 문장)
- 4×3 비교표 (연구대상·독립변수·종속변수·분석방법·데이터 확보 가능성·선행연구 공백·추천 이유)
- 최종 추천 1개 + 이유

검증 프롬프트:
```text
추천받은 연구주제 1문장을 가지고, 지도교수가 첫 면담에서 물어볼 법한
예상 질문 5가지를 생성하라. 각 질문 옆에 현재 내가 답할 수 있는지 여부를
"답변 가능 / 추가 준비 필요 / 확인 필요" 중 하나로 표시하라.
모르는 내용은 임의로 채우지 말고 [확인 필요]로 남겨라.
```

## 프롬프트 3. AI 협업 윤리·연구자 책임 점검

무엇을 얻나: AI를 쓰면 안 되는 구간과 반드시 연구자가 직접 판단해야 할 영역의 명확한 경계

```text
## Role
당신은 AI 연구윤리 점검 전문가입니다. 학위논문 작성 과정에서 AI 활용 범위와 연구자 책임 경계를 명확히 설정하는 일을 돕습니다.

## Context
연구주제: [확정된 연구주제 1문장]
소속 기관: [대학원명] / 학과: [학과명]
AI 활용 계획: [지금까지 AI를 쓰려고 한 작업 목록 — 예: 문헌 요약, 설문 문항 초안, 통계 해석, 본문 초안 작성 등]
현재 학교 AI 사용 가이드라인 확인 여부: [확인함 / 확인 안 함 / 가이드라인 없음]

## Task
1. 내 AI 활용 계획을 아래 기준으로 분류하라.

| 작업 항목 | AI 활용 가능 수준 | 필수 기재 사항 | 연구자 직접 책임 항목 | 잠재 위험 |
|---|---|---|---|---|
| [작업1] | | | | |
| [작업2] | | | | |
| ... | | | | |

   AI 활용 가능 수준 기준:
   - 적극 활용 가능: 반복 작업·형식 정리·초안 생성
   - 보조만 가능: 연구자 검증 필수
   - AI 사용 자제: 최종 판단·윤리 결정·책임 귀속 영역

2. 이 연구에서 특히 주의해야 할 윤리 위험요소 5가지를 제시하라.
   각 위험요소마다: 위험 설명 / 발생 조건 / 방지 방법을 한 줄씩 쓰라.

3. AI 사용 기록을 논문에 명시할 때 권장하는 방식 2가지를 제안하라.
   (학위논문 내 명시 방식, 심사위원회 보고 방식 각각)

## Format
- 분류표는 마크다운 형식
- 윤리 위험요소는 번호 목록
- 명시 방식은 예시 문장 포함

## 할루시네이션 방지 조건
- 특정 대학·학회의 AI 사용 규정을 임의로 인용하지 말 것. 규정 내용은 [확인 필요 — 소속 기관 확인 필요]로 표시
- 법적·윤리적 판단이 필요한 사항은 "~일 가능성이 있음"으로 수준을 밝히고, 최종 판단은 연구자·지도교수 몫임을 명시
- 추론 과정을 생략하지 말고, 어떤 근거로 분류했는지 표 아래에 2~3줄로 밝혀라
```

입력 예시:
> 연구주제: "중소 제조기업의 생성형 AI 도입 수준이 업무 효율성과 의사결정 속도에 미치는 영향을 다중회귀분석으로 분석한다."
> 소속: ○○대학교 경영학과 석사과정
> AI 활용 계획: 문헌 요약, 설문 문항 초안 생성, 통계 결과 해석 보조, 결론 초안 작성
> 학교 가이드라인 확인 여부: 확인 안 함

기대 출력(요약):
- 작업별 AI 활용 가능 수준 분류표 (적극 활용 가능 / 보조만 가능 / AI 사용 자제)
- 연구 특화 윤리 위험요소 5개 (위험 설명·발생 조건·방지 방법 포함)
- 논문 내 AI 사용 명시 방식 2가지 (예시 문장 포함)

검증 프롬프트:
```text
위에서 "AI 사용 자제" 또는 "연구자 직접 책임" 항목으로 분류된 작업들만 뽑아라.
각 작업마다 내가 현재 그 판단을 내릴 준비가 되어 있는지 점검할 수 있는
자가 점검 질문 1개씩을 만들어라. 답을 만들지 말고 질문만 제시하라.
```

## ✅ 연구자 체크 (출력 받은 뒤)

- [ ] AI가 제시한 선행연구 공백·통계 수치를 DBpia·RISS·Google Scholar에서 직접 확인했는가
- [ ] DIKW 지혜 층의 판단(연구의 사회적 가치, 연구결과 활용 방향)은 내가 직접 작성했는가
- [ ] 연구주제 1문장에 연구대상·독립변수·종속변수·분석 방법이 모두 포함되어 있는가
- [ ] 소속 대학원의 AI 사용 가이드라인을 실제로 확인하고 위험 항목을 체크했는가
- [ ] [확인 필요] 표시가 붙은 항목을 그대로 논문 초안에 쓰지 않았는가
- [ ] AI 활용 내역을 별도 노트에 기록해두었는가 (지도교수 면담·심사 대비)

## ⚠️ 흔한 실패 패턴

| 증상 | 원인 | 처방 |
|---|---|---|
| AI가 그럴듯한 선행연구 제목을 제시했는데 실제로 존재하지 않음 | 할루시네이션 — LLM은 없는 논문도 확률적으로 생성함 | 검증 프롬프트를 반드시 실행하고, 인용 전 DBpia·RISS·Google Scholar에서 원문 확인 |
| 주제 1문장이 계속 바뀌고 AI마다 다른 방향을 제안함 | 입력 맥락(Context)이 너무 짧아 AI가 방향을 못 잡음 | 프롬프트 2의 Context 칸(연구 분야·방법·맥락)을 구체적으로 채운 뒤 재실행 |
| DIKW 지혜 층이 비어 있거나 "연구자 책임"으로만 처리됨 | AI가 가치 판단 영역을 회피하는 것은 정상 — 이 층은 연구자 몫 | 워크북 W-1의 Step 2 양식을 직접 손으로 채우고, AI 출력을 참고 자료로만 사용 |
