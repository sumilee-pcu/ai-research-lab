# AI 논문작성 프롬프트 어휘 사전 — 확장판
### "어떤 단어를 쓰느냐가 AI 답변의 수준을 결정한다"

> **핵심 원리(프롬프트 이론의 출발점)**
> AI는 당신이 쓴 단어를 단서로 "이 사람이 어느 수준·어느 분야의 답을 원하는가"를 추정한다.
> 막연히 "분석해줘"라고 하면 막연한 답이, **"구성타당도 관점에서 분석해줘"**라고 하면 측정학 전문 분석이 나온다.
> → **정확한 학술 용어 = AI의 해당 분야 전문지식 활성화 스위치.**
>
> 사용법: 외우지 말고 "이런 개념이 있구나"를 알고, 논문 쓸 때 **꺼내 쓰는** 어휘판으로 활용한다.
> 각 용어: **비유 + 뜻 + "이 단어를 쓰면 AI 답변이 어떻게 달라지는가(프롬프트 예시)"**

---

## 1장. 연구적 사고·인지 — 연구자처럼 생각하게 하는 단어

**메타인지 (Metacognition)**
- 비유: 운전 중 "지금 내가 졸린지"를 아는 것. 연구로 치면 "내 논리에 빈틈이 있는지"를 스스로 점검.
- 뜻: 자기가 무엇을 알고 모르는지 인식하는 능력. "생각에 대한 생각."
- 프롬프트: "내 연구설계에서 **메타인지적으로** 점검이 안 된 가정을 짚어줘" → 단순 검토가 아닌 *숨은 전제* 진단.

**조작적 정의 (Operational Definition)**
- 비유: "행복"을 잴 수 없으니 "최근 1주 긍정정서 점수"로 바꿔 측정 가능하게 만드는 것.
- 뜻: 추상 개념을 측정·관찰 가능한 구체적 지표로 바꾼 정의.
- 프롬프트: "이 변수를 **조작적으로 정의**해줘" → 개념 설명이 아닌 *측정 문항·지표*가 나온다.

**개념적 틀 (Conceptual Framework)**
- 비유: 집 짓기 전의 설계 도면. 변수들이 어떻게 연결되는지의 지도.
- 뜻: 연구의 핵심 개념과 그 관계를 도식·논리로 구조화한 틀.
- 프롬프트: "이 주제의 **개념적 틀**을 변수 관계도로 제시해줘" → 나열이 아닌 *인과·관계 구조*.

**연역/귀납 (Deduction / Induction)**
- 비유: 연역=이론에서 가설로 내려오기, 귀납=관찰에서 패턴으로 올라가기.
- 뜻: 연역은 이론→가설→검증, 귀납은 자료→패턴→이론.
- 프롬프트: "이 연구를 **연역적 접근**으로 재구성해줘" → 탐색식이 아닌 *가설검증 구조*.

**환원주의 vs 전체론 (Reductionism / Holism)**
- 비유: 시계를 부품으로 분해해 이해(환원) vs 전체 작동을 통째로 이해(전체).
- 뜻: 현상을 부분으로 쪼개 설명할지, 전체 맥락으로 볼지의 관점.
- 프롬프트: "이 현상을 **환원주의적/전체론적** 두 관점으로 각각 분석해줘" → 한쪽 치우침 방지.

**언어화 (Articulation)**
- 비유: 고수의 "대충 이만큼"을 레시피로 적어내는 것. 직관을 글로 꺼내기.
- 뜻: 머릿속 암묵지를 명시적 언어로 표현하는 행위.
- 프롬프트: "내 연구 동기를 **학술적으로 언어화**해줘" → 감상이 아닌 *연구 정당화 논리*.

**비판적 사고 (Critical Thinking)**
- 비유: 기사 하나를 읽고 "출처·근거·반례"를 따져보는 습관.
- 뜻: 주장·근거·전제를 의심하고 검증하는 사고.
- 프롬프트: "이 논의를 **비판적으로** 검토하고 반론을 제시해줘" → 동조가 아닌 *약점 노출*.

## 2장. 연구 설계 — 연구의 뼈대를 세우는 단어

**연구문제 / 연구목적 (Research Question / Purpose)**
- 비유: 여행의 목적지. 없으면 어디로 가는지 모름.
- 뜻: 연구가 답하려는 핵심 질문과 그 의도.
- 프롬프트: "이 주제에서 검증 가능한 **연구문제** 3개를 구체화해줘" → 막연한 관심이 *측정가능 질문*으로.

**변수 (독립·종속·매개·조절·통제) (Variables)**
- 비유: 요리에서 불세기(독립)→맛(종속), 재료신선도(조절), 소금(통제).
- 뜻: 원인변수·결과변수·중간경로(매개)·조건(조절)·고정요인(통제).
- 프롬프트: "이 모형의 **독립·종속·매개·조절·통제변수**를 분류해줘" → 뭉뚱그린 요인이 *역할별 구조*로.

**가설 (Hypothesis)**
- 비유: "비 오면 매출 준다"처럼 검증 전 미리 세운 예측.
- 뜻: 변수 간 관계에 대한 검증 가능한 진술.
- 프롬프트: "이 연구문제를 **영가설·대립가설**로 진술해줘" → 추측이 *통계검증용 형식*으로.

**표집 (Sampling)**
- 비유: 국 한 솥의 간을 보려고 한 숟갈 떠보기. 대표성이 핵심.
- 뜻: 모집단에서 표본을 뽑는 방법(확률/비확률, 층화·편의 등).
- 프롬프트: "이 연구에 적합한 **표집 방법**과 표본수 근거를 제시해줘" → 임의 수가 *정당화된 설계*로.

**타당도 (내적·외적·구성·준거) (Validity)**
- 비유: 체중계가 "체중"을 재야 타당. 키를 재면 부타당.
- 뜻: 측정·결론이 의도한 것을 제대로 반영하는 정도.
- 프롬프트: "이 척도의 **구성타당도·준거타당도** 확보 방안을 제시해줘" → 일반 검토가 *측정학 절차*로.

**신뢰도 (Reliability)**
- 비유: 같은 체중을 열 번 재도 비슷하게 나오는 저울.
- 뜻: 반복 측정 시 결과의 일관성(예: Cronbach's α).
- 프롬프트: "이 척도의 **신뢰도**를 어떻게 보고·해석하는지 알려줘" → 숫자가 *해석 기준*과 함께.

**삼각검증 (Triangulation)**
- 비유: 산 높이를 세 지점에서 재서 오차를 줄이는 것.
- 뜻: 복수의 자료·방법·관점으로 결론의 견고성을 높이는 전략.
- 프롬프트: "이 결론을 **삼각검증** 구조로 보강해줘" → 단일 근거가 *다중 증거*로.

## 3장. 문헌고찰·이론 — 선행연구 위에 서는 단어

**선행연구 / 연구 갭 (Prior Research / Research Gap)**
- 비유: 지도에서 아직 아무도 안 간 빈 곳을 찾는 것.
- 뜻: 기존 연구가 다루지 못한 빈틈 = 내 연구의 자리.
- 프롬프트: "이 분야 선행연구의 **연구 갭**을 유형별로 정리해줘" → 요약이 *내 기여 지점*으로.

**이론적 배경 (Theoretical Background)**
- 비유: 새 건물을 세울 기존 지반.
- 뜻: 연구를 떠받치는 기존 이론·모형의 토대.
- 프롬프트: "이 주제의 **이론적 배경**으로 적합한 이론 3개와 적용 논리를 제시해줘".

**체계적 문헌고찰 (Systematic Review)**
- 비유: 도서관 전체를 정해진 규칙대로 빠짐없이 훑기.
- 뜻: 명시적 절차(검색식·포함/배제 기준)로 문헌을 빠짐없이 종합하는 방법.
- 프롬프트: "이 키워드로 **체계적 문헌고찰**의 검색전략과 선정기준을 설계해줘".

**메타분석 (Meta-Analysis)**
- 비유: 여러 저울의 측정치를 합쳐 더 정확한 무게를 내는 것.
- 뜻: 다수 연구의 효과크기를 통계적으로 통합하는 분석.
- 프롬프트: "이 주제가 **메타분석** 대상으로 적합한지 기준으로 판단해줘".

**인용·표절·자기표절 (Citation / Plagiarism)**
- 비유: 남의 아이디어엔 출처라는 '이름표'를 붙여야 함.
- 뜻: 출처표기 규범과 그 위반(타인·자기 글 무단 재사용).
- 프롬프트: "이 문단의 **표절 위험 구간**과 인용 보완점을 짚어줘" → 막연한 검사가 *구체 수정점*으로.

**포화 (Saturation, 질적)**
- 비유: 인터뷰를 더 해도 새 이야기가 안 나오는 지점.
- 뜻: 추가 자료가 새 통찰을 주지 않는 상태(표본 종료 근거).
- 프롬프트: "이 질적연구에서 **이론적 포화**를 어떻게 판단·서술하는지 알려줘".

## 4장. 연구방법·자료수집 — 데이터를 만드는 단어

**양적·질적·혼합연구 (Quantitative / Qualitative / Mixed)**
- 비유: 숫자로 재기(양적) vs 의미를 캐기(질적) vs 둘을 엮기(혼합).
- 뜻: 측정·통계 중심 / 의미·맥락 중심 / 두 접근의 결합.
- 프롬프트: "이 연구문제에 **양적·질적·혼합** 중 어떤 설계가 적합한지 근거로 비교해줘".

**측정도구 / 척도 (Instrument / Scale)**
- 비유: 길이를 재는 자, 마음을 재는 설문.
- 뜻: 변수를 수치화하는 검증된 문항 묶음(리커트 등).
- 프롬프트: "이 변수를 측정할 **검증된 척도**와 출처, 신뢰도를 추천해줘".

**평정자 간 신뢰도 (Inter-rater Reliability)**
- 비유: 심사위원 3명의 점수가 얼마나 일치하나.
- 뜻: 둘 이상 코더가 같은 자료를 같게 분류하는 일치도(κ 등).
- 프롬프트: "이 내용분석의 **평정자 간 신뢰도**(Cohen's κ) 산출·해석법을 알려줘".

**근거이론·현상학·사례연구 (Grounded Theory / Phenomenology / Case Study)**
- 비유: 자료에서 이론을 길어 올리기 / 체험의 본질 캐기 / 한 사례 깊이 파기.
- 뜻: 대표적 질적연구 접근들.
- 프롬프트: "내 자료에 **근거이론** 코딩(개방·축·선택)을 적용하는 절차를 설계해줘".

**내용분석 / 코딩 (Content Analysis / Coding)**
- 비유: 인터뷰 녹취를 색깔 형광펜으로 주제별 분류.
- 뜻: 텍스트를 범주로 체계 분류·계량화하는 분석.
- 프롬프트: "이 응답들을 **코딩 스킴**으로 범주화하고 빈도를 정리해줘".

## 5장. 통계·데이터 분석 — 결과를 증명하는 단어

**기술통계 / 추론통계 (Descriptive / Inferential)**
- 비유: 사진 찍기(현황 묘사) vs 표본으로 모집단 추정.
- 뜻: 자료를 요약 / 표본에서 모집단을 추론.
- 프롬프트: "이 데이터의 **기술통계**부터 보고하고, 이어 적합한 **추론통계**를 제안해줘".

**정규성 (Normality)**
- 비유: 종 모양 분포인지 확인. 아니면 다른 검정 필요.
- 뜻: 자료가 정규분포를 따르는 정도(왜도·첨도, Shapiro-Wilk).
- 프롬프트: "이 변수의 **정규성**을 점검하고 위반 시 대안 검정을 알려줘".

**Cronbach's α (신뢰도 계수)**
- 비유: 한 척도 안 문항들이 한목소리를 내는 정도.
- 뜻: 내적 일관성 신뢰도 지수(보통 .70 이상 권장).
- 프롬프트: "요인별 **Cronbach's α**와 *항목 제거 시 α*로 약한 문항을 진단해줘".

**요인분석 (EFA / CFA)**
- 비유: 흩어진 문항들을 비슷한 것끼리 묶어 '덩어리(요인)'를 찾기.
- 뜻: 문항 뒤의 잠재 구조를 탐색(EFA)·확인(CFA).
- 프롬프트: "**탐색적 요인분석(EFA)** 절차(KMO·Bartlett·요인추출·회전)를 단계로 안내해줘".

**상관·회귀 (Correlation / Regression)**
- 비유: 키와 몸무게가 같이 움직이나(상관), 키로 몸무게를 예측(회귀).
- 뜻: 변수 간 관계의 강도 / 예측·설명 모형.
- 프롬프트: "이 변수들로 **위계적 회귀**를 설계하고 가정 점검까지 포함해줘".

**효과크기 / p값 (Effect Size / p-value)**
- 비유: "차이가 있다(p)"와 "얼마나 크다(효과크기)"는 다른 질문.
- 뜻: 유의성(우연 아님)과 실질적 크기(Cohen's d 등).
- 프롬프트: "유의성뿐 아니라 **효과크기**까지 보고·해석하는 문장을 써줘".

**매개·조절분석 (Mediation / Moderation)**
- 비유: 매개=중간 다리, 조절=관계의 세기를 바꾸는 스위치.
- 뜻: 변수 간 경로의 메커니즘(매개)·조건(조절).
- 프롬프트: "X→Y에 M의 **매개효과**를 검증하는 절차(Baron&Kenny/부트스트랩)를 정리해줘".

## 6장. 학술 글쓰기 — 논문답게 쓰게 하는 단어

**IMRaD 구조**
- 비유: 논문의 표준 골격: 서론-방법-결과-논의.
- 뜻: Introduction·Methods·Results·Discussion 구성.
- 프롬프트: "이 초고를 **IMRaD** 구조로 재배치하고 빠진 섹션을 지적해줘".

**서론 깔때기 (Funnel Introduction)**
- 비유: 넓은 배경에서 좁은 연구문제로 좁혀 내려가는 깔때기.
- 뜻: 일반→구체로 좁히는 서론 전개 방식.
- 프롬프트: "이 서론을 **깔때기 구조**(배경→갭→목적→문제)로 다시 써줘".

**논증 (Argumentation)**
- 비유: 주장-근거-반론-재반박의 토론.
- 뜻: 주장과 증거로 결론을 정당화하는 글의 논리.
- 프롬프트: "이 단락의 **논증 구조**(주장·근거·반례)를 점검하고 보강해줘".

**헤지징 (Hedging)**
- 비유: "확실히 그렇다" 대신 "그럴 가능성이 있다"의 신중한 어조.
- 뜻: 단정 대신 적절한 유보로 학술적 신중함을 표현.
- 프롬프트: "이 결과 서술을 **헤지징**을 적용해 과장 없이 다듬어줘".

**응집성·일관성 (Cohesion / Coherence)**
- 비유: 문장이 매끄럽게 이어지고(응집), 전체가 한 방향(일관).
- 뜻: 연결어·지시어로 이어지는 흐름과 논리적 일관성.
- 프롬프트: "이 문단의 **응집성**을 높이게 연결어와 흐름을 손봐줘".

**주제문 (Topic Sentence)**
- 비유: 문단의 머리글자. 한 문단=한 주장.
- 뜻: 단락의 핵심을 첫 문장에 제시하는 구조.
- 프롬프트: "각 단락에 **주제문**을 세우고 한 단락 한 주장으로 정리해줘".

**학술적 어조 (Academic Tone)**
- 비유: 일기체가 아닌 학회 발표체.
- 뜻: 객관적·격식적·근거 기반의 글투.
- 프롬프트: "이 글을 **학술적 어조**로(구어·1인칭 과다 제거) 교정해줘".

## 7장. AI 활용·프롬프트 기법 — AI를 연구 파트너로 만드는 단어

**프롬프트 엔지니어링 (Prompt Engineering)**
- 비유: 네비에 "강남" 대신 "강남역 2번 출구"를 입력.
- 뜻: 원하는 결과를 끌어내도록 지시를 정교하게 설계하는 기술.
- 프롬프트: 이 사전 전체가 그 실천이다 — **정확한 용어가 곧 정교한 프롬프트**.

**역할 부여 (Persona / Role Prompting)**
- 비유: AI에게 "당신은 통계 심사위원"이라는 배역을 주기.
- 뜻: 답변자의 전문 역할을 지정해 관점·수준을 고정.
- 프롬프트: "**당신은 SSCI 심사위원이다.** 이 논의를 심사평 형식으로 비판해줘".

**맥락 주입 (Context Injection)**
- 비유: 비서에게 회의 전 배경자료를 먼저 건네기.
- 뜻: 과제 전 필요한 배경·자료·제약을 함께 제공.
- 프롬프트: "다음 **선행연구 3편 요약을 맥락으로** 주고, 이 위에서 갭을 도출해줘".

**사고연쇄 (Chain-of-Thought)**
- 비유: 답만 말하지 말고 "풀이 과정을 보이며" 풀기.
- 뜻: 단계적 추론을 유도해 논리 비약을 줄이는 기법.
- 프롬프트: "**단계별로 추론하며**(CoT) 이 가설의 논리적 타당성을 검토해줘".

**예시 학습 (Few-shot)**
- 비유: "이렇게 써줘" 하고 견본 2개를 먼저 보여주기.
- 뜻: 원하는 형식의 예시를 제시해 출력 형태를 맞추는 기법.
- 프롬프트: "다음 **예시 2개의 형식**대로 내 연구 함의를 작성해줘".

**RAG / 문헌 기반 생성 (Retrieval-Augmented Generation)**
- 비유: 오픈북 시험. 답하기 전 관련 문서를 먼저 검색·참조.
- 뜻: 외부 문헌을 검색·주입해 근거 있는 답을 생성(노트북LM 등).
- 프롬프트: "**업로드한 논문들만 근거로**(RAG) 답하고 출처를 표기해줘" → 환각↓.

**환각·팩트체크 (Hallucination / Fact-check)**
- 비유: AI가 그럴듯한 가짜 인용을 지어내는 현상.
- 뜻: 사실과 다른 생성. 인용·수치는 반드시 검증 필요.
- 프롬프트: "이 답의 **환각 가능 지점**(특히 인용·통계)을 표시하고 검증법을 알려줘".

**적대적 협력 (Adversarial Collaboration)**
- 비유: 검사와 변호사를 동시에 세워 편향을 줄이기.
- 뜻: 일부러 반대 입장을 두어 결론의 견고성을 높이는 방법.
- 프롬프트: "이 주장에 **적대적 협력** 구조로 찬반 논거를 모두 펼친 뒤 종합해줘".

## 8장. 연구윤리·신뢰성 — 믿을 수 있는 연구로 만드는 단어

**연구윤리 / IRB**
- 비유: 사람 대상 연구의 안전벨트와 심사대.
- 뜻: 연구의 도덕적 규범과 기관생명윤리위원회 심의.
- 프롬프트: "이 설문연구의 **IRB 심의 포인트**(동의·익명·위험)를 점검해줘".

**AI 저자성·생성형 AI 사용 고지 (AI Authorship / Disclosure)**
- 비유: AI는 도구이지 공저자가 아니다 — 단, 사용 사실은 밝힌다.
- 뜻: 생성형 AI 활용 시 학술지 규정에 따른 고지·책임 원칙.
- 프롬프트: "이 논문에 **AI 사용 고지문**을 학술지 규정 형식으로 작성해줘".

**재현가능성 (Reproducibility)**
- 비유: 레시피대로 하면 누구나 같은 요리가 나와야 함.
- 뜻: 동일 방법·데이터로 같은 결과를 얻을 수 있는 성질.
- 프롬프트: "이 방법 섹션을 **재현가능**하도록 빠진 절차·파라미터를 보완해줘".

**투명성 / 사전등록 (Transparency / Pre-registration)**
- 비유: 경기 전 규칙을 미리 공개해 사후 짜맞추기를 막기.
- 뜻: 가설·분석을 사전에 공개·고정해 연구 신뢰를 높이는 관행.
- 프롬프트: "이 연구의 **사전등록** 양식(가설·변수·분석계획)을 작성해줘".

**데이터 위변조 / 선택적 보고 (Fabrication / Cherry-picking)**
- 비유: 잘 나온 결과만 골라 보여주기 = 반칙.
- 뜻: 데이터 조작·유리한 결과만 보고하는 부정행위.
- 프롬프트: "이 결과 보고에 **선택적 보고** 위험이 있는지 점검해줘".

## 9장. 양적연구 심화 — 모형을 정교하게 만드는 단어

**구조방정식모형 (SEM)**
- 비유: 여러 회귀를 하나의 큰 인과 지도로 동시에 그리는 것.
- 뜻: 측정모형+구조모형으로 잠재변수 간 관계를 한 번에 검증.
- 프롬프트: "이 모형을 **구조방정식(SEM)**으로 설정하고 적합도지수(CFI·RMSEA·SRMR) 기준을 알려줘".

**위계선형모형 / 다층모형 (HLM / Multilevel)**
- 비유: 학생(1수준)이 학급(2수준)에 묶여 있는 자료를 그 구조대로 분석.
- 뜻: 자료의 내포(중첩) 구조를 반영하는 분석.
- 프롬프트: "학생-학급 내포 자료라 **다층모형**이 필요한지 ICC로 판단해줘".

**측정동일성 (Measurement Invariance)**
- 비유: 한국·미국 응답자에게 같은 '자'로 재고 있는지 확인.
- 뜻: 집단 간 척도가 동일하게 작동하는지 검증(형태·계수·절편).
- 프롬프트: "집단 비교 전에 **측정동일성**(configural→metric→scalar) 절차를 안내해줘".

**수렴·판별타당도 (AVE / CR)**
- 비유: 같은 요인 문항은 뭉치고(수렴), 다른 요인과는 떨어져야(판별).
- 뜻: AVE·복합신뢰도(CR)·상관으로 구성타당도를 통계 검증.
- 프롬프트: "**AVE와 CR**로 수렴·판별타당도를 평가하는 기준과 해석을 정리해줘".

**다중공선성 (Multicollinearity)**
- 비유: 키와 다리길이를 둘 다 예측변수로 넣으면 서로 겹쳐 혼선.
- 뜻: 독립변수 간 강한 상관으로 추정이 불안정해지는 문제(VIF).
- 프롬프트: "회귀 전 **다중공선성**을 VIF로 점검하고 대처법을 알려줘".

**검정력 분석 (Power Analysis)**
- 비유: 차이를 잡아내려면 표본이 몇 명 필요한지 미리 계산.
- 뜻: 효과크기·유의수준·검정력으로 필요 표본수를 산출(G*Power).
- 프롬프트: "효과크기 .3, 검정력 .8 기준 **표본수**를 산출하고 근거를 써줘".

**결측치·이상치 (Missing Data / Outlier)**
- 비유: 빈칸(결측)과 튀는 값(이상치)을 어떻게 다룰지 미리 정하기.
- 뜻: 누락·극단값의 진단과 처리(대체·제거 등).
- 프롬프트: "이 데이터의 **결측 패턴**과 **이상치**를 진단하고 처리 방침을 제안해줘".

**부트스트래핑 (Bootstrapping)**
- 비유: 표본을 수천 번 재추출해 분포를 시뮬레이션.
- 뜻: 재표집으로 신뢰구간을 추정(매개효과 검증에 자주 사용).
- 프롬프트: "매개효과를 **부트스트랩 5000회**로 검증하는 절차와 보고법을 알려줘".

**공통방법편의 (Common Method Bias)**
- 비유: 한 사람이 모든 문항을 자기보고로 답해 생기는 인공 상관.
- 뜻: 동일 응답원·방법에서 비롯되는 체계적 편향(Harman 단일요인 등).
- 프롬프트: "자기보고 설문이라 **공통방법편의** 점검·통제 방안을 제시해줘".

## 10장. 질적연구 심화 — 의미를 엄밀하게 다루는 단어

**개방·축·선택 코딩 (Open/Axial/Selective Coding)**
- 비유: 원석 고르기→묶기→중심축 세우기.
- 뜻: 근거이론의 3단계 코딩 절차.
- 프롬프트: "이 인터뷰를 **개방→축→선택 코딩** 순서로 범주화해줘".

**지속적 비교법 (Constant Comparison)**
- 비유: 새 사례를 기존 범주와 계속 견주며 다듬기.
- 뜻: 자료-범주를 반복 비교해 개념을 정련하는 방법.
- 프롬프트: "**지속적 비교법**으로 이 범주들의 경계를 재검토해줘".

**신뢰성 4준거 (Trustworthiness)**
- 비유: 질적연구의 '타당도·신뢰도' 대응물.
- 뜻: 신뢰성(credibility)·전이성·의존성·확증성.
- 프롬프트: "이 질적연구의 **신뢰성 4준거** 확보 전략을 각각 제시해줘".

**멤버 체킹 (Member Checking)**
- 비유: 인터뷰 해석을 당사자에게 "이렇게 이해했는데 맞나요?" 확인.
- 뜻: 참여자에게 분석을 검증받아 신뢰성을 높이는 기법.
- 프롬프트: "**멤버 체킹** 절차와 결과를 논문에 서술하는 방법을 알려줘".

**반성성·연구자 위치 (Reflexivity / Positionality)**
- 비유: 연구자 자신의 시선이 결과에 미친 영향을 거울로 비추기.
- 뜻: 연구자의 배경·관점이 연구에 작용함을 성찰·기술.
- 프롬프트: "내 **연구자 위치(positionality)** 진술문을 작성하도록 질문을 던져줘".

**두꺼운 기술 (Thick Description)**
- 비유: 윙크를 '눈 깜빡임'이 아니라 맥락까지 묘사.
- 뜻: 맥락·의미를 풍부히 담아 전이성을 높이는 서술.
- 프롬프트: "이 장면을 **두꺼운 기술**로 맥락까지 살려 다시 써줘".

**주제분석 (Thematic Analysis)**
- 비유: 여러 인터뷰에서 반복되는 '주제 가락'을 뽑아내기.
- 뜻: 자료에서 주제를 식별·정련·보고하는 6단계 분석(Braun&Clarke).
- 프롬프트: "**주제분석 6단계**로 이 자료의 주제를 도출하고 근거 인용을 붙여줘".

**감사 추적 (Audit Trail)**
- 비유: 결론까지의 모든 결정 발자국을 남겨 검증 가능하게.
- 뜻: 분석 과정·결정을 기록해 의존성·확증성을 확보.
- 프롬프트: "이 분석의 **감사 추적**으로 남겨야 할 기록 목록을 만들어줘".

## 11장. 혼합연구 심화 — 양·질을 엮는 단어

**수렴병렬 / 순차 설계 (Convergent / Sequential)**
- 비유: 양·질을 동시에(수렴) 또는 한쪽 먼저-다른쪽 나중(순차).
- 뜻: 혼합연구의 대표 설계(수렴병렬·설명적순차·탐색적순차).
- 프롬프트: "내 연구목적에 맞는 **혼합연구 설계 유형**을 근거로 골라줘".

**통합 / 조인트 디스플레이 (Integration / Joint Display)**
- 비유: 양적 표와 질적 인용을 한 표에 나란히 놓아 대화시키기.
- 뜻: 양·질 결과를 결합해 새 통찰을 만드는 지점·표현.
- 프롬프트: "양적·질적 결과를 **조인트 디스플레이** 표로 통합해줘".

**메타추론 (Meta-inference)**
- 비유: 두 갈래 결과를 합쳐 한 단계 위의 결론을 끌어냄.
- 뜻: 양·질 추론을 통합해 도출하는 상위 결론.
- 프롬프트: "양·질 결과로부터 **메타추론**을 도출하고 한계를 명시해줘".

---

## 12장. 측정·설계 정밀화 — 편향을 잡는 단어

**준실험설계 (Quasi-experimental)**
- 비유: 무선배정은 못 하지만 비교집단은 두는 현실적 실험.
- 뜻: 무선할당 없이 인과를 추정하는 설계(사전사후·비동등집단).
- 프롬프트: "현장 제약상 **준실험설계**로 내적타당도를 높이는 방법을 제안해줘".

**무선할당 (Random Assignment)**
- 비유: 제비뽑기로 집단을 나눠 사전 차이를 상쇄.
- 뜻: 처치집단 배정을 무작위로 해 교란을 통제.
- 프롬프트: "**무선할당**과 무선표집의 차이를 내 연구 맥락으로 설명해줘".

**천장·바닥 효과 (Ceiling / Floor Effect)**
- 비유: 시험이 너무 쉬워 다 만점(천장), 너무 어려워 다 0점(바닥).
- 뜻: 측정 범위 한계로 변별이 안 되는 현상.
- 프롬프트: "이 척도에 **천장/바닥 효과**가 있는지 분포로 점검해줘".

**사회적 바람직성 편향 (Social Desirability Bias)**
- 비유: 설문에서 '착하게 보이려' 답하는 경향.
- 뜻: 응답자가 바람직해 보이려 왜곡 응답하는 편향.
- 프롬프트: "이 문항의 **사회적 바람직성 편향**을 줄이는 문구·설계를 제안해줘".

**역문항 (Reverse-coded Item)**
- 비유: 일부 문항을 일부러 반대로 물어 무성의 응답을 거르기.
- 뜻: 의미를 역으로 진술해 응답 일관성을 점검하는 문항(분석 시 역코딩).
- 프롬프트: "이 척도에 **역문항**을 넣고, 분석 전 역코딩 방법을 알려줘".

## 13장. AI·프롬프트 심화 — 출력을 통제하는 단어

**제약 명시 (Constraint Specification)**
- 비유: "300자 이내, 표로, 출처 포함"처럼 조건을 못 박기.
- 뜻: 분량·형식·범위·금지사항을 명시해 출력을 통제.
- 프롬프트: "**제약: 500자, APA 인용, 추측 금지**로 이 결과를 서술해줘".

**출력 형식 지정 (Output Formatting)**
- 비유: 답을 '표/번호목록/JSON'처럼 원하는 그릇에 담게 하기.
- 뜻: 결과 구조를 미리 지정해 재사용성을 높임.
- 프롬프트: "결과를 **'변수·정의·측정문항' 3열 표**로만 출력해줘".

**자기검증 / 자기비판 (Self-critique)**
- 비유: AI에게 "네 답을 스스로 채점하고 약점을 말해봐".
- 뜻: 생성 후 자기 점검·반박을 시켜 품질을 높이는 기법.
- 프롬프트: "위 답을 **스스로 비판**하고 더 정확한 버전으로 고쳐줘".

**프롬프트 체이닝 (Prompt Chaining)**
- 비유: 한 번에 다 시키지 말고 단계로 끊어 이어가기.
- 뜻: 작업을 여러 프롬프트로 분할·연결해 정확도를 높임.
- 프롬프트: "이 분석을 ①설계→②코드→③해석 **단계로 나눠** 진행하자".

**메타프롬프트 (Meta-prompting)**
- 비유: "좋은 질문을 네가 먼저 만들어줘"라고 시키기.
- 뜻: AI에게 프롬프트 자체를 설계·개선하게 하는 기법.
- 프롬프트: "이 연구를 잘 분석할 **프롬프트를 네가 먼저 설계**해줘".

**근거표시 요구 (Grounding / Citation)**
- 비유: 모든 주장에 '출처 영수증'을 붙이게 하기.
- 뜻: 자료 근거·출처를 표기하게 해 환각을 억제.
- 프롬프트: "각 주장에 **업로드 문서의 근거 위치**를 표기하고, 없으면 '근거 없음'이라 말해줘".

**컨텍스트 윈도우 / 온도 (Context Window / Temperature)**
- 비유: 한 번에 읽을 수 있는 분량(창)과 답의 보수성↔창의성 다이얼.
- 뜻: 입력 한도와 무작위성 조절 파라미터.
- 프롬프트: "긴 논문이라 **컨텍스트 한계**를 고려해 분할 요약 전략을 짜줘".
