# P-3 RCTF 프롬프트 — 제3장 프롬프트 패키지

> 연결 장: 제3장 RCTF 프롬프트 · 워크북: [W-1](../workbook/W1_연구출발점과도구스택.md) · 부록: [A](../appendix/A_자주쓰는프롬프트30종.md)
> 사용법: 복사 → [대괄호] 교체 → 실행 → 검증 프롬프트로 재확인
> 골격 먼저: [RCTF 기본골격](RCTF_기본골격.md)

---

## 언제 쓰나

- 기존 프롬프트가 AI에게 Task만 던지고 Role·Context·Format이 빠져 있을 때
- ChatGPT·Claude·Gemini 각 도구의 특성에 맞게 프롬프트를 따로 최적화하고 싶을 때
- AI가 내놓은 초안에 출처 없는 단정·과장·추정이 섞여 있는지 검증하고 싶을 때
- 복잡한 논문 과업(문헌 비교 → 갭 진술 → Discussion 초안)을 체이닝으로 단계 분해할 때

---

## 프롬프트 1 — 나쁜 프롬프트 RCTF 개선

무엇을 얻나: 막연하게 작성된 기존 프롬프트를 RCTF 4요소로 진단·재작성한 개선 프롬프트 3종(ChatGPT·Claude·Gemini)과 검증 프롬프트 1종.

```text
[R] 당신은 학위논문 작성을 지도하는 연구방법론 전문가다.
[C] 나는 [연구주제]를 연구하는 대학원생이며, [자료 설명: 예) 첨부 PDF 5편 / 수집된 설문 데이터 등]을 갖고 있다. 최종 산출물은 [산출물: 예) 문헌 비교표 / Discussion 초안 등]이다.
[T] 내가 현재 사용하는 프롬프트는 다음과 같다:
"""
[현재 프롬프트 전문을 여기에 붙여넣기]
"""
이 프롬프트의 문제점을 Role·Context·Task·Format 4축으로 각각 진단하고, ChatGPT용·Claude용·Gemini용으로 각각 RCTF 구조에 맞게 다시 작성하라.
[F] 진단 결과는 4행 표(요소|기존 상태|문제|개선 방향)로, 재작성 프롬프트 3종은 각 도구별 코드블록으로 출력하라. 한국어 학술체, 전체 1,200자 이내.
---
할루시네이션 방지 조건:
- 출처 없는 단정 금지. 근거가 있을 때만 단정 표현 사용.
- 불확실한 내용은 [확인 필요]로 표시.
- 모르거나 추정인 부분은 "추정:" 을 앞에 붙여 구분.
- 위 답변을 작성한 뒤, 사실 여부를 한 번 더 자기검증하라.
```

입력 예시:
- `[연구주제]` → `중소기업 AI 도입이 매출에 미치는 영향`
- `[자료 설명]` → `관련 국내외 논문 5편 PDF`
- `[산출물]` → `선행연구 비교표 및 연구 갭 진술`
- `[현재 프롬프트]` → `이 논문들 비교해줘`

기대 출력(요약): 4행 진단표(Role 없음 / Context 부재 / Task 불명확 / Format 미지정)와 ChatGPT·Claude·Gemini 각각의 RCTF 개선 프롬프트 3종.

검증 프롬프트:

```text
방금 제안한 개선 프롬프트 3종에서 원문 근거가 부족하거나 과장된 부분을 찾아라. 추정으로 작성한 문장은 [추정]이라고 표시하고, 학위논문에 그대로 쓰면 위험한 문장을 따로 분리하라.
```

## 프롬프트 2 — 도구별(ChatGPT / Claude / Gemini) 특화 변환

무엇을 얻나: 동일한 연구 과업을 세 도구의 특성에 맞춰 각각 최적화한 RCTF 프롬프트.

```text
[R] 당신은 ChatGPT·Claude·Gemini의 특성 차이를 실무적으로 잘 아는 AI 활용 컨설턴트다.
[C] 내 연구주제는 [연구주제]이고, 수행하려는 과업은 [과업: 예) 선행연구 5편의 방법론 비교표 작성]이다. 각 도구의 특성은 다음과 같이 전제한다:
- ChatGPT: 긴 대화 맥락 유지, 단계별 지시에 강함, GPTs 연동 가능
- Claude: 장문 PDF 분석·구조적 요약에 강함, 사고 과정(thinking) 활성화 가능
- Gemini: Google 학술 자료 연계, 최신 검색 통합 가능
[T] 위 과업을 수행하기 위한 RCTF 구조 프롬프트를 ChatGPT용·Claude용·Gemini용으로 각각 따로 작성하라. 각 도구의 장점을 살리되, 동일한 산출물([산출물 형식: 예) 마크다운 비교표 + 200자 갭 진술])을 목표로 한다.
[F] 도구별 프롬프트를 각각 코드블록으로 구분 출력. 각 블록 상단에 "이 도구로 이 과업을 쓰는 이유" 1문장 포함. 한국어 학술체.
---
할루시네이션 방지 조건:
- 도구별 특성 설명은 위에 명시한 전제 범위 안에서만 기술. 범위를 벗어난 주장은 [확인 필요]로 표시.
- 출처 없는 도구 성능 비교 단정 금지.
- 답변 후 자기검증: 세 프롬프트 중 과업과 맥락이 충분히 연결되지 않은 항목이 있다면 스스로 지적하라.
```

입력 예시:
- `[연구주제]` → `고령 근로자의 디지털 역량 개발과 직무 만족도의 관계`
- `[과업]` → `선행연구 5편의 연구설계·표본·측정변수·한계를 4열 비교표로 정리`
- `[산출물 형식]` → `마크다운 4열 표 + 200자 연구 갭 진술`

기대 출력(요약): ChatGPT용(단계별 지시 체이닝 활용), Claude용(PDF 첨부 및 구조적 분석 강화), Gemini용(최신 자료 검색 연계) 각 1종, 각 블록에 선택 근거 1문장 포함.

검증 프롬프트:

```text
방금 제시한 ChatGPT·Claude·Gemini 각 프롬프트에서 해당 도구로 실제 실행했을 때 오류나 제한이 발생할 수 있는 부분을 진단하라. 문제가 예상되는 항목마다 [주의] 표시와 수정 제안을 함께 제시하라.
```

## 프롬프트 3 — 만능 검증 프롬프트(받은 답 자기검증)

무엇을 얻나: AI가 생성한 모든 초안에 적용 가능한 할루시네이션 탐지·자기검증 프롬프트.

```text
[R] 당신은 학위논문 심사를 앞두고 초안을 점검하는 비판적 심사위원이다.
[C] 아래는 내가 AI에게 [과업: 예) 선행연구 비교 / Discussion 초안 작성 등]을 요청해 받은 결과물이다:
"""
[AI가 출력한 결과물 전문을 여기에 붙여넣기]
"""
내 연구주제는 [연구주제]이고, 이 결과물은 [최종 사용 목적: 예) 논문 2장 선행연구 섹션]에 사용될 예정이다.
[T] 위 결과물을 다음 5개 기준으로 검증하라:
① 출처가 명시되지 않은 명제·수치를 모두 열거하고 [출처 없음]으로 표시
② 원문 근거보다 과장되거나 확대 해석된 문장을 찾아 [과장]으로 표시
③ 추정·가정으로 작성된 문장을 찾아 [추정]으로 표시
④ 학위논문에 그대로 쓰면 위험한 문장(사실 오류 가능성, 윤리 문제 등)을 따로 분리
⑤ 이 결과물의 전반적인 신뢰도를 상/중/하로 평가하고 이유 3줄 이내로 제시
[F] 각 기준별 결과를 번호 목록으로 출력. 위험 문장은 빨간 텍스트 대신 ⚠️ 기호로 표시. 한국어 학술체, 전체 800자 이내.
---
할루시네이션 방지 조건:
- 검증 자체에서도 추정이 포함되면 [추정]으로 표시.
- 확신할 수 없는 판단은 "가능성 있음:" 형태로 표현.
- 검증 완료 후, 이 검증 결과 자체의 한계 1문장을 마지막에 추가하라.
```

입력 예시:
- `[과업]` → `선행연구 비교 및 연구 갭 식별`
- `[AI 결과물]` → 이전 턴에서 Claude가 출력한 비교표 전문
- `[연구주제]` → `청소년 SNS 사용 시간이 학업 성취에 미치는 영향`
- `[최종 사용 목적]` → `석사학위논문 2장 선행연구 검토 섹션`

기대 출력(요약): 5개 기준별 검증 결과 목록, ※ 위험 문장 분리 목록, 신뢰도 상/중/하 평가 및 이유, 검증 결과 자체의 한계 1문장.

검증 프롬프트:

```text
위 검증 결과에서 내가 원본 자료를 직접 확인해야 하는 항목만 추려서, 확인 방법(어떤 데이터베이스에서 어떻게 검색할지)까지 함께 제시하라.
```

---

## ✓ 연구자 체크

- [ ] 프롬프트를 전송하기 전, Role·Context·Task·Format 4요소가 모두 들어 있는지 확인했다
- [ ] Context에 연구주제·자료 범위·학위 과정을 구체적으로 명시했다
- [ ] Task가 "동사 + 명사 + 수량" 형태로 구체화되어 있다 (예: "5편을 4열 표로 비교하라")
- [ ] Format에 언어·길이·구조(표/목록/문단)가 명시되어 있다
- [ ] 모든 프롬프트 끝에 할루시네이션 방지 5계명 중 관련 조건을 붙였다
- [ ] AI 초안을 받은 뒤 검증 프롬프트로 한 번 더 걸렀다

---

## ※ 흔한 실패 패턴

| 증상 | 원인 | 처방 |
|---|---|---|
| AI 출력이 너무 일반적이고 내 연구와 무관하다 | Context 부재 — 연구주제·자료 범위를 프롬프트에 넣지 않음 | Context 블록에 연구주제, 자료 설명, 학위 단계를 2~3문장으로 추가 |
| 출처 없는 논문 제목·저자·수치가 섞여 있다 | 할루시네이션 방지 조건 미적용 | 모든 프롬프트 끝에 "출처 없는 명제는 [출처 없음]으로 표시하라" 추가 |
| 한 프롬프트에 너무 많은 과업을 담아 결과가 산만하다 | Task 과적재 — 체이닝 미적용 | 과업을 3단계(비교표 → 갭 진술 → 초안)로 쪼개 멀티턴 체이닝으로 순서대로 실행 |
