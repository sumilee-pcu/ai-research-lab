# P-11 결과 해석 — 제11장 프롬프트 패키지

> 연결 장: 제11장 결과 해석과 논의 · 워크북: [W-7](../workbook/W7_결과해석과글쓰기윤리.md)
> 사용법: 복사 → [대괄호] 교체 → 실행 → 검증 프롬프트로 재확인

---

## 언제 쓰나

분석이 끝났고 수치·표·그림이 손에 있지만, **그것이 무엇을 의미하는지 글로 써야 할 때** 이 패키지를 꺼낸다.

| 상황 | 권장 프롬프트 |
|------|-------------|
| Results와 Discussion을 한 번에 초안 작성 | P-1 (핵심 통합) |
| 연구의 한계를 솔직하게 정리해야 할 때 | P-2 (한계 도출) |
| 심사 전 반박 질문을 미리 예행연습하고 싶을 때 | P-3 (심사위원 시뮬레이션) |

**핵심 원칙 — 이 세 가지를 항상 기억하라**

- **상관관계 ≠ 인과관계**: 통계적 연관이 있다고 해서 원인이 되지 않는다. "A가 B를 증가시켰다" → "A와 B 사이에 유의한 정적 관계가 관찰되었다"로 교체하라.
- **과장 금지**: "최초", "혁신적", "매우 중요한" 같은 수식어는 근거가 명확할 때만 허용한다.
- **결과를 넘어선 주장 금지**: 데이터가 뒷받침하지 않는 결론은 쓰지 않는다.

---

## 프롬프트 1 — Results / Discussion 분리 초안 (핵심)

**무엇을 얻나:** 한 번의 입력으로 Results(사실·수치·표 설명)와 Discussion(해석·함의·한계·향후 연구) 초안을 분리하여 받는다. Discussion은 5단 구조(핵심 요약 → 선행연구 비교 → 의미·함의 → 한계 → 향후 연구)로 자동 구성된다.

```text
아래 연구결과를 Results와 Discussion으로 분리해 작성하라.

[연구 정보]
- 연구주제: [예: 중소기업 ESG 공시 수준이 투자 유치에 미치는 영향]
- 연구질문(RQ): [예: ESG 공시 수준은 벤처투자 유치 금액과 유의한 관계가 있는가?]
- 분석방법: [예: 다중회귀분석, n=312, SPSS 26]
- 주요 결과: [예: ESG 총점(β=0.31, p<.001), 환경 항목(β=0.22, p=.004)이 유의, 사회 항목은 비유의]

[작성 지침]
Results:
- 관찰된 사실, 통계값, 표·그림 설명만 포함한다.
- 해석·평가어를 쓰지 않는다.
- 시제는 과거형(~이었다, ~으로 나타났다)을 사용한다.

Discussion (5단 구조):
① 핵심 결과 요약 (200자): Results의 정수를 한 문단으로
② 기존 연구와 비교 (400자): 선행연구와 일치하는 점·차이나는 점·그 이유 추론
③ 의미와 함의 (400자): 학술적 함의 / 실무적 함의를 분리해 작성
④ 한계 (300자): 본 연구가 하지 못한 것 5가지를 솔직하게 기술
⑤ 향후 연구 (200자): 후속 연구 방향 3가지

[필수 제약]
- 상관관계를 인과로 해석하지 마라.
- "최초", "혁신적", "매우 중요한" 등 근거 없는 과장 표현을 피하라.
- 데이터가 뒷받침하지 않는 주장은 [근거 부족 — 삭제 또는 완화 필요]로 표시하라.
- 마지막에 사업화 임팩트 미니 섹션 1문단(150-200자)을 추가하라.
```

**입력 예시:**
- 연구주제: 비대면 학습 환경에서 AI 튜터 피드백 빈도가 학습 몰입도에 미치는 영향
- RQ: AI 튜터 피드백 빈도는 대학생의 학습 몰입도(flow)와 유의한 관계가 있는가?
- 분석방법: 구조방정식모형(SEM), n=218, AMOS 26
- 주요 결과: 피드백 빈도 → 학습 몰입도 경로계수 β=0.44(p<.001), 설명력 R²=0.29

**기대 출력(요약):**
- Results: 경로계수·유의확률·R² 수치를 평가어 없이 기술한 1~2문단
- Discussion: 5단 구조 1,500자 초안, 과장 표현 없음, 사업화 미니 섹션 포함

**검증 프롬프트:**

```text
위에서 작성된 Results와 Discussion 초안을 다시 검토하라.

1. Results 섹션에 해석·평가어·함의가 섞여 있으면 해당 문장을 찾아 표시하고 수정안을 제시하라.
2. Discussion 섹션에서 데이터 근거 없이 인과관계를 주장하는 문장을 찾아 표시하라.
3. 과장된 수식어("최초", "혁신적", "매우 중요한" 등)가 있으면 모두 찾아 대안 표현을 제안하라.
4. Discussion 5단 구조 중 빠진 단계가 있으면 알려라.
```

## 프롬프트 2 — 한계(Limitation) 도출

**무엇을 얻나:** 연구의 약점을 학술적으로 솔직하게 5가지 정리하되, 각 한계를 "향후 연구의 출발점"으로 프레이밍하여 논문 신뢰도를 높인다.

```text
아래 연구의 한계를 학술적으로 솔직하게 5가지 작성하라.

[연구 요약]
- 연구주제: [연구주제]
- 분석방법: [방법, 표본 크기, 데이터 수집 기간·방법]
- 주요 결과: [핵심 결과 1~3줄]

[작성 지침]
- 각 한계를 한 문단(2~3문장)으로 작성한다.
- 문단 구조: (1) 한계 사실 기술 → (2) 그로 인한 연구의 제약 → (3) 향후 연구에서 극복 가능한 방향 제시
- "이 연구는 ~하지 못했다"는 표현을 "후속 연구에서는 ~을 통해 보완될 수 있다"는 긍정적 프레이밍으로 마무리하라.
- 표본 대표성, 측정 도구, 연구 시기, 교란변수, 일반화 가능성 중 해당 사항을 포함하라.
- 과도하게 약점을 부각하거나 연구 가치를 스스로 깎아내리는 표현은 피하라.
```

**입력 예시:**
- 연구주제: 소상공인 디지털 전환 지원 정책 효과 분석
- 분석방법: 설문조사, n=180, 서울·경기 지역 소상공인만 대상, 2024년 3~4월
- 주요 결과: 정부 지원금 수혜 경험이 디지털 전환 의도(β=0.38, p<.001)에 유의한 영향

**기대 출력(요약):**
표본의 지역 편향, 횡단 설계의 인과 추론 한계, 자기보고 편향, 단기 관찰 한계, 정책 외 요인 미통제 — 각각 2~3문장으로, 향후 연구 방향으로 마무리된 5문단

**검증 프롬프트:**

```text
위에서 작성된 한계 5가지를 검토하라.

1. 연구에서 실제로 확인된 한계인가, 아니면 추측인가? 추측이라면 표시하라.
2. 향후 연구 제언이 지나치게 막연하거나("더 많은 연구가 필요하다") 실행 불가능한 내용이 있으면 구체화하라.
3. 연구의 핵심 강점을 불필요하게 부정하는 표현이 있으면 수정하라.
4. 한계 5가지가 서로 중복되지 않고 독립적인지 확인하라.
```

## 프롬프트 3 — 심사위원 반박 질문 5개 + 보강 자료 목록

**무엇을 얻나:** 박사과정 심사위원이 던질 법한 반박 질문 5개와, 각 질문에 답하기 위해 준비해야 할 문헌·데이터·추가 분석 목록을 미리 받는다.

```text
내 연구에 가장 강력하게 반대할 수 있는 심사위원의 입장에서, 아래 연구에 대한 반박 질문 5개를 만들어라.

[연구 요약]
- 연구주제: [연구주제]
- RQ: [연구질문]
- 분석방법: [방법]
- 핵심 주장(결론): [핵심 결론 1~3문장]

[작성 지침]
각 질문에 대해 다음을 함께 작성하라:
① 반박 질문 (심사위원 어투로)
② 예상 답변 초안 (연구자 입장에서, 2~3문장)
③ 보강 필요 자료 (이 질문에 답하기 위해 추가로 준비해야 할 선행연구 · 데이터 · 분석)

질문 유형을 다양하게 구성하라:
- 방법론 타당성 ("왜 이 방법을 선택했나?")
- 표본 대표성 ("이 표본이 모집단을 대표하는가?")
- 인과관계 해석 ("상관관계를 인과로 해석하는 것 아닌가?")
- 비교 기준 ("기존 연구 대비 차별점이 무엇인가?")
- 실용적 한계 ("현실에서 적용 가능한가?")
```

**입력 예시:**
- 연구주제: 딥러닝 기반 감성분석 모델의 주가 예측 적용 가능성
- RQ: BERT 기반 뉴스 감성분석 점수가 단기 주가 변동 예측에 유의한가?
- 분석방법: BERT fine-tuning + 시계열 회귀, 코스닥 50개 종목, 2023년 1~12월
- 핵심 주장: 감성 점수가 다음 날 수익률 예측에 유의한 기여(RMSE 개선 12%)

**기대 출력(요약):**
5쌍의 (반박 질문 + 예상 답변 초안 + 보강 자료 목록), 인과관계 질문·데이터 누수(look-ahead bias) 질문·일반화 질문 포함

**검증 프롬프트:**

```text
위에서 만들어진 반박 질문 5개를 검토하라.

1. 질문 유형이 방법론·표본·인과·비교·실용성으로 고르게 분산되어 있는가?
2. 예상 답변 초안이 질문을 실질적으로 반박하고 있는가, 아니면 회피하고 있는가?
3. 보강 자료 목록 중 실제로 존재할 가능성이 낮거나 할루시네이션 위험이 있는 항목이 있으면 표시하라.
4. 내 연구의 실제 약점 중 이 5개 질문이 놓친 것이 있으면 추가하라.
```

## ✅ 연구자 체크

프롬프트 실행 후 결과물을 저장하기 전에 아래 항목을 직접 확인하라.

- [ ] **상관 ≠ 인과**: "~이 ~를 증가시켰다" → "~와 ~사이에 유의한 관계가 관찰되었다"로 교체했는가?
- [ ] **과장 금지**: "최초", "혁신적", "매우 중요한", "획기적" 등의 표현에 근거가 있는가?
- [ ] **결과를 넘어선 주장 금지**: 데이터에 없는 집단·시기·상황으로 결과를 확대 해석하지 않았는가?
- [ ] **Results 오염 없음**: Results 섹션에 "이는 ~을 시사한다" 같은 해석 문장이 섞이지 않았는가?
- [ ] **Discussion 반복 없음**: Discussion이 Results의 수치를 그대로 나열하는 데 그치지 않고 해석·비교·함의를 담고 있는가?
- [ ] **할루시네이션 확인**: AI가 제시한 선행연구 인용(저자명·연도·제목)을 Google Scholar 또는 RISS에서 실제 확인했는가?

## ⚠️ 흔한 실패 패턴

| 실패 패턴 | 예시 | 올바른 대안 |
|----------|------|-----------|
| Results에 해석 혼입 | "이는 소셜 미디어 노출이 구매 의도를 높임을 보여준다" | "소셜 미디어 노출과 구매 의도 사이에 유의한 정적 관계가 나타났다(β=0.34, p<.01)" |
| Discussion이 Results 반복 | "분석 결과 변수 A는 유의했고, 변수 B는 비유의하였다…" | 선행연구와 비교, 차이 이유 추론, 함의 도출로 진전 |
| AI 생성 과장 표현 무비판 수용 | "본 연구는 최초로 이 분야의 혁신적 해결책을 제시하였다" | 근거 없으면 삭제, 근거 있으면 구체적 출처·비교 기준 명시 |
