## 프롬프트 1 — 분석 코드 생성(핵심, 주석 포함 Python)

무엇을 얻나: 데이터 구조 확인부터 APA 결과표·그래프 저장·결과 해석 문단까지 순서대로 실행 가능한 Python 스크립트 한 파일

```text
너는 시니어 데이터 과학자이자 통계 컨설턴트다.
첨부 데이터(또는 아래 설명)로 가설 [가설]을 검증하는 Python 분석 코드를 작성하라.
독립변수 [X], 종속변수 [Y], 통제변수 [C].
데이터 구조: 행은 [분석 단위], 열은 [변수 설명]이다.

아래 순서대로 코드를 작성하라. 각 단계마다 한국어 주석을 달아라.

1. 라이브러리 import 및 시드 설정(random.seed(42), np.random.seed(42))
2. 데이터 로드 및 구조 확인(shape, dtypes, head)
3. 결측치 확인(isnull 비율, 히트맵)
4. 기술통계(연속형 변수: 평균·SD·왜도·첨도·95% CI, APA 마크다운 표)
5. 신뢰도 분석(Cronbach α — pingouin 사용)
6. 통계 전제 검정(정규성: Shapiro-Wilk + Q-Q plot, 등분산성: Levene, 다중공선성: VIF)
7. 주 분석([분석 방법: t-test / ANOVA / 회귀분석])
8. 효과크기(Cohen's d / eta squared / Cohen's f² 중 해당 항목)
9. APA 양식 결과표 생성 및 CSV 저장
10. 그래프 생성 및 PNG 저장(dpi=300)
11. 결과 해석 문단 초안(통계적 의미 + 실무적 의미 구분)

실제 데이터를 보지 못했다면 수치를 만들지 말고,

```

기대 출력(요약):

## 프롬프트 2 — APA 결과표 생성


## 코드 예시 — 분석 파이프라인(바이브코딩 시범)

아래는 P-1 프롬프트로 생성된 코드의 예시 구조다. 그대로 실행하려면 `survey_data.csv`와 변수명을 실제 데이터에 맞게 교체하라.

```python
# ============================================================
# P-9 분석 파이프라인 시범 코드
# 가설: AI 활용 수준(ai_use)이 생산성 인식(productivity)에 영향을 미친다
# 실제 데이터 없음 → 변수명 매핑은 [연구자 확인 필요]
# ============================================================

import random
import numpy as np
import pandas as pd
import scipy.stats as stats
import statsmodels.api as sm
import statsmodels.formula.api as smf
import matplotlib.pyplot as plt
import seaborn as sns
import warnings
warnings.filterwarnings('ignore')

# 재현성 시드 고정
random.seed(42)
np.random.seed(42)

# ----------------------------------------------------------
# STEP 1. 데이터 로드 및 구조 확인
# ----------------------------------------------------------
df = pd.read_csv('./data/survey_data.csv', encoding='utf-8-sig')
print("Shape:", df.shape)
print(df.dtypes)
print(df.head(3))

# ----------------------------------------------------------
# STEP 2. 결측치 확인
# ----------------------------------------------------------
missing = df.isnull().mean().round(3) * 100
print("\n결측치 비율(%):\n", missing[missing > 0])
# [연구자 확인 필요] 결측치 10% 초과 변수는 제외 또는 다중 대체 검토

# ----------------------------------------------------------
# STEP 3. 복합 변수 합산 (리커트 문항 평균)
# ----------------------------------------------------------
ai_cols = ['ai_use_1', 'ai_use_2', 'ai_use_3', 'ai_use_4']
prod_cols = ['productivity_1', 'productivity_2', 'productivity_3']
df['ai_use'] = df[ai_cols].mean(axis=1)
df['productivity'] = df[prod_cols].mean(axis=1)

# ----------------------------------------------------------
# STEP 4. 기술통계 (APA 마크다운 표)
# ----------------------------------------------------------
cont_vars = ['ai_use', 'productivity', 'age']
desc = df[cont_vars].agg(['mean', 'std', 'skew']).T
desc.columns = ['M', 'SD', 'Skewness']
desc['Kurtosis'] = df[cont_vars].kurtosis()
print("\n기술통계:\n", desc.round(2).to_markdown())

# ----------------------------------------------------------
# STEP 5. 신뢰도 분석 (Cronbach α)
# ----------------------------------------------------------
try:
    import pingouin as pg
    alpha_ai = pg.cronbach_alpha(data=df[ai_cols])[0]
    alpha_prod = pg.cronbach_alpha(data=df[prod_cols])[0]
    print(f"\nCronbach α — ai_use: {alpha_ai:.3f}, productivity: {alpha_prod:.3f}")
    # [연구자 확인 필요] α < .70이면 척도 문항 재검토
except ImportError:
    print("pingouin 미설치: pip install pingouin")

# ----------------------------------------------------------
# STEP 6. 통계 전제 검정
# ----------------------------------------------------------
# 6-1. 정규성 (Shapiro-Wilk, n < 5000 권장)
for var in ['ai_use', 'productivity']:
    stat, p = stats.shapiro(df[var].dropna())
    print(f"Shapiro-Wilk {var}: W={stat:.3f}, p={p:.3f}")
    # [연구자 확인 필요] p < .05이면 왜도·첨도·Q-Q plot 함께 판단

# 6-2. Q-Q plot
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
for ax, var in zip(axes, ['ai_use', 'productivity']):
    stats.probplot(df[var].dropna(), plot=ax)
    ax.set_title(f'Q-Q plot: {var}')
plt.tight_layout()
plt.savefig('./output/qq_plot.png', dpi=300)
plt.close()

# 6-3. 다중공선성 VIF
from statsmodels.stats.outliers_influence import variance_inflation_factor
X_vif = df[['ai_use', 'age', 'gender']].dropna()
X_vif = sm.add_constant(X_vif)
vif_df = pd.DataFrame({
    'Variable': X_vif.columns,
    'VIF': [variance_inflation_factor(X_vif.values, i) for i in range(X_vif.shape[1])]
})
print("\nVIF:\n", vif_df)
# [연구자 확인 필요] VIF > 10이면 다중공선성 문제 검토

# ----------------------------------------------------------
# STEP 7. 주 분석 — 다중회귀분석
# ----------------------------------------------------------
df_clean = df[['productivity', 'ai_use', 'age', 'gender']].dropna()
model = smf.ols('productivity ~ ai_use + age + gender', data=df_clean).fit()
print("\n회귀분석 결과:\n", model.summary())

# ----------------------------------------------------------
# STEP 8. 효과크기 (Cohen's f²)
# ----------------------------------------------------------
r_sq = model.rsquared
cohens_f2 = r_sq / (1 - r_sq)
print(f"\nCohen's f² = {cohens_f2:.3f}  (소: .02, 중: .15, 대: .35)")

# ----------------------------------------------------------
# STEP 9. APA 결과표 생성 및 CSV 저장
# ----------------------------------------------------------
coef_df = pd.DataFrame({
    'Variable': model.params.index,
    'B': model.params.values.round(3),
    'SE': model.bse.values.round(3),
    't': model.tvalues.values.round(3),
    'p': model.pvalues.values.round(3),
    '95% CI Lower': model.conf_int()[0].values.round(3),
    '95% CI Upper': model.conf_int()[1].values.round(3),
})
print("\nAPA 결과표:\n", coef_df.to_markdown(index=False))
coef_df.to_csv('./output/apa_results.csv', index=False, encoding='utf-8-sig')

# ----------------------------------------------------------
# STEP 10. 그래프 저장
# ----------------------------------------------------------
plt.figure(figsize=(6, 5))
sns.regplot(x='ai_use', y='productivity', data=df_clean, scatter_kws={'alpha': 0.4})
plt.xlabel('AI 활용 수준 (ai_use)')
plt.ylabel('생산성 인식 (productivity)')
plt.title('AI 활용 수준 → 생산성 인식 회귀선')
plt.tight_layout()
plt.savefig('./output/scatter_ai_productivity.png', dpi=300)
plt.close()

# 잔차 진단
fig, ax = plt.subplots(figsize=(6, 4))
ax.scatter(model.fittedvalues, model.resid, alpha=0.4)
ax.axhline(0, color='red', linestyle='--')
ax.set_xlabel('예측값')
ax.set_ylabel('잔차')
ax.set_title('잔차 산점도')
plt.tight_layout()
plt.savefig('./output/residual_plot.png', dpi=300)
plt.close()

# ----------------------------------------------------------
# STEP 11. 결과 해석 문단 초안 요청 (Claude에게 전달용 메모)
# ----------------------------------------------------------
print("""
```

## 연구자 체크

데이터 미확인 시 수치 환각 경고

AI는 데이터를 직접 보지 못한 경우 그럴듯한 수치를 만들어 낼 수 있다. 프롬프트에 "실제 데이터를 보지 못했다면 수치를 생성하지 말라"는 문장을 반드시 포함하고, 출력된 수치가 자신의 데이터에서 나온 것인지 반드시 대조 확인하라.

p값 과대해석 경고

p < .001이 "매우 강한 효과"를 의미하지 않는다. 표본이 크면 사소한 차이도 통계적으로 유의해진다. 다음 세 가지를 함께 보고해야 한다.

| 보고 항목 | 확인 방법 |
|---|---|
| 효과크기 | Cohen's d, η², f², r 중 해당 값 |
| 95% 신뢰구간 | CI가 0을 포함하는지 확인 |
| 실무적 의미 | 해당 분야의 선행 연구와 비교 |
