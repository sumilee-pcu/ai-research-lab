# P-2 도구 선택 — 제2장 프롬프트 패키지

> 연결 장: 제2장 AI 도구 지형도 · 워크북: [W-1](../workbook/W1_연구출발점과도구스택.md) · 부록: [B](../appendix/B_AI도구요금제정책.md)·[부속 가](../appendix/부속자료_가_AI도구비교표.md)
> 사용법: 복사 → [대괄호] 교체 → 실행 → 검증 프롬프트로 재확인

---

## 언제 쓰나

- 새 연구 과제를 시작할 때, 어느 AI 도구로 첫 삽을 떠야 할지 결정이 서지 않을 때
- 익숙한 도구 하나만 반복 사용하다가 산출물 품질이 정체됐다고 느낄 때
- 유료 요금제 결제 전에 내 작업이 해당 도구의 강점 영역과 겹치는지 따져보고 싶을 때
- 중요한 산출물을 두 도구로 교차 검증하여 신뢰도를 높이고 싶을 때

---

## 프롬프트 1. 작업별 도구 추천

무엇을 얻나: 특정 작업과 연구주제에 맞는 AI 도구 비교표, 1순위·2순위 추천, 각 도구용 프롬프트 초안을 한 번에 확보한다.

```text
## 역할(Role)
너는 학술 연구자의 AI 도구 활용 전략 컨설턴트다.

## 맥락(Context)
나는 [작업명 — 예: 선행연구 20편 요약, 통계 분석 코드 초안 작성, 키워드 트렌드 리포트 작성]을 수행해야 한다.
- 연구주제: [주제 — 예: 국내 청소년 디지털 리터러시 격차]
- 입력 자료: [자료 유형 및 분량 — 예: PDF 논문 15편, 약 200쪽]
- 원하는 산출물: [산출물 형태·분량 — 예: A4 2쪽 분량의 주제별 요약 노트]

## 과제(Task)
위 작업을 ChatGPT·Claude·Gemini·Perplexity·NotebookLM·SciSpace·Zotero·Python/Cursor·시각화 도구(Napkin AI·Flourish 등) 중 어디에 맡길지 비교하라.
다음 형식의 비교표를 작성하라:

| 도구 | 이 작업에서의 강점 | 한계 | AI가 처리할 부분 | 연구자가 검증할 부분 |

표 아래에 다음 내용을 추가하라:
1. 1순위 추천 도구와 선택 근거 (2~3문장)
2. 2순위 교차검증 도구와 활용 방식
3. 1순위·2순위 각각에 바로 붙여 넣을 수 있는 프롬프트 초안

## 형식(Format)
- 비교 대상은 이 작업과 관련성이 높은 도구 4~6종으로 좁혀서 제시하라 (전체 나열 금지)
- 표는 마크다운 형식으로 작성하라
- 각 셀은 1~2문장 이내로 작성하라
- 확실하지 않은 도구 기능은 "[확인 필요]"로 표시하고, 모르는 정보는 모른다고 밝혀라
- 답변 마지막에 이 추천의 전제 가정 2개와, 그 가정이 틀렸을 때 선택이 어떻게 달라지는지 서술하라
```

입력 예시:
- 작업명: 선행연구 15편 요약
- 연구주제: 국내 청소년 디지털 리터러시 격차
- 입력 자료: PDF 논문 15편(약 200쪽)
- 산출물: A4 2쪽 분량 주제별 요약 노트

기대 출력(요약): 도구 4~5종에 대한 강점·한계 비교표, 1순위(예: Claude)와 2순위(예: NotebookLM) 추천 및 근거, 각 도구에 바로 붙여 넣을 수 있는 프롬프트 초안 2종.

검증 프롬프트:

```text
방금 추천한 도구 선택에서 가장 취약한 전제 가정은 무엇인가?
그 가정이 틀렸을 경우 1순위와 2순위가 어떻게 바뀌는지 설명하라.
확신할 수 없는 부분은 "[확인 필요]"로 표시하라.
```

## 프롬프트 2. 두 도구 교차검증

무엇을 얻나: 두 도구로 같은 작업을 수행한 결과를 체계적으로 대조하여, 어느 부분을 신뢰하고 어느 부분을 추가 확인해야 하는지 판단 기준을 확보한다.

```text
## 역할(Role)
너는 AI 산출물의 신뢰성을 평가하는 학술 연구 검토자다.

## 맥락(Context)
나는 [작업명]에 대해 두 AI 도구의 결과를 비교하려 한다.
- 도구 A: [도구명 — 예: Claude]
- 도구 A 결과: [도구 A 산출물 전문 또는 핵심 내용 붙여넣기]
- 도구 B: [도구명 — 예: ChatGPT]
- 도구 B 결과: [도구 B 산출물 전문 또는 핵심 내용 붙여넣기]

## 과제(Task)
두 결과를 비교 분석하라. 다음 세 항목을 표로 제시하라:

| 항목 | 두 결과가 일치하는 부분 | 두 결과가 엇갈리는 부분 | 어느 쪽을 더 신뢰할 수 있는 이유 |

표 아래에 다음을 추가하라:
1. 두 도구 모두 틀렸을 가능성이 있는 항목 (있다면 명시, 없으면 "없음"이라고 밝혀라)
2. 추가 확인이 필요한 항목 목록과 확인 방법 제안
3. 최종 통합 초안 작성 시 어느 부분을 어느 도구 결과에서 가져오는 것이 적절한지 판단

## 형식(Format)
- 두 도구의 차이를 "한 도구가 더 낫다"는 식으로 단정하지 말고, 각 도구의 강점이 나타나는 상황을 서술하라
- 추론 과정을 드러내라: 어떤 근거로 신뢰도를 판단했는지 설명하라
- 모르는 부분은 모른다고 밝혀라, "[확인 필요]" 표시를 적극 활용하라
```

입력 예시:
- 작업명: 디지털 리터러시 격차 관련 선행연구 핵심 논거 정리
- 도구 A(Claude) 결과 및 도구 B(ChatGPT) 결과를 각각 붙여넣기

기대 출력(요약): 일치·불일치 항목 비교표, 양쪽 모두 오류 가능성이 있는 항목 지적, 최종 초안 작성 시 활용 지침.

검증 프롬프트:

```text
위 비교에서 두 도구가 일치한다고 분류한 항목 중, 실제로는 표현만 비슷하고 내용이 다를 수 있는 항목이 있는가?
있다면 해당 항목을 지적하고, 원문 자료에서 직접 확인해야 할 지점을 구체적으로 알려라.
```

## 프롬프트 3. 비용·한계 점검 및 도구 스택 설계

무엇을 얻나: 연구 기간 전체에서 사용할 AI 도구 조합(스택)을 1페이지로 정리하고, 예상 비용과 각 도구의 실질적 한계를 미리 파악하여 연구 계획에 반영한다.

```text
## 역할(Role)
너는 학술 연구자의 AI 도구 예산 및 워크플로우 설계 전문가다.

## 맥락(Context)
- 연구주제: [주제]
- 연구 기간: [기간 — 예: 6개월]
- 예상 주요 작업: [작업 목록 — 예: 문헌 검색 50편, 인터뷰 전사 10건, 논문 초안 3회 수정, 통계 분석 1회, 영문 교정 1회]
- 현재 보유 계정: [보유 계정 목록 — 예: ChatGPT 무료, Claude 무료]
- 월 예산: [금액 — 예: 월 3만 원 이내]

## 과제(Task)
다음 세 가지를 순서대로 제시하라:

1. 비용·한계 점검표
| 도구 | 무료 한도 | 유료 플랜 월 비용(USD/KRW 병기) | 내 작업에서 한계에 부딪힐 시점 | 대안 |

2. 도구 스택 1페이지 초안
내 연구 기간과 예산에 맞는 도구 조합을 단계별(탐색 → 분석 → 집필 → 교정)로 정리하라.
각 단계마다 주요 도구 1~2종과 보조 도구를 지정하고, 도구 전환 시점(언제 유료로 올리는가)을 명시하라.

3. 비용 최소화 우선순위
예산이 빠듯할 때 가장 먼저 유료로 올려야 할 도구 1순위와 그 근거를 1~2문장으로 요약하라.

## 형식(Format)
- 요금제 정보는 변동 가능성이 있으므로, 수치 옆에 "[확인 필요 — 가입 직전 공식 페이지에서 재확인]"을 반드시 표시하라
- 모르는 도구의 요금 정보는 추정하지 말고 "공식 페이지 확인 요망"으로 남겨라
- 추론 과정을 드러내라: 왜 이 도구를 이 단계에 배치했는지 간략히 설명하라
```

입력 예시:
- 연구주제: 청소년 디지털 리터러시 격차
- 연구 기간: 6개월
- 주요 작업: 문헌 검색 50편, 인터뷰 전사 10건, 논문 초안 3회 수정, 통계 분석 1회
- 현재 계정: ChatGPT 무료, Claude 무료
- 월 예산: 월 3만 원 이내

기대 출력(요약): 도구별 비용·한계 점검표, 연구 단계별 도구 스택 초안, 예산 우선순위 요약.

검증 프롬프트:

```text
위에서 제안한 도구 스택에서, 내 연구가 예상보다 길어지거나 데이터 규모가 2배로 커질 경우
가장 먼저 병목이 생기는 도구와 그 이유를 구체적으로 설명하라.
요금 정보는 "[확인 필요]"로 표시하고, 추정과 확정 정보를 구분하라.
```

## ✓ 연구자 체크 (출력 받은 뒤)

- [ ] 도구별 강점·한계 설명이 내 실제 작업 유형(장문 분석·코드·검색·글쓰기)과 맞는지 확인했는가
- [ ] AI가 "[확인 필요]"로 표시한 항목은 직접 확인했는가
- [ ] 도구 정책·요금은 자주 바뀌므로 부록 B에서 최신 정보를 확인했는가
- [ ] 1순위 도구의 결과를 2순위 도구로 교차검증했는가 (중요 산출물의 경우)
- [ ] 제안된 프롬프트 초안에 내 연구주제·자료·산출물 정보를 구체적으로 채워 넣었는가
- [ ] 도구 스택 설계 시 현재 보유 계정과 실제 월 예산을 정확히 입력했는가

## ※ 흔한 실패 패턴

| 증상 | 원인 | 처방 |
|---|---|---|
| 모든 작업을 ChatGPT 한 도구로만 처리했는데 장문 분석에서 맥락이 끊어진다 | 도구 특성 무시, 장문 컨텍스트가 필요한 작업을 컨텍스트 제한이 있는 도구에 맡김 | 2.6절 의사결정 트리를 따라 작업 유형을 먼저 분류한 뒤 도구를 배정하라 |
| AI가 추천한 도구 조합이 너무 많아 오히려 혼란스럽다 | 작업명·산출물 형태를 너무 포괄적으로 입력함 | [작업명]을 "선행연구 PDF 15편 요약 → A4 2쪽"처럼 구체적인 입력·출력 단위로 좁혀 다시 실행하라 |
| 요금 정보가 실제와 달라 예산 계획이 어긋났다 | AI 학습 데이터의 요금 정보가 최신 정책을 반영하지 못함 | 요금 수치는 부록 B 또는 각 도구 공식 페이지에서 가입 직전에 반드시 재확인하라 |
