# 프롬프트 라이브러리 (P-1 ~ P-13)

> 책 각 장에 대응하는 **복붙 가능한 확장형 프롬프트** 모음입니다. 책 본문의 짧은 압축 프롬프트를, 그대로 실행할 수 있는 완전한 형태로 펼쳤습니다.

## 사용법 3단계

1. 필요한 패키지(P-번호) 파일을 엽니다.
2. 프롬프트를 통째로 복사해 ChatGPT·Claude·Gemini 등에 붙여 넣습니다.
3. `[대괄호]` 부분을 **내 연구 내용으로 교체**하고 실행합니다. 출력은 각 파일의 **검증 프롬프트**로 한 번 더 거릅니다.

> ⚠️ 모든 프롬프트에는 [할루시네이션 방지 5계명](RCTF_기본골격.md#5-할루시네이션-방지-5계명-)이 내장되어 있습니다. 인용·통계·수치는 반드시 원문에서 직접 확인하세요.

## 한눈에 보는 흐름

```
연구주제 1문장 (P-1)
   → 도구 스택 설계 (P-2) → RCTF로 질문 만들기 (P-3)
   → 문헌 읽기 (P-4) → 인용 정리 (P-5) → 트렌드·Gap (P-6) → 목차 (P-7)
   → 데이터 설계 (P-8) → 분석 (P-9) → 시각화 (P-10)
   → 해석·논의 (P-11) → 글쓰기·윤리 (P-12)
   → 사업화·제안서 (P-13)
```

하나의 연구주제 1문장이 **누적되며** 학위논문·발표자료·사업계획서로 확장됩니다.
