# P-6 트렌드 탐색 — 제6장 프롬프트 패키지

> 연결 장: 제6장 연구 트렌드 탐색 · 워크북: [W-3](../workbook/W3_트렌드와연구질문도출.md)
> 사용법: 복사 → [대괄호] 교체 → 실행 → 검증 프롬프트로 재확인

---

## 언제 쓰나

연구주제를 잡은 직후, "지금 이 주제를 왜 연구해야 하는가?" 를 서론에서 설득해야 할 때 쓴다.
학술 트렌드와 시장·현장 트렌드를 분리해 분석하고, 두 흐름이 겹치는 교집합(학술 Gap × 시장 Gap)에서 연구질문(RQ) 후보와 서론용 문제의식 문장을 도출하는 것이 이 패키지의 목적이다.

추천 도구
| 목적 | 권장 도구 |
|---|---|
| 인용 후보 발굴(학술 Gap) | Perplexity (Academic Focus 모드) |
| 종합 트렌드 리포트 초안 | Gemini Deep Research |
| 현장·소셜 트렌드(시장 Gap) | Grok |
| 키워드 트리 시각화 | Genspark / Napkin AI |

> 주의: Perplexity 등 웹검색형 도구 사용 시 출처 URL을 반드시 포함하도록 지시하고, 뉴스·블로그·SNS 출처는 학술적 사실로 단정하지 말고 "현장 신호"로만 활용할 것.

## 프롬프트 1 — 키워드 확장 (핵심 / 하위 / 유사 / 제외)

무엇을 얻나: 트렌드 검색 전에 검색 범위를 결정하는 키워드 4종 목록. 검색 노이즈를 줄이고 연구 범위를 선명하게 잡는다.

```text
역할(Role): 너는 학술 문헌 검색 전문가다.
맥락(Context): 내 연구주제는 [주제]이고, 연구 목적은 [연구 목적 한 문장]이다.
과제(Task): 아래 4가지 키워드 유형을 각각 5개 이상 목록으로 정리하라.
  1. 핵심 키워드 — 검색 시 반드시 포함해야 하는 단어
  2. 하위 키워드 — 핵심 키워드를 구체화하는 세부 개념
  3. 유사·대체 키워드 — 같은 개념을 다르게 부르는 표현(동의어·영문 포함)
  4. 제외 키워드 — 검색 결과에 섞이면 안 되는 혼동 단어
형식(Format): 유형별로 번호 목록으로 출력하고, 각 단어 옆에 선정 이유를 한 줄로 적어라.
할루시네이션 방지: 실제 학술 데이터베이스(KCI·RISS·SCOPUS·WoS)에서 통용되는 용어인지 확신이 없으면 [확인 필요]를 표시하라. 유행어나 자체 조어를 기정사실처럼 올리지 마라.
```

입력 예시:
- [주제] → `고령층 디지털 리터러시 교육`
- [연구 목적 한 문장] → `스마트폰 활용 교육 프로그램의 효과를 측정하는 척도를 개발하기 위해`

기대 출력(요약):
- 핵심 키워드 5개 (예: 디지털 리터러시, 고령층, 스마트폰 교육 …)
- 하위 키워드 5개 (예: 정보 접근성, 디지털 포용, 미디어 이해력 …)
- 유사·대체 키워드 5개 (예: digital literacy, older adults, ICT education …)
- 제외 키워드 5개 (예: 청소년, 게임 리터러시, 인터넷 중독 …)

검증 프롬프트:

```text
위에서 제시한 키워드 목록 중 [확인 필요] 표시가 없는 항목만 골라,
각 단어가 최근 5년(2020-2025) KCI 또는 SCOPUS 논문 제목·초록에 실제로 등장하는지
근거 논문 제목을 1편씩 함께 제시하라. 근거를 찾지 못한 항목은 [확인 필요]로 표시하라.
```

## 프롬프트 2 — 학술 Gap · 시장 Gap 분리 분석 (핵심 프롬프트)

무엇을 얻나: 학술계가 아직 다루지 않은 영역(학술 Gap)과 현장·시장이 아직 풀지 못한 문제(시장 Gap)를 각각 한 문장으로 정리한다. 두 Gap의 교집합이 서론 문제의식의 핵심 근거가 된다.

```text
역할(Role): 너는 학술 트렌드 분석가이자 산업 리서처다.
맥락(Context): 내 연구주제는 [주제]이고, 분석 대상 기간은 최근 [기간 — 예: 3년, 2023-2025]이다.
과제(Task):
  [학술 트렌드]
  - 이 주제를 다룬 주요 논문·학회·연구기관의 최근 동향을 5문장 이내로 요약하라.
  - 학술 Gap(학계가 아직 답하지 않은 공백)을 1문장으로 명확하게 서술하라.
  [시장·현장 트렌드]
  - 이 주제와 관련된 산업 뉴스, 정책 변화, 현장 Pain Point를 5문장 이내로 요약하라.
  - 시장 Gap(현장·사용자가 아직 풀지 못한 문제)을 1문장으로 명확하게 서술하라.
  [교집합]
  - 두 Gap이 겹치는 지점을 2-3문장으로 서술하라.
형식(Format): 학술 트렌드 / 학술 Gap / 시장·현장 트렌드 / 시장 Gap / 교집합 순으로 소제목을 붙여 출력하라.
출처 요건(Perplexity 등 웹검색 도구 사용 시): 학술 트렌드 항목에는 논문 또는 공식 보고서 URL을 반드시 포함하라. 뉴스·블로그·SNS 출처는 시장·현장 트렌드 항목에만 활용하고, 이를 학술적 사실로 단정하지 마라.
할루시네이션 방지: 직접 확인하지 않은 수치·통계·논문 제목은 [확인 필요]로 표시하라. 추정이나 유추는 "~로 보인다", "~가 예상된다"로 표현하고 단정하지 마라.
```

입력 예시:
- [주제] → `고령층 디지털 리터러시 교육`
- [기간] → `최근 3년(2022-2025)`

기대 출력(요약):
- 학술 트렌드 요약 5문장 + 학술 Gap 1문장
- 시장·현장 트렌드 요약 5문장 + 시장 Gap 1문장
- 두 Gap의 교집합 2-3문장

검증 프롬프트:

```text
위 분석에서 [확인 필요] 표시 없이 제시된 학술 Gap 문장을 검증하라.
해당 Gap을 뒷받침하는 논문 2편과, 반대로 이미 Gap이 채워졌음을 시사하는 논문 1편을
제목·저자·게재지·연도와 함께 제시하라. 두 입장을 모두 보여주고
어느 쪽이 더 근거가 탄탄한지 판단을 내려라.
```

## 프롬프트 3 — RQ 후보 3개 + 서론용 문제의식 문장

무엇을 얻나: 두 Gap의 교집합을 기반으로 연구질문(RQ) 후보 3개와 서론 첫 단락에 바로 쓸 수 있는 문제의식 문장 3개를 얻는다.

```text
역할(Role): 너는 논문 서론 작성을 전문으로 하는 학술 글쓰기 코치다.
맥락(Context): 
  - 연구주제: [주제]
  - 학술 Gap: [프롬프트 2에서 도출한 학술 Gap 1문장]
  - 시장 Gap: [프롬프트 2에서 도출한 시장 Gap 1문장]
  - 두 Gap의 교집합: [프롬프트 2에서 도출한 교집합 서술]
과제(Task):
  1. 연구질문(RQ) 후보 3개를 작성하라.
     - RQ 1: 학술 Gap 중심 — 이론적 공백을 채우는 질문
     - RQ 2: 시장 Gap 중심 — 현장 문제 해결에 집중하는 질문
     - RQ 3: 교집합 통합 — 학술·실용 가치를 동시에 담은 질문
  2. 서론용 문제의식 문장 3개를 작성하라.
     - 각 문장은 독립적으로 쓰일 수 있도록 완결된 형태여야 한다.
     - 최신 트렌드 또는 Gap을 독자에게 설득하는 어조로 작성하라.
     - 문장 길이: 각 50-80자 내외(한국어 기준)
형식(Format): RQ 후보 → 번호 목록 / 문제의식 문장 → 번호 목록, 각 항목에 한 줄 코멘트 추가.
할루시네이션 방지: 특정 수치나 통계를 문제의식 문장 안에 넣을 경우, 반드시 출처를 괄호 안에 명시하고 확인되지 않은 수치는 [확인 필요]로 표시하라. 뉴스·블로그·SNS 자료를 학술적 사실처럼 단정하지 마라.
```

입력 예시:
- [주제] → `고령층 디지털 리터러시 교육`
- [학술 Gap] → `고령층 디지털 리터러시 교육 효과를 측정하는 표준화된 한국형 척도가 부재하다`
- [시장 Gap] → `스마트폰 기반 교육 프로그램이 증가하고 있으나 학습 지속률이 낮다는 현장 불만이 지속된다`
- [교집합] → `측정 도구 부재로 인해 현장 프로그램의 효과가 체계적으로 검증되지 않고 있다`

기대 출력(요약):
- RQ 1: 한국형 고령층 디지털 리터러시 척도는 어떤 요인 구조로 구성되어야 하는가?
- RQ 2: 스마트폰 기반 교육 프로그램의 지속률을 높이는 설계 요소는 무엇인가?
- RQ 3: 표준화 척도 적용이 고령층 디지털 교육 프로그램의 효과 및 지속률에 미치는 영향은?
- 문제의식 문장 3개 (서론 첫 단락 후보)

검증 프롬프트:

```text
위에서 제시된 RQ 3개 중 하나를 선택해 [RQ 번호 및 내용]을 붙여넣어라.
이 RQ가 기존 연구에서 이미 다루어진 적이 있는지 확인하고,
유사 선행연구 2편(제목·저자·연도·간략 요약)을 제시하라.
선행연구와의 차별점을 1문장으로 정리하고,
RQ를 더 구체화하거나 범위를 좁혀야 할 필요가 있다면 수정 제안을 하라.
```

## ✓ 연구자 체크

프롬프트 실행 후 아래 항목을 직접 확인하라.

- [ ] 학술 Gap과 시장 Gap이 명확히 분리되어 있는가? (섞여 있으면 서론 논리가 흐려진다)
- [ ] 출력에 포함된 논문·보고서 제목을 실제로 검색해 존재 여부를 확인했는가?
- [ ] [확인 필요] 표시 항목을 모두 직접 검증했는가?
- [ ] RQ 3개가 각각 학술·시장·통합 관점을 고르게 반영하는가?
- [ ] 문제의식 문장이 뉴스·블로그 출처를 학술적 사실처럼 단정하지 않는가?
- [ ] 키워드 트리를 Genspark 또는 Napkin AI로 시각화했는가? (워크북 W-3 Step 3 참조)

## ※ 흔한 실패 패턴

| 실패 패턴 | 증상 | 대처법 |
|---|---|---|
| Gap 혼용 | "학술 Gap: 시장 수요가 높다" — 학술 근거 없이 시장 용어 사용 | 학술 Gap에는 반드시 논문·보고서 출처 요구; 시장 Gap과 섹션 분리 |
| 할루시네이션 수치 | "2024년 65세 이상 스마트폰 보급률 87%(출처 없음)" — 미확인 통계 삽입 | [확인 필요] 표시 규칙 엄수; 검증 프롬프트로 출처 강제 확인 |
| RQ 과잉 일반화 | "디지털 격차를 어떻게 해소할 것인가" — 주제가 너무 넓어 한 논문으로 답 불가 | 연구 기간·대상·방법을 특정해 RQ 범위를 좁힘; 검증 프롬프트에서 선행연구와 차별점 재확인 |
