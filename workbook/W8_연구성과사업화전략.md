# W-8 연구성과 사업화 전략

> 연결 장: 제13장 · 연결 프롬프트: [P-13](../prompts/P13_사업화.md) · 부록: [D](../appendix/D_정부과제캘린더.md) · [E](../appendix/E_5대활용트랙비교표.md) · [부속 마](../appendix/부속자료_마_사업화의사결정시트.md)

> 이 워크북을 마치면: 린 캔버스 9블록 완성 + 정부과제 제안서 매핑표 작성 + 청중별 1분 발표 첫 문장 완성

---

## 사용법

1. Step 1 → 5 순서대로 채운다. 앞 단계 결과가 뒤 단계의 재료가 되므로 순서를 지키는 것이 중요하다.
2. 빈칸(`____________`)과 표의 빈 셀은 여러분의 연구 내용으로 직접 채운다.
3. 시장규모, 예산, 매출 등 수치는 반드시 직접 조사 후 기입한다. 이 양식에는 `[확인 필요]`로 표시해 두었다.
4. 각 Step 끝의 → 연결 프롬프트를 활용하면 AI와 함께 내용을 보강할 수 있다.
5. 완료 체크리스트로 마무리 점검을 한다.

## Step 1. 논문 핵심 기여 3문장

목적: 연구의 본질적 가치를 사업화 언어로 재해석하기 전에, 학술적 기여를 간결하게 정리한다. 이 3문장이 이후 모든 단계의 기반이 된다.

### 1-1. 기여 문장 작성

아래 형식에 따라 논문의 핵심 기여를 3문장으로 작성하라.

| 번호 | 기여 유형 | 내 논문의 기여 (직접 작성) |
|------|-----------|---------------------------|
| ① | 이론적 기여 (새로운 개념·모델·프레임워크 제시) | ____________________________________________ |
| ② | 방법론적 기여 (새로운 분석 방법·도구·프로세스 제시) | ____________________________________________ |
| ③ | 실천적 기여 (현장 적용 가능성·정책 함의·산업 적용) | ____________________________________________ |

> 작성 팁: "본 연구는 \_\_\_를 최초로 \_\_\_하여, \_\_\_에게 \_\_\_한 가치를 제공한다"는 구조를 활용해 보라.

### 1-2. 핵심 키워드 추출

3문장에서 사업화와 연결될 핵심 키워드를 최대 5개 뽑는다.

```
키워드 1: ____________
키워드 2: ____________
키워드 3: ____________
키워드 4: ____________
키워드 5: ____________
```

## Step 2. 문제·고객·솔루션 변환

목적: 학술 언어로 쓰인 논문 내용을 사업화·정책화에 적합한 언어로 변환한다. '연구자의 시각'에서 '수혜자의 시각'으로 전환하는 핵심 단계다.

### 2-1. 변환 매핑표

| 항목 | 학술 언어 (논문 표현) | 사업화 언어 (변환 후) |
|------|----------------------|----------------------|
| 해결할 문제 | 논문에서 제기한 연구 문제: ________________ | 현장에서 느끼는 불편·손실·위험: ________________ |
| 고객 (수혜자) | 연구 대상 집단: ________________ | 이 솔루션을 실제로 사용할 사람·기관: ________________ |
| 기존 해결책의 한계 | 선행연구의 한계: ________________ | 현재 현장에서 쓰는 방법의 문제점: ________________ |
| 제안 솔루션 | 본 연구의 방법론·결과: ________________ | 실제로 제공할 서비스·제품·정책: ________________ |
| 차별성 | 본 연구의 novelty: ________________ | 경쟁 제품·서비스 대비 우위: ________________ |
| 기대효과 | 연구의 학술적 함의: ________________ | 수혜자가 얻는 구체적 이익: ________________ |

### 2-2. 수혜자 프로파일

가장 핵심적인 수혜자(고객) 1인을 구체적으로 묘사한다.

```
이름(가상):  ____________
직업/역할:   ____________
나이대:      ____________
현재 겪는 문제: ____________________________________________
이 솔루션을 만나면 달라지는 점: ________________________________
```

## Step 3. 린 캔버스 9블록

목적: 비즈니스 모델 전체를 한 페이지에 시각화한다. 린 캔버스(Lean Canvas)는 스타트업 및 연구 사업화에서 널리 쓰이는 1페이지 비즈니스 모델 도구다.

> 주의: 시장규모, 예상 매출, 예산 등 수치 항목은 반드시 직접 조사하여 기입하라. 아래 `[확인 필요]` 표시가 된 항목은 추정치를 쓰지 말고 근거 있는 수치로 대체하라.

### 3-1. 린 캔버스 작성표

| 블록 번호 | 블록명 | 내용 (직접 작성) | 작성 가이드 |
|-----------|--------|-----------------|-------------|
| ① 문제 (Problem) | 해결하려는 핵심 문제 | 1. ________________ 2. ________________ 3. ________________ | 수혜자가 실제로 경험하는 Top 3 문제를 쓴다 |
| ② 고객군 (Customer Segments) | 초기 타깃 고객 | 얼리어답터: ________________ 주요 고객군: ________________ | 가장 고통이 큰 집단을 먼저 쓴다 |
| ③ 고유가치제안 (Unique Value Proposition) | 단 한 줄의 핵심 메시지 | ____________________________________________ | "누가, 무엇을, 왜 당신에게서 사야 하는가"를 한 문장으로 |
| ④ 솔루션 (Solution) | 제공할 핵심 기능 | 1. ________________ 2. ________________ 3. ________________ | 문제 ①에 1:1 대응하여 작성 |
| ⑤ 채널 (Channels) | 고객에게 도달하는 경로 | ____________________________________________ | 학회·정부기관·병원·기업·SNS 등 |
| ⑥ 수익원 (Revenue Streams) | 돈을 버는 방식 | 수익 모델: ________________ 단가(건당/월/년): [확인 필요] 목표 고객 수: [확인 필요] | 라이선스·컨설팅·SaaS·정부과제 등 |
| ⑦ 비용구조 (Cost Structure) | 주요 비용 항목 | 고정비: ________________ 변동비: ________________ 초기 개발비: [확인 필요] | 인건비·인프라·마케팅 등 |
| ⑧ 핵심지표 (Key Metrics) | 성공을 측정하는 지표 | 1. ________________ 2. ________________ 3. ________________ | 사용자 수·재방문율·과제 수주액 등 |
| ⑨ 경쟁우위 (Unfair Advantage) | 쉽게 복제할 수 없는 강점 | ____________________________________________ | 특허·데이터·네트워크·논문 기반 신뢰성 등 |

### 3-2. 린 캔버스 시각화 (자유 작성)

아래 틀에 위 내용을 옮겨 한눈에 볼 수 있게 정리한다.

│                │                │                │                │                │
│                ├────────────────┤                ├────────────────┤                │
│                │  ⑧ 핵심지표    │                │  ⑤ 채널        │                │
│                │                │                │                │                │
├────────────────┴────────────────┼────────────────┴────────────────┴────────────────┤
│  ⑦ 비용구조                     │  ⑥ 수익원                                        │

## Step 4. 정부과제 제안서 매핑

목적: 논문의 각 구성 요소가 정부 R&D 과제 제안서의 어느 항목에 대응하는지 매핑하여, 제안서 작성의 기반을 마련한다.

### 4-1. 논문 → 제안서 항목 매핑표

|-----------|--------------------------|----------------------|--------------------------|
| 연구 배경 및 필요성 | ________________________ | 연구개발의 필요성 및 목표 | ________________________ |
| 선행연구 검토 | ________________________ | 국내외 기술 현황 분석 | ________________________ |
| 연구 방법론 | ________________________ | 연구개발 내용 및 방법 | ________________________ |
| 주요 결과 | ________________________ | 연구개발 성과 및 활용 방안 | ________________________ |
| 한계 및 향후 연구 | ________________________ | 향후 연구계획 | ________________________ |
| 참고문헌 | ________________________ | 참고자료 | ________________________ |

### 4-2. 과제 유형 선택

연구 성격에 맞는 정부과제 유형에 체크하라.

- [ ] 기초연구 (NRF 개인기초연구 등) — 새로운 이론·원리 탐구
- [ ] 응용연구 (부처 R&D) — 특정 문제 해결을 위한 지식 창출
- [ ] 개발연구 (IITP, KIAT 등) — 실제 제품·시스템·서비스 개발
- [ ] 정책연구 (경제·인문사회연구회 등) — 정책 수립 지원
- [ ] 국제공동연구 — 해외 기관과의 협력 연구
- [ ] 기술이전/사업화 (TIPS, 창업패키지 등) — 연구 결과의 시장 진입

## Step 5. 청중별 1분 발표 첫 문장

목적: 동일한 연구 성과라도 청중에 따라 강조점이 달라진다. 지도교수·평가위원·투자자 각각에게 맞는 첫 문장(엘리베이터 피치의 오프닝)을 미리 준비한다.

> 작성 원칙: 첫 문장은 30초 안에 말할 수 있어야 하며(약 60~80자 이내), 청중의 관심사를 정확히 건드려야 한다.

### 5-1. 청중별 첫 문장 작성

| 청중 | 이 청중이 가장 관심 갖는 것 | 나의 첫 문장 (직접 작성) |
|------|---------------------------|------------------------|
| 지도교수·학술 심사위원 | 연구의 학문적 독창성, 방법론의 엄밀성, 선행연구와의 차별성 | "____________________________________________" |
| 정부과제 평가위원 | 연구의 사회적 필요성, 성과 목표의 명확성, 예산 대비 효율성 | "____________________________________________" |
| 투자자·산업계 파트너 | 시장 기회의 크기, 수익 모델의 가능성, 팀의 실행 역량 | "____________________________________________" |
| 일반 대중·언론 | 내 삶과의 연관성, 쉬운 이해, 사회적 임팩트 | "____________________________________________" |

### 5-2. 전체 1분 발표 구성 (선택 작성)

관심 있는 청중 1인을 골라 1분 발표 전체 구성을 스케치한다.

선택한 청중: ________________________

```
[0~10초] 첫 문장 (문제 제기):
____________________________________________

[10~25초] 현재 해결책의 한계:
____________________________________________

[25~45초] 나의 솔루션과 근거:
____________________________________________

[45~55초] 기대 성과 / 요청 사항:
____________________________________________

[55~60초] 마무리 문장 (기억에 남을 한 줄):
____________________________________________
```
