## Step 1. Results vs. Discussion 분리

**목적:** Results 섹션은 "무엇을 관찰했는가(사실)"만 기술하고, Discussion 섹션은 "그것이 무엇을 의미하는가(해석·함의)"를 다룹니다. 두 섹션을 혼동하면 심사위원으로부터 "결과와 해석이 뒤섞여 있다"는 지적을 받습니다. 아래 표를 채우며 두 섹션을 명확히 구분하세요.

### 1-1. 분리 연습 표

| # | 내 연구의 관찰 사실 (Results에 쓸 내용) | 해석·함의 (Discussion에 쓸 내용) |
|---|----------------------------------------|----------------------------------|
| 1 | | |
| 2 | | |
| 3 | | |
| 4 | | |
| 5 | | |
| 6 | | |

> **작성 팁:** "관찰 사실" 열에는 수치, 그래프 추세, 통계 결과만 적습니다. "~이기 때문에", "~을 시사한다" 같은 해석 표현이 들어가면 Discussion 열로 옮기세요.

### 1-2. 자주 발생하는 혼용 표현 점검

아래 표현이 Results 섹션에 등장하면 Discussion으로 이동하세요.

| 혼용 위험 표현 | 적절한 위치 |
|----------------|-------------|
| "이는 ~을 의미한다" | Discussion |
| "결과는 ~을 지지한다" | Discussion |
| "~에 기인한 것으로 보인다" | Discussion |
| "통계적으로 유의하였다 (p < .05)" | Results (수치만) |
| "집단 간 차이가 관찰되었다" | Results |

## Step 2. Discussion 5단 구조

**목적:** Discussion은 단순 요약이 아니라 연구의 학문적·실무적 가치를 설득하는 섹션입니다. 아래 5단 구조를 따르면 논리적 흐름이 자연스럽게 완성됩니다.

> **상관 ≠ 인과 원칙:** 상관관계(correlation)를 인과관계(causation)로 과장하는 것은 학술 윤리 위반입니다. "A가 B에 영향을 미친다"고 쓰려면 실험 설계(randomization, control)가 갖춰져야 합니다. 관찰·설문 연구라면 "A와 B 간 유의한 정적 관계가 나타났다"로 표현하세요.

## Step 4. 영문 초록 6문장

**목적:** 국제 학술지 투고 또는 학위논문 영문 초록 작성을 위한 6문장 구조입니다. 각 문장은 명확한 역할을 가지며, 전체 초록은 150~250 단어를 목표로 합니다.

> **AI 활용 시 주의:** AI가 작성한 영문 초록은 반드시 원어민 교정 또는 전문 교정 서비스를 거치세요. AI 문장이 문법적으로 자연스럽더라도 전문 용어 선택이나 뉘앙스가 어색할 수 있습니다.

### 4-1. 6문장 구조 초안

| 문장 번호 | 역할 | 영문 초안 (직접 작성) | 한글 대조문 |
|-----------|------|----------------------|-------------|
| 문장 1 | **배경 (Background):** 연구가 다루는 학문적·사회적 맥락 | | |
| 문장 2 | **목적 (Purpose/Objective):** 연구의 구체적 목적 또는 연구 문제 | | |

- [ ] **[Step 2]** 상관관계를 인과관계로 과장하는 표현이 없다. ("A가 B를 유발한다" → "A와 B 간 유의한 관계가 나타났다"로 수정)
- [ ] **[Step 3]** 예상 반박 질문 5개 이상에 대한 근거 있는 답변을 준비했다.
- [ ] **[Step 4]** 영문 초록 6문장(배경·목적·방법·결과·함의·결론)이 완성되었고 150~250 단어 범위 내에 있다.
- [ ] **[Step 5]** AI 도구 사용 내역(도구명·버전·목적·검증 방법)을 명시한 문구를 논문에 삽입했다.
- [ ] **[공통]** 모든 AI 생성 내용을 연구자가 직접 검토·수정했고, 최종 책임이 연구자에게 있음을 확인했다.
