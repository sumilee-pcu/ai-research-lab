# 워크북 (W-1 ~ W-8)

> 프롬프트가 "AI에게 시키는 법"이라면, 워크북은 **내가 직접 채워 넣는 빈칸 양식**입니다. 연구주제 1문장에서 출발해 사업화 전략까지, 8개 워크북을 따라가면 한 편의 연구가 완성됩니다.

## 사용법

1. 워크북을 화면에 띄우거나 인쇄/복사합니다.
2. 빈칸·빈 표를 **내 연구주제로 직접** 채웁니다.
3. 막히는 칸은 연결된 [프롬프트 패키지](../prompts/)로 AI 보조를 받되, **최종 판단은 직접** 내립니다.
4. 각 워크북 끝의 ✅ 완료 체크리스트로 마무리합니다.

## 누적형 학습 흐름

각 워크북의 산출물은 **다음 워크북의 입력**이 됩니다. W-1에서 정한 연구주제 1문장이 W-3의 RQ, W-4의 목차, W-8의 사업계획서로 이어집니다. 한 번 정한 주제를 쉽게 바꾸지 말고, 도구와 관점을 계속 입혀 가세요.

> 빈 양식 외에 표 형식 다운로드가 필요하면 [templates/](../templates/)를 참고하세요.
