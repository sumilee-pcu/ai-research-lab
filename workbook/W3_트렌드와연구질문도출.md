## 사용법

1. **순서대로** Step 1 → 5를 완성한 뒤 체크리스트로 검토하세요.

4. **웹 검색·AI 응답 결과는 학술 사실로 단정하지 마세요.** 반드시 원문 논문·공식 통계로 교차 확인해야 합니다.
5. 이 파일은 논문 초안 작성 전 아이디어 스케치용입니다. 완성 수준을 지나치게 걱정하지 말고 우선 채우는 것을 목표로 하세요.

## Step 1. 키워드 트리

**목적:** 연구 주제를 둘러싼 어휘 지형을 시각화하여, 검색 범위와 제외 기준을 명확히 정의한다.

### 1-1. 키워드 트리 표

아래 표를 채우세요. 각 칸에 2~5개 키워드를 쉼표로 구분하여 입력합니다.

| 구분 | 내용 | 작성 예시(참고용) |
|------|------|-----------------|
| **핵심 키워드** (Core) | | 예: 생성형 AI, 논문 작성 자동화 |
| **하위 키워드** (Sub) | | 예: 프롬프트 엔지니어링, RAG, 파인튜닝 |
| **유사·대체 키워드** (Synonym) | | 예: LLM 글쓰기 지원, AI 보조 연구 |
| **제외 키워드** (Exclusion) | | 예: 표절 탐지, 자동 번역, 문법 교정 |

> **Tip — 핵심 키워드:** 논문 제목에 반드시 들어갈 단어입니다. 영문 병기도 함께 적어 두면 데이터베이스 검색 시 유용합니다.
>
> **Tip — 하위 키워드:** 핵심 개념을 구성하는 세부 기술·방법론·대상입니다.
>
> **Tip — 유사·대체 키워드:** 다른 연구자가 같은 현상을 다른 용어로 지칭할 때 쓰는 단어입니다. 검색 누락을 막아 줍니다.
>
> **Tip — 제외 키워드:** 주제 범위를 명확히 하기 위해 의도적으로 배제할 키워드입니다. 심사위원에게 연구 범위 한정의 근거가 됩니다.

### 1-2. 키워드 트리 다이어그램 (선택)

아래 텍스트 다이어그램을 직접 수정하거나 별도 도구(Miro, draw.io 등)로 옮겨도 됩니다.

```
[핵심 키워드]
    ├── [하위 키워드 1]
    │       ├── (세부 용어)
    │       └── (세부 용어)
    ├── [하위 키워드 2]
    │       └── (세부 용어)
    └── [하위 키워드 3]

[유사 키워드] ←→ [핵심 키워드]
[제외 키워드] ✗
```

---

**가이드**

- 키워드는 **영문/한국어 병기**를 권장합니다 (예: 생성형 AI / Generative AI).
- 핵심 키워드는 **2~3개**로 좁히는 것이 논문 초점을 유지하는 데 도움이 됩니다.
- 유사 키워드가 많을수록 문헌 검색의 재현율(recall)이 높아집니다.
- 제외 키워드를 명시해 두면 연구 범위 한정 시 근거로 활용할 수 있습니다.

## Step 5. 서론 문제의식 문장 3개

**목적:** RQ를 독자에게 납득시키기 위한 서론의 핵심 논리를 문장으로 완성한다.

> **작성 원리:** 서론의 문제의식은 보통 ① 현상 제시 → ② 기존 접근의 한계 → ③ 연구 필요성 순서로 전개됩니다. 아래 세 문장 틀이 이 구조를 따릅니다.

---

**문장 1. 현상 제시 — "~가 확대되고 있다/변화하고 있다"**

*(독자가 공감할 수 있는 사회적·기술적·산업적 현상을 객관적으로 제시)*

```
최근 _______________________________(현상)이/가 _______________________________(맥락·규모·속도)
로 확대/심화되고 있다[또는 변화하고 있다].
```

출처·근거 메모:

```
(인용할 통계·보고서·논문 등을 간략히 메모)
※ 웹 검색 결과를 그대로 사용하지 말고 원문을 반드시 확인하세요.
```

---

**문장 2. 기존 접근의 한계 — "그러나 ~는 충분히 다루어지지 않았다"**

*(선행연구 또는 현장 해결책이 이 현상을 해결하지 못하는 이유를 제시)*

```
그러나 기존 연구(또는 현장 접근법)는 _______________________________(한계)
에 집중한 나머지, _______________________________(미해결 문제)
에 대한 체계적 논의가 부족하다.
```

선행연구 근거 메모:

```
(Step 2에서 정리한 학술 Gap 내용을 요약)
```

---

**문장 3. 연구 필요성 제시 — "따라서 이 연구는 ~를 목적으로 한다"**

*(RQ와 직결되는 연구 목적을 명확히 선언)*

```
따라서 본 연구는 _______________________________(연구 대상/맥락)에서
_______________________________(연구 방법/분석)을 통해
_______________________________(기대 기여·결과)를 규명하는 것을 목적으로 한다.
```

---

**가이드**

- 세 문장이 논리적으로 연결되는지(현상 → 한계 → 필요성) 소리 내어 읽으며 확인하세요.
- 문장 1에서 인용한 수치·사실은 학술 논문 또는 공식 기관 자료로 뒷받침해야 합니다.
- 완성된 세 문장은 최종 논문 서론 2~3단락의 뼈대가 됩니다.
- AI가 생성한 문장을 그대로 사용하지 말고, 자신의 언어로 고쳐 쓰세요.
