# W-6 논문 시각화 패키지

> 연결 장: 제10장 · 연결 프롬프트: [P-10](../prompts/P10_시각화.md) · 부록: [C](../appendix/C_논문시각화템플릿.md)
> 이 워크북을 마치면: Figure 4종 설계표 + 캡션 + 검증 항목

---

## 사용법

1. Step 1에서 논문 각 섹션별로 필요한 그림을 먼저 목록화합니다.
2. Step 2에서 각 Figure를 4종 유형 중 하나로 분류하고 설계 정보를 채웁니다.
3. Step 3에서 각 그림의 캡션 초안을 작성합니다.
4. Step 4에서 AI 생성 이미지와 실제 데이터 기반 그래프를 반드시 구분·표시합니다.
5. 최종적으로 완료 체크리스트를 점검하고 제출 전 자기검증을 마칩니다.

> 핵심 원칙: 실제 측정·분석 데이터를 나타내는 그래프는 반드시 matplotlib, R ggplot2, Seaborn 등 코드 기반 도구로 생성하십시오. AI 이미지 생성 도구(DALL·E, Midjourney, Adobe Firefly 등)로 만든 그림은 캡션에 반드시 생성 방법을 명시해야 하며, 정량 데이터의 시각화를 AI 이미지로 대체하는 것은 연구 윤리 위반입니다.

## Step 1. Figure 필요성 점검

목적: 논문의 각 섹션(서론·이론·방법·결과·논의)에서 어떤 그림이 독자 이해에 필수적인지 미리 계획합니다. 텍스트만으로 설명하기 어려운 내용, 논문의 핵심 기여를 가장 잘 드러내는 내용을 우선순위에 두십시오.

|------|-------------------------------|--------------------|---------------------------------|
| 서론 | | | |

### 1-2. 전체 Figure 수량 계획

| 항목 | 내용 |
|------|------|
| 계획 중인 총 Figure 수 | \_\_\_\_ 개 |

> 가이드: Figure 수가 많다고 좋은 논문이 아닙니다. "이 그림을 없애면 독자가 정말 이해하지 못하는가?"를 기준으로 걸러내십시오. 연결 프롬프트 [P-10](../prompts/P10_시각화.md)을 활용해 AI에게 "이 섹션에 어떤 Figure가 필요한가?" 조언을 구할 수 있습니다.

## Step 3. 캡션 작성

목적: 좋은 캡션은 그림을 보지 않고도 내용을 이해할 수 있어야 합니다. 각 Figure마다 아래 양식을 채워 캡션 초안을 완성하십시오.

### 캡션 구성 원칙

- 첫 문장: 그림이 무엇을 보여주는지 직접 서술 ("Figure X shows …" 또는 "X를 나타낸다.")
- 둘째 문장(선택): 핵심 패턴·결과·구조의 의미를 한 문장으로 해설
- 출처 표기: 직접 제작은 "저자 작성", 기존 자료 변형은 원출처 인용, AI 이미지는 사용 도구·날짜·프롬프트 요약 명시

> 윤리 경고: 실제 측정 결과, 실험 사진, 수치 데이터를 AI로 "생성"하거나 "보정"하는 행위는 연구 데이터 위조(fabrication)에 해당합니다. 개념도·시스템도·인포그래픽에 AI를 보조 도구로 사용하는 것은 적절하나, 반드시 캡션과 Methods에 명시해야 합니다. 부록 [C](../appendix/C_논문시각화템플릿.md)의 공시 문구 템플릿을 참고하십시오.
