# W-2 문헌 수집과 참고문헌 관리

> 연결 장: **제4~5장** · 연결 프롬프트: [P-4](../prompts/P04_문헌분석.md) · [P-5](../prompts/P05_인용관리.md)
>
> 이 워크북을 마치면: **문헌 8칸 비교표** + **연구 Gap 1문장** + **참고문헌 점검표**

---

## 사용법

1. 각 Step을 순서대로 진행하되, 이미 완성된 단계는 건너뛰어도 됩니다.
2. **빈칸은 반드시 원문을 직접 확인한 뒤 채우세요.** AI가 생성한 서지정보(저자명·연도·페이지·DOI)는 오류가 잦습니다. 환각(hallucination) 위험을 항상 염두에 두십시오.
3. 연결 프롬프트(P-4, P-5)를 AI 도구에 붙여 넣으면 각 단계를 AI와 함께 작업할 수 있습니다.
4. 표·양식은 복사해서 논문당·문헌당 반복 사용하세요.
