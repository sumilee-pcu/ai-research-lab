# AI Research Lab

AI 활용 논문작성법 교재의 실습 자료, 프롬프트 템플릿, 워크시트, 예제 코드를 제공하는 저장소입니다.

## 저장소 목적

이 저장소는 AI를 활용해 논문과 연구자료를 준비하는 학습자를 위한 실습 공간입니다. 책에서 다루는 ChatGPT, Claude, Gemini, NotebookLM, SciSpace, Zotero, Python 기반 분석 도구를 실제 연구 흐름에 맞춰 연습할 수 있도록 구성합니다.

## 구성 예정

```text
ai-research-lab/
├─ prompts/        # 장별 프롬프트 템플릿
├─ worksheets/     # 실습 워크시트와 체크리스트
├─ examples/       # 예제 데이터와 샘플 결과물
├─ notebooks/      # Python 분석 노트북
├─ figures/        # 도식화 및 시각화 예시
└─ docs/           # 보충 설명 자료
```

## 학습 흐름

1. AI 연구의 원리 이해
2. AI 도구별 역할 구분
3. RCTF 프롬프트 작성
4. 논문 PDF 읽기와 문헌 정리
5. Zotero 기반 인용 관리
6. 연구 트렌드 탐색
7. IMRaD 구조 설계
8. 데이터 수집과 분석 자동화
9. 논문 시각화
10. 결과 해석과 Discussion 작성
11. 학술 글쓰기와 연구윤리 점검
12. 연구성과의 사업화 자료 전환

## 사용 방법

각 폴더의 자료는 교재 장 순서에 맞춰 순차적으로 추가될 예정입니다. 실습자는 자신의 연구주제를 하나 정한 뒤, 장별 템플릿을 복사해 본인 주제에 맞게 수정하면서 사용하면 됩니다.

## 권장 준비물

- 본인 연구주제 1문장
- 관련 논문 PDF 5편 이상
- ChatGPT, Claude, Gemini 계정
- Zotero 설치 환경
- Python 실행 환경 또는 Google Colab

## 안내

본 저장소의 자료는 AI 활용 논문작성법 교재 학습을 돕기 위한 실습용 자료입니다. 실제 학위논문, 학술지 논문, 연구보고서 제출 시에는 소속 기관의 연구윤리 규정, 인용 기준, AI 활용 지침을 반드시 확인해야 합니다.
