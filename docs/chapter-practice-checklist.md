# 장별 실습 체크리스트

AI 활용 논문작성법 교재의 장별 실습 목표와 산출물을 정리한 문서입니다. 실습자는 하나의 연구주제를 정한 뒤, 각 장의 산출물을 누적해 최종적으로 논문 초안과 사업화 자료까지 연결합니다.

## 1부 AI 연구의 기초

### 제1장 AI 연구의 원리

- 실습 목표: AI와 연구자의 역할을 구분하고, 본인 연구주제를 DIKW 관점으로 정리한다.
- 수행 작업:
  - 본인 연구주제 1문장 작성
  - DIKW 4단계로 연구주제 분해
  - AI가 도울 일과 연구자가 책임질 일 구분
  - LLM의 주요 한계와 검증 필요 지점 정리
- 산출물:
  - `worksheets/ch01_dikw_research_map.md`
  - 연구주제 1문장
  - DIKW 자가 진단표

### 제2장 AI 도구 지형도

- 실습 목표: ChatGPT, Claude, Gemini 등 주요 AI 도구의 역할을 비교하고 본인 연구에 맞는 도구 조합을 정한다.
- 수행 작업:
  - 같은 질문을 3개 AI 도구에 입력
  - 응답 품질, 출처, 문체, 논리성 비교
  - 연구 단계별 도구 배분표 작성
- 산출물:
  - `worksheets/ch02_tool_map.md`
  - AI 도구 비교표
  - 본인 연구용 AI 도구 스택

### 제3장 RCTF 프롬프트

- 실습 목표: Role, Context, Task, Format 구조로 연구용 프롬프트를 작성한다.
- 수행 작업:
  - 나쁜 프롬프트와 좋은 프롬프트 비교
  - 문헌요약용 프롬프트 작성
  - 연구질문 도출용 프롬프트 작성
  - 초안 작성용 프롬프트 작성
- 산출물:
  - `prompts/ch03_rctf_prompts.md`
  - RCTF 프롬프트 3종
  - 프롬프트 개선 기록

## 2부 문헌과 연구설계

### 제4장 AI PDF 독해

- 실습 목표: NotebookLM과 SciSpace를 활용해 논문 PDF를 읽고 근거 중심으로 정리한다.
- 수행 작업:
  - 관련 논문 PDF 5편 이상 준비
  - NotebookLM에 업로드 후 핵심 질문 입력
  - SciSpace로 논문별 비교표 생성
  - 연구 갭 1문장 도출
- 산출물:
  - `worksheets/ch04_pdf_reading_table.md`
  - 논문 5편 요약표
  - 연구 갭 1문장

### 제5장 Zotero 인용관리

- 실습 목표: Zotero로 참고문헌을 수집하고 본문 인용 샘플을 만든다.
- 수행 작업:
  - Zotero 컬렉션 생성
  - 논문 PDF와 메타데이터 정리
  - APA 또는 학교 지정 양식으로 인용 삽입
  - 잘못된 DOI, 저자명, 학술지명 점검
- 산출물:
  - `worksheets/ch05_zotero_library_check.md`
  - Zotero 컬렉션 1개
  - 본문 인용 샘플 3개
  - 참고문헌 목록 샘플

### 제6장 연구 트렌드 탐색

- 실습 목표: 최신 연구·시장 트렌드를 탐색해 연구문제와 키워드 트리를 만든다.
- 수행 작업:
  - Perplexity, Gemini, Grok, Genspark 중 2개 이상 사용
  - 최근 논문, 정책, 시장 자료 검색
  - 학술 갭과 시장 문제를 구분
  - 키워드 트리 작성
- 산출물:
  - `worksheets/ch06_trend_report.md`
  - 트렌드 리포트 3페이지
  - 키워드 트리
  - 연구질문 3개

### 제7장 IMRaD 2.0 설계

- 실습 목표: 연구질문, 가설, 방법론, 사업화 항목이 연결되는 논문 구조를 설계한다.
- 수행 작업:
  - IMRaD 구조로 논문 목차 초안 작성
  - 연구질문과 방법론 정합성 점검
  - 논문 목차를 사업계획서 항목으로 변환
  - Claude Projects 또는 긴 컨텍스트 도구에 누적 자료 투입
- 산출물:
  - `worksheets/ch07_imrad_outline.md`
  - 논문 목차 초안
  - 섹션별 개요
