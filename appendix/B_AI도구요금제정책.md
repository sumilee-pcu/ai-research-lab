## 2. 요금제 고를 때 체크리스트 (연구자 관점)

아래 항목을 공식 요금 페이지에서 직접 확인하십시오.

### 2-1. 기능·용량 관련
- [ ] **컨텍스트 창(Context Window)**: 한 번에 처리할 수 있는 텍스트 길이. 긴 논문 전체를 한 번에 분석하려면 긴 컨텍스트 창이 필요함
- [ ] **파일 업로드 가능 여부 및 용량 제한**: PDF, Word 등 문서를 직접 업로드할 수 있는지, 최대 파일 크기·개수 제한
- [ ] **월별 사용량 한도**: 질의 횟수, 토큰 수, 또는 크레딧 단위로 제한이 있는지 확인
- [ ] **모델 선택 권한**: 무료 요금제에서 접근 가능한 모델과 유료 요금제에서 접근 가능한 모델의 차이

### 2-2. 데이터·프라이버시 관련
- [ ] **데이터 학습 옵트아웃(Opt-out)**: 내 대화·문서가 AI 모델 학습에 사용되는지, 설정에서 비활성화할 수 있는지
- [ ] **데이터 보존 기간**: 업로드한 파일이나 대화 기록이 서버에 얼마나 보관되는지
- [ ] **미공개 연구 데이터 취급**: 아직 발표되지 않은 연구 데이터나 원고를 입력했을 때의 기밀성 보호 여부
- [ ] **기관 계정(Teams/Enterprise) 정책**: 개인 계정과 달리 데이터 처리 방식이 다를 수 있음

### 2-3. 기관·협업 관련
- [ ] **기관 라이선스**: 소속 대학·연구소에서 단체 계약을 통해 유료 기능을 무료로 사용할 수 있는지 IT 부서에 문의
- [ ] **공유·협업 기능**: 지도교수, 공동연구자와 대화 내용이나 노트를 공유할 수 있는지
- [ ] **결제 방식**: 월별 구독(취소 가능) vs. 연간 구독(할인 가능) 차이

### 2-4. 신뢰성·검증 관련
- [ ] **출처 제공 여부**: 답변에 인용 출처를 명시하는지, 출처 링크가 실제로 유효한지
- [ ] **환각(Hallucination) 위험**: 사실 확인이 필요한 작업에 사용할 때 교차검증 필수
