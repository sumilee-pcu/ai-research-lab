## 도입: 논문 그림 4종 분류와 용도

학술 논문에 삽입되는 그림은 목적과 생성 방식에 따라 아래 4가지로 나뉜다. 각 유형은 제작 도구, 캡션 규칙, 윤리 기준이 다르므로 처음부터 유형을 확정하고 작업해야 한다.

| 유형 | 한국어 명칭 | 주요 목적 | 생성 방식 | 윤리 민감도 |
|------|------------|----------|----------|-----------|
| **Type A** | 시스템 다이어그램 | 연구 모델·프레임워크·아키텍처 구조 설명 | AI 생성 / 드로잉 도구 | 중간 — 개념적 그림이지만 내용 정확성 필요 |
| **Type B** | 정보형 인포그래픽 | 절차·비교·요약 정보를 시각적으로 전달 | AI 생성 / 디자인 도구 | 중간 — 정보 왜곡 금지 |
| **Type C** | 설명용 이미지 | 현상·개념·사례를 직관적으로 묘사 | AI 생성 / 사진 / 스크린샷 | 중간 — 출처·저작권 확인 필수 |
| **Type D** | 정량 데이터 그래프 | 실제 수집 데이터를 수치로 표현 | **코드 기반 필수** (matplotlib 등) | **높음 — 데이터 위조·조작 절대 금지** |

> **규칙 요약:** Type A·B·C는 AI 이미지 생성 도구를 사용할 수 있다. **Type D는 반드시 실제 데이터와 코드로 생성해야 하며, AI 이미지 생성으로 제작하는 것은 연구 윤리 위반이다.**

## Type A. 시스템 다이어그램

### 언제 쓰나

- 연구 프레임워크, 개념 모델, 소프트웨어 아키텍처, 실험 설계 흐름을 한 눈에 보여줄 때
- 텍스트만으로 설명하기 어려운 구성 요소 간 관계를 도식화할 때

### 추천 도구

| 도구 | 특징 | 비용 |
|------|------|------|
| draw.io (diagrams.net) | 무료, 웹/데스크톱, 다양한 도형 라이브러리 | 무료 |
| Lucidchart | 협업 기능 강력 | 유료(무료 플랜 제한) |
| Canva (AI 다이어그램) | 빠른 초안 생성, AI 레이아웃 제안 | 무료/유료 |
| Mermaid (코드 기반) | 마크다운 내 텍스트로 다이어그램 생성, 버전 관리 가능 | 무료 |
| Microsoft Visio | 기업·학교 라이선스 환경 | 유료 |

### 입력 자료

- 연구 모델의 구성 요소 목록
- 요소 간 관계(방향, 흐름, 계층)를 기술한 메모 또는 텍스트 설명
- 참고할 선행 연구 다이어그램 (저작권 확인 후 참고만)

### 캡션 양식 (APA 7판)

```
Figure [번호]
[간결한 제목, 첫 글자만 대문자, 이탤릭체]
[설명 문장: 그림이 나타내는 내용을 1–3문장으로 서술.]
[필요시] Note. [저작권 표시 또는 AI 생성 명시]
```

**예시:**

```
Figure 2
연구 프레임워크 개요
본 그림은 데이터 수집, 전처리, 분석, 해석의 네 단계로 구성된 연구 프레임워크를 나타낸다.
Note. Canva(버전 2.0)를 사용하여 생성한 AI 보조 다이어그램임. 초안 프롬프트: "사각형 4개로 구성된 연구 흐름도, 화살표 연결".
```

### 검증 체크

- [ ] 구성 요소 명칭이 본문과 일치하는가
- [ ] 흐름 방향이 논리적으로 타당한가
- [ ] AI 생성 도구를 사용했다면 캡션에 도구명과 프롬프트를 명시했는가
- [ ] 선행 연구 다이어그램을 참고했다면 출처를 주석에 표기했는가

### 생성 방법

**AI 생성 보조 (허용):** Canva AI, ChatGPT DALL-E 등으로 초안을 생성하고 draw.io에서 수정

**Mermaid 코드 기반 (권장):**

```mermaid
flowchart LR
    A[데이터 수집] --> B[전처리]
    B --> C[분석]
    C --> D[결과 해석]
    D --> E[논문 작성]
```

## Type D. 정량 데이터 그래프

> **핵심 윤리 규칙**
>
> **실제 연구 결과를 나타내는 그래프는 절대로 AI 이미지 생성 도구(DALL-E, Midjourney 등)로 만들어서는 안 된다.** 이는 데이터 위조에 해당하며 연구 부정행위(research misconduct)로 간주된다.
>
> 정량 그래프는 반드시:
> 1. 실제로 수집·측정한 데이터를 사용하고,
> 2. matplotlib, seaborn, ggplot2 등 **코드로 생성**하며,
> 3. 원본 데이터 파일과 생성 코드를 보관·공개해야 한다.

### 언제 쓰나

- 변수 간 비교, 분포, 추세, 관계를 수치로 보여줄 때
- 논문 결과(Results) 섹션에 삽입하는 모든 수치 시각화

### 추천 도구

| 도구 | 언어 | 특징 |
|------|------|------|
| matplotlib | Python | 가장 범용적, 세밀한 커스터마이징 |
| seaborn | Python | 통계 시각화 특화, 코드 간결 |
| ggplot2 | R | R 사용자 표준, 출판 품질 |
| Plotly | Python/R/JS | 인터랙티브 그래프 |
| JASP / SPSS | GUI | 코딩 없이 기본 그래프 |

### 입력 자료

- 실제 수집·측정한 원본 데이터 파일 (CSV, Excel 등)
- 분석 결과 수치 (평균, 표준편차, p값 등)
- 그래프 종류 결정 기준: 비교→막대, 분포→히스토그램/박스플롯, 관계→산점도, 추세→선그래프

### 캡션 양식 (APA 7판)

```
Figure [번호]
[간결한 제목, 이탤릭체]
[그래프가 나타내는 내용, 축 설명, 표본 크기, 오차 막대 의미 등을 포함한 1–3문장]
Note. [통계적 유의성, 사후 검정 결과, 데이터 출처 등]
```

**예시:**

```
Figure 6
집단별 사전-사후 점수 비교 (막대그래프)
본 그래프는 실험 집단(n = 32)과 통제 집단(n = 31)의 사전검사와 사후검사 평균 점수를 나타낸다. 오차 막대는 95% 신뢰 구간을 의미한다.
Note. 집단 간 사후검사 점수 차이는 통계적으로 유의하였다, t(61) = 3.24, p = .002.
```

## 정량 그래프용 Python 코드 스니펫

### 스니펫 1: 집단 비교 막대그래프

> 연결 파일: `../code/` 디렉터리의 분석 코드 예시 참조

```python
"""
논문용 집단 비교 막대그래프 (APA 스타일)
- 실제 데이터를 data 딕셔너리 또는 CSV 파일로 교체하여 사용
- 한글 폰트: Windows에서는 'Malgun Gothic', macOS는 'AppleGothic' 사용
"""

import matplotlib.pyplot as plt
import matplotlib.font_manager as fm
import numpy as np

# 한글 폰트 설정 (운영체제에 맞게 수정)
plt.rcParams['font.family'] = 'Malgun Gothic'   # Windows
# plt.rcParams['font.family'] = 'AppleGothic'   # macOS (주석 해제)
plt.rcParams['axes.unicode_minus'] = False       # 마이너스 기호 깨짐 방지

# ── 실제 데이터로 교체할 부분 ──────────────────────────────────────────────────
# 예시 데이터: 두 집단의 사전/사후 점수 평균과 표준오차
groups = ['실험 집단', '통제 집단']
pre_means  = [52.3, 51.8]   # 사전검사 평균 (실제 데이터로 교체)
post_means = [74.6, 58.2]   # 사후검사 평균 (실제 데이터로 교체)
pre_se     = [2.1, 1.9]     # 사전검사 표준오차 (실제 데이터로 교체)
post_se    = [2.4, 2.0]     # 사후검사 표준오차 (실제 데이터로 교체)
# ─────────────────────────────────────────────────────────────────────────────

x = np.arange(len(groups))
width = 0.35  # 막대 너비

fig, ax = plt.subplots(figsize=(7, 5), dpi=300)  # 300dpi: 논문 투고 기준

bars1 = ax.bar(x - width/2, pre_means,  width, yerr=pre_se,
               label='사전검사', color='#4C72B0', capsize=5,
               error_kw={'elinewidth': 1.2})
bars2 = ax.bar(x + width/2, post_means, width, yerr=post_se,
               label='사후검사', color='#DD8452', capsize=5,
               error_kw={'elinewidth': 1.2})

# 축·레이블 설정
ax.set_xlabel('집단', fontsize=12)
ax.set_ylabel('평균 점수', fontsize=12)
ax.set_title('집단별 사전-사후 점수 비교', fontsize=13, fontweight='bold')
ax.set_xticks(x)
ax.set_xticklabels(groups, fontsize=11)
ax.set_ylim(0, 90)
ax.legend(fontsize=11)
ax.spines['top'].set_visible(False)    # 상단 테두리 제거 (APA 스타일)
ax.spines['right'].set_visible(False)  # 우측 테두리 제거 (APA 스타일)

plt.tight_layout()
plt.savefig('figure6_bar_comparison.png', dpi=300, bbox_inches='tight')
plt.savefig('figure6_bar_comparison.pdf', bbox_inches='tight')  # 벡터 형식 추가 저장
plt.show()
print("저장 완료: figure6_bar_comparison.png / .pdf")
```

### 스니펫 2: 분포 비교 박스플롯

> 연결 파일: `../code/` 디렉터리의 boxplot 예시 참조

```python
"""
논문용 집단 분포 비교 박스플롯 (APA 스타일)
- 원시 데이터(raw_data)를 실제 측정값 배열로 교체하여 사용
- 박스플롯은 분포의 중앙값·사분위수·이상값을 함께 보여줌
- 한글 폰트: Windows에서는 'Malgun Gothic', macOS는 'AppleGothic' 사용
"""

import matplotlib.pyplot as plt
import numpy as np

# 한글 폰트 설정
plt.rcParams['font.family'] = 'Malgun Gothic'   # Windows
# plt.rcParams['font.family'] = 'AppleGothic'   # macOS (주석 해제)
plt.rcParams['axes.unicode_minus'] = False

# ── 실제 데이터로 교체할 부분 ──────────────────────────────────────────────────
# 예시: 세 처치 조건의 반응 시간(ms) 측정값
np.random.seed(42)  # 재현 가능성 확보 — 실제 분석에서는 제거
condition_A = np.random.normal(520, 45, 30).tolist()  # 조건 A (실제 데이터로 교체)
condition_B = np.random.normal(480, 60, 30).tolist()  # 조건 B (실제 데이터로 교체)
condition_C = np.random.normal(610, 55, 30).tolist()  # 조건 C (실제 데이터로 교체)
raw_data = [condition_A, condition_B, condition_C]
labels   = ['조건 A', '조건 B', '조건 C']
# ─────────────────────────────────────────────────────────────────────────────

fig, ax = plt.subplots(figsize=(7, 5), dpi=300)

bp = ax.boxplot(raw_data, labels=labels, patch_artist=True,
                medianprops={'color': 'black', 'linewidth': 2})

# 박스 색상 지정 (흑백 인쇄 시에도 구분 가능하도록 해치 패턴 권장)
colors  = ['#AEC6CF', '#FFD1DC', '#C3E6CB']
hatches = ['/', '\\', 'x']  # 흑백 인쇄 구분용 해치
for patch, color, hatch in zip(bp['boxes'], colors, hatches):
    patch.set_facecolor(color)
    patch.set_hatch(hatch)

# 개별 데이터 포인트 오버레이 (투명도 조정으로 겹침 표현)
for i, data in enumerate(raw_data, start=1):
    x_jitter = np.random.normal(i, 0.05, len(data))  # 점 분산
    ax.scatter(x_jitter, data, alpha=0.4, s=15, color='gray', zorder=3)

ax.set_xlabel('처치 조건', fontsize=12)
ax.set_ylabel('반응 시간 (ms)', fontsize=12)
ax.set_title('처치 조건별 반응 시간 분포', fontsize=13, fontweight='bold')
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)

plt.tight_layout()
plt.savefig('figure7_boxplot.png', dpi=300, bbox_inches='tight')
plt.savefig('figure7_boxplot.pdf', bbox_inches='tight')
plt.show()
print("저장 완료: figure7_boxplot.png / .pdf")
```

## APA 그림 캡션 작성 규칙

APA 7판은 그림 캡션을 그림 **아래**에 배치하며, 네 요소로 구성한다.

| 요소 | 형식 | 예시 |
|------|------|------|
| **그림 번호** | 굵은체, "Figure N." | **Figure 4.** |
| **제목** | 이탤릭체, 첫 단어만 대문자, 마침표 | *집단별 사전-사후 점수 비교.* |
| **설명** | 일반 글자체, 그림이 나타내는 내용 서술, 마침표 | 실험 집단(n = 32)과 통제 집단(n = 31)의 평균 점수를 나타낸다. 오차 막대는 95% CI이다. |
| **주석(Note)** | "Note." 굵은체 + 이탤릭, 이후 일반 글자체 | **Note.** 두 집단 간 사후검사 점수 차이는 유의하였다, t(61) = 3.24, p = .002. |

### 캡션에 반드시 포함해야 하는 정보

- **그림 번호:** 논문 전체에서 Figure 1, 2, 3... 순서로 연속 번호 부여
- **오차 막대:** 표준오차(SE), 표준편차(SD), 신뢰구간(CI) 중 무엇인지 명시
- **통계 정보:** 유의한 집단 차이가 있다면 검정 통계량과 p값 기재
- **AI 생성 명시:** AI 이미지 생성 도구를 사용했다면 Note에 도구명·버전·프롬프트 요약 기재
- **출처:** 선행 연구의 그림을 수정하거나 재사용한 경우 원저작자와 출처 표기

### APA 7판 캡션 전체 예시

```
Figure 6
집단별 사전-사후 점수 비교
본 그래프는 실험 집단(n = 32)과 통제 집단(n = 31)의 사전검사와 사후검사 평균 점수를 나타낸다. 오차 막대는 95% 신뢰 구간을 의미한다.
Note. 두 집단 간 사후검사 점수 차이는 통계적으로 유의하였다, t(61) = 3.24, p = .002, d = 0.82.
```

## 그림 제출 전 체크리스트

### 기술 품질

- [ ] 해상도 300 dpi 이상 (래스터 이미지 기준; 벡터 PDF 권장)
- [ ] 이미지 크기: 학술지 컬럼 너비(단단 약 85mm, 양단 약 170mm) 맞춤
- [ ] 파일 형식: TIFF 또는 EPS(학술지 투고용) / PNG+PDF(프리프린트·일반 제출용)
- [ ] 글꼴이 이미지에 임베드되어 있는가 (PDF 저장 시 폰트 포함 옵션 확인)

### 시각적 접근성

- [ ] 흑백 인쇄 시에도 각 요소가 구분 가능한가 (색맹·흑백 호환)
- [ ] 색상 외에도 해치(빗금), 선 종류, 마커 모양으로 구분하는가
- [ ] 텍스트 최소 크기 8pt 이상인가 (인쇄 후 측정)
- [ ] 범례 텍스트가 충분히 크고 읽기 쉬운가

### 내용 정확성

- [ ] 그래프 수치가 본문 및 표의 수치와 일치하는가
- [ ] 축 레이블과 단위가 명확하게 표기되어 있는가
- [ ] 오차 막대의 종류(SE, SD, CI)가 캡션에 명시되어 있는가
- [ ] 통계적 유의성 표시(*, **, *** 또는 p값)가 정확한가
- [ ] N(표본 수)이 캡션 또는 그림에 표시되어 있는가

### 캡션 자기완결성

- [ ] 그림만 단독으로 봐도 내용을 이해할 수 있는가
- [ ] 약어가 처음 등장 시 풀어서 설명되어 있는가
- [ ] APA 7판 캡션 형식(번호·제목·설명·주석)을 갖추고 있는가

- [ ] 타인의 그림을 수정·재사용한 경우 원저작자 허가를 받았는가
- [ ] 출처 표기(출처, 연도, 페이지/그림 번호, 저작권 진술)가 캡션에 있는가
- [ ] AI 이미지 생성 도구를 사용했다면 도구명·버전·프롬프트가 캡션 주석에 있는가
- [ ] 정량 데이터 그래프는 코드 기반으로 생성했는가 (AI 이미지 생성 아님 확인)
- [ ] 생성 코드와 원본 데이터가 저장·공개 준비가 되어 있는가

- [ ] 컬러 그림 추가 비용이 발생하는 학술지라면 흑백 대안을 준비했는가
