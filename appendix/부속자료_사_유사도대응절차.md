## 2. 핵심 원칙: 수치보다 "어디가 왜 겹쳤나"

유사도 수치(%)는 문제의 심각도를 직접 나타내지 않습니다.

- **높은 수치가 반드시 표절을 의미하지 않습니다.** 인용 부호·출처를 정확히 표기한 직접 인용, 연구방법 정형구, 참고문헌 목록은 수치를 높이지만 윤리적으로 문제가 없습니다.
- **낮은 수치가 반드시 안전을 의미하지 않습니다.** 아이디어 도용이나 의역 표절은 단어가 달라 수치가 낮아도 심각한 윤리 위반입니다.
- 보고서를 받으면 수치를 보기 전에 **겹친 부분의 출처와 맥락**을 먼저 확인하십시오.

## 3. 유사도 보고서 읽는 법

### 3-1. 화면 구성 이해

- **색상 코드**: 출처별로 다른 색상이 배정됨. 하나의 색 = 하나의 출처 문서
- **우측 패널 / 소스 목록**: 각 출처별 겹침 비율 표시; 클릭하면 해당 문단으로 이동
- **전체 유사도 수치**: 참고문헌·인용구 포함 수치와 제외 수치가 다를 수 있음

### 3-2. 제외 설정 확인

많은 도구에서 아래 항목을 제외하고 재계산할 수 있습니다. 기관 규정에 따라 적절히 활용하십시오.

- 인용문(따옴표 처리된 구절)
- 참고문헌 목록
- 소수(예: 5단어 이하) 일치 구절
- 출처가 명확한 인용 블록

> 제외 설정 사용 여부도 기관 지침을 따르십시오. [확인 필요]

## 4. 겹침 유형별 대응 표

| 겹침 유형 | 설명 | 대응 방법 |
|---|---|---|
| **직접 인용 누락** | 타인 문장을 그대로 옮겼으나 인용 부호·출처 미표기 | 인용 부호(" ") 추가 + 출처 표기; 또는 내용을 자신의 말로 완전히 재서술 후 출처 각주 |
| **흔한 표현·공용어구** | 학문 분야의 정형 표현, 공식 명칭, 법령 문구 등 | 문제없음; 보고서에서 해당 부분 확인 후 무시 가능 (단, 기관 규정 확인) |
| **자기표절(자기 이전 저작물 중복)** | 자신의 이전 논문·보고서와 겹침 | 이전 저작물임을 명시적으로 밝히고 출처 인용; 상당 부분 중복이면 내용 재서술 또는 기관에 사전 확인 [확인 필요] |
| **방법론 정형구** | "본 연구는 … 방법을 사용하였다" 류의 관용 표현 | 대부분 문제없음; 필요하면 동의어·문장 구조 변형으로 최소화 |
| **참고문헌 목록** | 참고문헌이 겹침 항목으로 잡힘 | 도구에서 "참고문헌 제외" 설정 적용; 설정 불가 시 기관에 해당 수치 설명 |
| **의역·아이디어 도용** | 단어는 바꿨으나 타인 아이디어를 출처 없이 사용 | 수치에 잡히지 않아도 표절; 반드시 출처 추가 |
| **AI 생성 텍스트 유사** | 여러 사람이 같은 AI 프롬프트를 쓸 경우 문장 유사 | 자신의 언어로 충분히 재작성; AI 활용 여부 기관 규정에 따라 공개 [확인 필요] |

## 5. 연구윤리 원칙

### 5-1. 표절·자기표절

- **표절**: 타인의 아이디어, 자료, 표현을 출처를 밝히지 않고 자신의 것처럼 사용하는 행위
- **자기표절**: 자신의 이전 출판물을 출처 표기 없이 재사용하는 행위. 학술지마다 허용 범위가 다르므로 투고 전 확인 필요 [확인 필요]
- 두 경우 모두 의도 여부와 무관하게 윤리 위반으로 처리될 수 있습니다.

### 5-2. AI 생성 텍스트 관련

- AI가 작성한 텍스트를 그대로 제출하면 일부 기관에서는 표절에 준하여 처리합니다.
- AI 활용 사실 공개 의무 여부는 기관·학술지마다 다릅니다. [확인 필요]
- **논문의 모든 내용에 대한 학문적 책임은 연구자 본인에게 있습니다.** AI는 도구이며, AI가 생성한 오류·허위 정보도 연구자 책임입니다.
- AI 활용 여부와 무관하게, 제출 전 내용의 사실 정확성·출처를 직접 검증하십시오.

### 5-3. 기관 규정 우선

이 자료는 일반적인 지침을 제공합니다. 소속 기관, 제출 학술지, 연구과제의 규정이 이 자료보다 우선합니다.
