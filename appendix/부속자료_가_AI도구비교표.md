## 1. 연구 작업별 추천 도구 매트릭스

> 최종 확인: 2026-06-08, 실제 요금·정책은 공식 페이지에서 재확인

### 1-1. 문헌 요약

| 도구 | 강점 | 한계 | 교차검증 추천 |
|------|------|------|---------------|
| ChatGPT | 자연스러운 요약문 생성; 다양한 형식(개조식·단락) 조정 가능 | 오래된 논문 내용을 학습 데이터 기반으로 요약 시 최신성 부족 가능; 출처 명시 불안정 | Perplexity로 최신 출처 재확인 |
| Claude | 긴 PDF 전체를 한 번에 처리 가능(긴 컨텍스트 강점); 논리 구조 파악 우수 | 인터넷 실시간 검색 미지원(지식 컷오프 존재) [확인 필요] | NotebookLM에 같은 문서 업로드 후 비교 |
| NotebookLM | 업로드한 문서 안에서만 답변(환각 위험 낮음); 출처 인용 명확 | 외부 정보 결합 불가; 기능이 제한적 | ChatGPT·Claude로 더 넓은 맥락 보완 |
| SciSpace | 논문 PDF 직접 분석; 수식·방법론 설명 특화 | 일반 텍스트 요약 품질은 범용 모델보다 낮을 수 있음 | ChatGPT로 요약 재정리 |

### 1-2. 문헌 검색

| 도구 | 강점 | 한계 | 교차검증 추천 |
|------|------|------|---------------|
| Perplexity AI | 실시간 웹 검색 + 출처 링크 제공; 최신 논문·뉴스 탐색 | 출처 링크가 간혹 오류 또는 비학술 자료 혼입 | 제시된 논문을 Google Scholar·PubMed에서 직접 확인 |
| SciSpace | 학술 논문 데이터베이스 특화 검색; 관련 논문 추천 | 특정 데이터베이스에 한정; 비영어권 논문 커버리지 낮을 수 있음 | Zotero로 수집 후 원문 접근 |
| Gemini | Google Scholar 연동 가능성; 멀티모달 검색 | 학술 검색 특화 기능은 전용 DB 대비 제한적 | Perplexity로 보완 |
| ChatGPT | 연구 주제 관련 핵심어 생성·확장에 유용 | 실시간 검색 미지원(별도 웹 검색 도구 필요) [확인 필요] | Perplexity로 실제 검색 수행 |

### 1-3. 번역·언어 교정

| 도구 | 강점 | 한계 | 교차검증 추천 |
|------|------|------|---------------|
| ChatGPT | 학술 문체 조정 요청 가능; 특정 저널 스타일 지정 번역 | 전문 용어 번역 오류 가능; 번역 후 전문가 검토 필수 | Claude로 동일 단락 재번역 후 비교 |
| Claude | 긴 문서 일관된 문체로 번역; 논리 흐름 유지 우수 | 특정 분야 최신 전문용어는 학습 데이터에 따라 오류 가능 | 분야 전문가 검토 병행 필수 |
| DeepL (참고) | 번역 품질 높음; 유럽어 강점 | AI 생성 텍스트 교정 기능은 제한적 | 전문 번역 시 1순위 고려 |
| Gemini | 한국어-영어 번역 품질 양호; Google 서비스 연동 | 문체 세밀 조정은 ChatGPT·Claude보다 불편할 수 있음 | ChatGPT로 교정 보완 |

### 1-4. 코드 작성·데이터 분석

| 도구 | 강점 | 한계 | 교차검증 추천 |
|------|------|------|---------------|
| ChatGPT | 코드 실행 환경(Data Analysis 기능) 제공 [확인 필요]; Python·R 코드 생성 | 코드 오류 발생 시 자동 수정 시도하나 논리 오류는 간과 가능 | 생성된 코드를 로컬 환경에서 직접 실행·검증 필수 |
| Claude | 코드 설명 상세; 긴 코드 리뷰·리팩토링 강점 | 직접 코드 실행 불가 [확인 필요] | ChatGPT Code Interpreter와 병행 |
| Gemini | Google Colab 연동 가능성; 데이터 시각화 보조 [확인 필요] | 복잡한 통계 코드는 오류 검토 필수 | 로컬 실행으로 검증 |
| Perplexity | 코드 관련 최신 라이브러리·문서 검색 | 코드 생성보다 검색에 특화 | ChatGPT·Claude로 실제 코드 작성 |

### 1-5. 시각화 보조

| 도구 | 강점 | 한계 | 교차검증 추천 |
|------|------|------|---------------|
| ChatGPT | matplotlib, ggplot2 등 시각화 코드 생성; 샘플 데이터로 즉시 실행 가능 [확인 필요] | 디자인 세밀 조정 시 반복 프롬프트 필요 | 실제 데이터로 로컬 실행 후 수동 수정 |
| Claude | 시각화 코드 논리 설명 우수; 적합한 차트 유형 추천 | 직접 이미지 생성 불가; 코드 기반으로만 제공 | ChatGPT Code Interpreter로 실행 확인 |
| Gemini | 이미지 분석 후 유사 시각화 제안 가능(멀티모달) | 복잡한 학술 그래프 생성 코드 품질은 ChatGPT 대비 미확인 [확인 필요] | 결과물은 항상 로컬에서 검증 |

### 1-6. 인용 관리

| 도구 | 강점 | 한계 | 교차검증 추천 |
|------|------|------|---------------|
| Zotero | 무료 오픈소스; Word·LibreOffice 플러그인; 다양한 인용 스타일(APA, MLA, Chicago 등) 자동 생성 | 인터넷 메타데이터 불완전 시 수동 수정 필요 | 학술 DB(DOI)에서 직접 메타데이터 가져오기 권장 |
| SciSpace | 논문 내 참고문헌 자동 추출·정리 | Zotero 등 전용 인용 관리 프로그램의 기능 깊이에는 미치지 못함 | Zotero와 병행 사용 |
| ChatGPT | 인용 형식 변환(스타일 간 변환) 보조 | AI가 생성한 인용은 반드시 원문 확인 필수: 저자·연도·제목 오류 빈번 | 모든 인용을 Zotero 또는 원문에서 검증 |

## 2. 1순위/2순위 교차검증 권장 조합 예시

> 단일 도구의 출력만 신뢰하지 말고, 아래 조합으로 교차검증하십시오.

| 연구 작업 | 1순위 (주 작업) | 2순위 (검증·보완) | 교차검증 포인트 |
|-----------|----------------|-------------------|----------------|
| 논문 문헌 요약 | NotebookLM (업로드 문서 기반) | Claude (긴 PDF 통합 분석) | 두 요약 간 핵심 주장 차이 확인; 원문 대조 필수 |
| 최신 문헌 탐색 | Perplexity AI (실시간 검색) | Google Scholar / PubMed (직접 검색) | AI 제시 출처가 실제 존재하는지 학술 DB에서 확인 |
| 연구 주제 확장 | ChatGPT (아이디어 브레인스토밍) | Perplexity (실제 연구 동향 검색) | AI 제안이 실제 학계 연구와 일치하는지 확인 |
| 논문 초안 작성 | Claude (긴 맥락 일관성 유지) | ChatGPT (문체·형식 다듬기) | 두 결과 모두 연구자가 직접 편집; AI 문장 그대로 사용 지양 |
| 통계 코드 작성 | ChatGPT (코드 생성 + 실행) | Claude (코드 논리 검토) | 실제 데이터로 로컬 실행; 결과값 합리성 검토 |
| 인용 목록 관리 | Zotero (공식 메타데이터 수집) | SciSpace (논문 내 참고문헌 추출 보조) | 최종 인용은 반드시 원문·DOI 기반으로 검증 |
| 영문 초안 번역·교정 | ChatGPT (초벌 번역) | Claude (문체 일관성 검토) | 전문 용어는 분야 사전 및 기출판 논문과 대조 |

## 3. 도구 선택 의사결정 흐름

아래 흐름에 따라 작업에 맞는 도구를 선택하십시오.

```
[시작: 지금 하려는 작업은 무엇인가?]
          |
          |---> [인용 관리 / 참고문헌 목록 정리]
          |           → Zotero 사용 (전용 도구 최우선)
          |           → 보완: SciSpace (논문 내 참고문헌 추출)
          |
          |---> [논문 PDF 읽기 / 내용 파악]
          |           |
          |           |--> 파일 1~3개, 내용 범위 한정
          |           |         → NotebookLM (업로드 문서 한정, 환각 낮음)
          |           |
          |           |--> 파일이 길거나 여러 개 통합 분석 필요
          |                     → Claude (긴 컨텍스트 활용)
          |                     → 보완: SciSpace (학술 논문 특화)
          |
          |---> [최신 연구 동향 검색 / 출처 있는 정보 필요]
          |           → Perplexity AI (실시간 검색 + 출처 제공)
          |           → 반드시 Google Scholar / PubMed 교차검증
          |
          |---> [글쓰기 보조 / 초안·요약문 생성]
          |           |
          |           |--> 한국어 논문, 긴 문서 일관성 중요
          |           |         → Claude
          |           |
          |           |--> 다양한 형식·스타일 실험, 짧은 단락
          |                     → ChatGPT
          |
          |---> [데이터 분석 / 코드 작성]
          |           → ChatGPT (코드 생성·실행 환경) [요금제 확인 필요]
          |           → 보완: Claude (코드 논리 검토)
          |           → 최종: 반드시 로컬 환경에서 직접 실행·검증
          |
          |---> [번역 / 영문 교정]
          |           → ChatGPT 또는 Claude (초벌)
          |           → 전문용어는 분야 전문가 또는 기출판 논문 대조 필수
          |
          |---> [이미지·표 분석 / 멀티모달 작업]
                      → Gemini (멀티모달 강점)
                      → 보완: ChatGPT (분석 결과 해석 보조)
```

## 4. 공통 주의사항

| 항목 | 내용 |
|------|------|
| 환각(Hallucination) 위험 | 모든 AI 도구는 사실처럼 보이지만 틀린 정보를 생성할 수 있음. 특히 인용·통계·날짜는 반드시 원문 확인 |
| 저작권 | AI가 생성한 텍스트를 논문에 사용할 때 소속 기관·투고 저널의 AI 공시 정책 확인 필수 [확인 필요] |
| 데이터 보안 | 미공개 연구 데이터·원고는 AI 도구에 입력 전 데이터 학습 옵트아웃 설정 확인 |
| 최신성 | AI 모델의 지식 컷오프 이후 발표된 연구는 AI가 모를 수 있음. 최신 연구는 Perplexity·학술 DB 직접 검색 병행 |
| 단독 사용 지양 | 어떤 도구도 단독으로 사용하지 말고, 항상 교차검증 + 연구자 직접 판단 병행 |
