# 부록 E. 연구자의 5대 활용 트랙 비교표

> **연결 장:** 제13장 &nbsp;|&nbsp; **연결 프롬프트:** [P-13](../prompts/P13_사업화.md) &nbsp;|&nbsp; **워크북:** [W-8](../workbook/W8_연구성과사업화전략.md)

## 도입: 하나의 연구주제, 다섯 갈래의 확장

이 책은 **연구자·직장인·창업가·학습자**라는 4중 역할을 누적하며 역량을 쌓는 학습 모델을 제안한다. 제13장에서 강조했듯, 하나의 연구주제는 "어디로 가져가느냐"에 따라 전혀 다른 성과물로 변환된다. 예를 들어 "소규모 제조업의 AI 도입 장벽"이라는 한 문장은 다음 다섯 갈래로 뻗어 나간다.

| 갈래 | 변환된 산출물 예시 |
|------|-------------------|
| 학술 트랙 | KCI 등재 논문 「중소제조업 AI 수용 저해 요인의 구조적 분석」 |
| 학위 트랙 | 석사 학위논문 (이론·방법론 심화) |
| 사업화 트랙 | 린 캔버스 + IR 덱 「AI 도입 컨설팅 스타트업」 |
| 정부과제 트랙 | R&D 제안서 「제조 중소기업 AI 전환 지원 모델 개발」 |
| 실무·커리어 트랙 | 사내 혁신 보고서 / 이직 포트폴리오 / 전문가 칼럼 |

핵심 메시지: **연구 내용을 새로 만들지 않아도 된다.** 프레임·언어·강조점만 바꾸면 동일한 지식 자산이 여러 트랙에서 작동한다.

## 5대 트랙 비교표

> 기간·수치는 일반적인 경험치이며 개인·분야·기관에 따라 크게 달라질 수 있다. [확인 필요]

| 구분 | 학술 트랙 | 학위 트랙 | 사업화 트랙 | 정부과제 트랙 | 실무·커리어 트랙 |
|------|-----------|-----------|-------------|---------------|-----------------|
| **목표 산출물** | 학술지 논문, 학회 발표 논문 | 학위논문 (석·박사) | 창업 계획서, 린 캔버스, IR 덱, 사업자 등록 | R&D·창업 지원 제안서, 보조금 신청서 | 사내 보고서, 이직 포트폴리오, 전문 칼럼·강의 |
| **핵심 평가 기준** | 독창성, 이론 기여, 방법론 엄밀성, 동료 심사 통과 | 이론적 깊이, 방법론 완결성, 심사위원회 승인 | 시장성, 수익 모델 실현 가능성, 팀 역량 | 과제 적합성, 연구 역량(논문·특허), 예산 타당성 | 현업 적용 가능성, 이해관계자 설득력, 가독성 |
| **소요 기간 (일반론)** | 투고~게재 6개월–2년 [확인 필요] | 석사 1–3년, 박사 3–6년 [확인 필요] | 아이디어→MVP 3–12개월 [확인 필요] | 공고→결과 통보 2–6개월 [확인 필요] | 보고서 1–4주, 포트폴리오 구축 1–3개월 [확인 필요] |
| **필요 역량** | 문헌 리뷰, 통계·질적 연구 방법론, 학술 글쓰기 | 학술 트랙 역량 + 장기 자기관리, 지도 교수 커뮤니케이션 | 고객 인터뷰, 재무 모델링, 피칭, 네트워킹 | 정책 이해, 예산 작성, 컨소시엄 구성, 과제 관리 | 비즈니스 글쓰기, 데이터 시각화, 스토리텔링, 직무 역량 |
| **AI 활용 포인트** | 문헌 검색·요약, 초고 작성, 통계 코드 생성, 교정 | 챕터 구조 설계, 선행연구 매핑, 논증 점검, 일정 관리 | 고객 세그먼트 분석, IR 덱 초안, 시장 규모 추정 보조 | 유사 과제 사례 검색, 제안서 초안, 예산 항목 점검 | 보고서 요약·시각화 자동화, 커버레터 초안, 강의 자료 생성 |
| **대표 위험** | 심사 지연·게재 거절, 연구 윤리 위반 | 지도 교수 변경, 장기 소진(burn-out), 졸업 요건 미달 | 시장 오검증, 자금 소진, 공동창업자 갈등 | 선정 탈락, 과제 수행 중 요건 변경, 정산 리스크 | 기밀 유출 우려, 내부 저항, 포트폴리오 차별화 부족 |

## 의사결정 가이드

아래 분기 질문에 순서대로 답하며 **가장 먼저 집중할 트랙**을 찾아라.

**Q1. 지금 나에게 마감 기한이 명확하게 정해진 외부 의무가 있는가?**
- 학위 수료 기한 → **학위 트랙 우선**
- 정부 공모전·R&D 공고 마감 → **정부과제 트랙 우선**
- 없다면 Q2로 이동

**Q2. 연구 결과를 가장 빠르게 이력서·승진·연봉에 연결해야 하는가?**
- 예 → **실무·커리어 트랙 우선**
- 아니오 → Q3으로 이동

**Q3. 연구 아이디어에 실제 고객이 돈을 낼 것이라는 가설을 검증하고 싶은가?**
- 예, 그리고 창업 의향이 있다 → **사업화 트랙 우선**
- 아이디어 검증만 원한다 → 사업화 트랙 린 캔버스 단계만 활용 후 Q4

**Q4. 연구의 학문적 기여와 동료 인정이 중요한가? (테뉴어, 연구자 정체성 등)**
- 예 → **학술 트랙 우선**
- 상대적으로 덜 중요하다 → 실무·커리어 또는 사업화 트랙 재검토

**Q5. 현재 보유한 자원(시간·예산·네트워크) 중 가장 풍부한 것은?**

| 풍부한 자원 | 권장 트랙 |
|------------|-----------|
| 시간 (1년 이상 확보) | 학위 트랙 또는 학술 트랙 |
| 네트워크 (산업계·정부 연계) | 정부과제 트랙 또는 사업화 트랙 |
| 실행 속도 (3개월 안에 성과 필요) | 실무·커리어 트랙 |
| 자본 (시드 투자 또는 자기자본) | 사업화 트랙 |

**Q6. 위 분석 후에도 두 트랙 이상이 동점이라면?**
- **실무·커리어 트랙**을 기본 트랙으로 삼고, 나머지를 병렬 추진한다. 실무 보고서는 소요 기간이 짧아 가장 빠른 피드백 루프를 제공하며, 다른 트랙의 기초 자료로도 활용할 수 있다.

## 트랙 간 재활용 매핑

동일한 연구 자산을 다른 트랙으로 옮길 때 **무엇을 바꿔야 하는지** 정리한다.

| 원본 (출발 트랙) | 목적지 트랙 | 유지되는 것 | 반드시 바꿔야 하는 것 |
|-----------------|------------|------------|----------------------|
| 논문 서론 (학술) | 사업계획서 문제 정의 | 문제의 존재 증거, 통계·인용 | 독자 변경(투자자·심사관), 학술 용어→평이한 언어, 시장 규모 추가 |
| 논문 선행연구 (학술) | R&D 제안서 기술 현황 | 기술 트렌드 요약, 참고문헌 | 정책 목적과의 연결, 국내 중심 재편, 분량 압축 |
| 학위논문 3장 방법론 | 사내 분석 보고서 | 데이터 수집·분석 방법 | APA 각주 제거, 실무 언어로 전환, 의사결정 권고 추가 |
| IR 덱 시장 분석 (사업화) | 정부과제 필요성 섹션 | 시장 규모·문제 심각성 | 수익 강조→사회적 필요성 강조, 정량 목표·KPI 추가 |
| 사내 보고서 (실무) | 학술 논문 초고 | 현장 데이터, 사례 | 이론적 프레임 추가, 방법론 명시, 동료 심사 형식 전환 |
| 정부과제 최종 보고서 | 학술지 논문 | 연구 결과·데이터 | 정책 제언→이론 기여로 전환, 분량 축소, 투고 형식 준수 |

> **핵심 원칙:** 내용(what)보다 **프레임·독자·강조점(how & for whom)**을 바꾸는 것이 재활용의 본질이다.

## 내 트랙 우선순위 — 직접 채우는 빈 표

아래 표를 복사해 자신의 연구 상황에 맞게 직접 작성한다.

| 트랙 | 적합도 (상·중·하) | 다음 행동 (구체적 1가지) | 목표 마감 |
|------|------------------|--------------------------|-----------|
| 1. 학술 트랙 | | | |
| 2. 학위 트랙 | | | |
| 3. 사업화 트랙 | | | |
| 4. 정부과제 트랙 | | | |
| 5. 실무·커리어 트랙 | | | |

**작성 팁**
- 적합도 "상"은 현재 자원·상황에서 3개월 내 첫 산출물을 낼 수 있는 트랙에 부여한다.
- "다음 행동"은 오늘 또는 이번 주 안에 실행할 수 있는 가장 작은 단위로 적는다. (예: "지도 교수 면담 예약", "린 캔버스 초안 작성", "공모전 공고 검색")
- 마감이 없는 트랙은 스스로 마감을 설정해야 진행된다.
