## 1. Zotero 기본 설정

### 1-1. 설치 순서

1. [https://www.zotero.org](https://www.zotero.org) 에서 데스크톱 앱 다운로드·설치
2. 같은 페이지에서 Zotero Connector 브라우저 확장 설치 (Chrome / Firefox / Edge / Safari 지원)
3. 무료 계정 등록 → 클라우드 동기화 활성화 (300 MB 무료, 초과 시 유료 또는 WebDAV 연동)
4. Word 플러그인은 Zotero 설치 시 자동 등록됨 (Word가 설치된 환경 필요)

### 1-2. 한국 연구자를 위한 권장 플러그인

| 플러그인 | 기능 | 비고 |
|---|---|---|
| Better BibTeX | BibTeX/BibLaTeX 내보내기, cite key 자동 생성 | LaTeX·Overleaf 사용자 필수 |
| Zotfile (구버전) / Attanger (신버전) | PDF 파일 자동 이름 변경·이동 | Zotero 7 이상은 Attanger 권장 |
| Jasminum | 한국 학술 DB(RISS, KISS, DBpia) 메타데이터 수집 보조 | 한국어 저자명 처리 개선 |
| DOI Manager | 선택 항목 일괄 DOI 조회 및 업데이트 | DOI 누락 보완에 유용 |

> 플러그인은 Zotero 메뉴 → 도구 → 부가 기능 → `.xpi` 파일 설치로 추가합니다.

## 2. HWP(한/글)·Word 연동 트러블슈팅

### 2-1. 증상 → 원인 → 해결 표

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| HWP에서 Zotero 플러그인 탭이 보이지 않는다 | Zotero 공식 플러그인이 HWP를 지원하지 않음 | ① Word로 초안 작성 후 HWP로 변환 / ② BibTeX 내보내기로 수동 삽입 / ③ 참고문헌 목록을 따로 작성해 HWP에 붙여넣기 |
| Word에서 Zotero 탭이 사라졌다 | Word 업데이트 후 플러그인 비활성화 | Zotero → 편집 → 설정 → 인용 → 워드 프로세서 → "Word용 플러그인 재설치" 클릭 |
| 본문 인용이 `[저자?, 연도?]` 처럼 물음표로 표시된다 | 필드 코드 새로 고침 필요 또는 항목 연결 끊김 | Zotero 탭 → "새로 고침(Refresh)" 클릭; 해결 안 되면 항목 삭제 후 재삽입 |
| 참고문헌 목록에 한글 저자명이 영문 이름 뒤에 온다 (정렬 오류) | 한글 유니코드 정렬 방식 차이 | 인용 스타일 CSL 파일에서 `sort` 언어 설정 수정 [확인 필요]; 또는 수동으로 목록 재정렬 |
| 영문·한국어 혼합 참고문헌 정렬이 뒤섞인다 | 기본 정렬이 알파벳 기준이라 한글이 뒤로 밀림 | KCI 스타일은 국문 문헌을 앞에 배치하도록 수동 구분 또는 CSL 커스터마이징 [확인 필요] |
| 중복 항목이 라이브러리에 생긴다 | 여러 DB에서 동일 논문을 반복 저장 | 라이브러리 탭 → 중복 항목(Duplicates) 폴더 → 병합(Merge) 버튼으로 통합 |
| DOI가 없거나 잘못 입력됐다 | 메타데이터 수집 오류 | DOI Manager 플러그인으로 일괄 조회; 또는 항목 편집창에서 직접 입력 후 "doi.org"로 유효성 확인 |
| PDF 원문이 자동 첨부되지 않는다 | 구독 인증 없이 Unpaywall/Scholar만 시도 | "Find Available PDF" 클릭 또는 기관 VPN 연결 후 재시도; 수동 PDF 첨부도 가능 |
| 동기화 충돌 오류가 발생한다 | 여러 기기에서 동시에 변경 후 동기화 | Zotero → 편집 → 설정 → 동기화 → "파일 동기화 재설정"으로 서버 버전 우선 적용 [백업 후 진행 권장] |
| 그룹 라이브러리가 보이지 않는다 | zotero.org 그룹 초대를 수락하지 않았거나 로그인 계정 불일치 | zotero.org 로그인 확인 → 그룹 초대 수락 → Zotero 앱 재시작 |

### 2-2. HWP 환경에서 참고문헌을 관리하는 현실적 대안

HWP는 Zotero 플러그인을 공식 지원하지 않습니다. 다음 중 상황에 맞는 방식을 선택하십시오.

1. Word 병행 작성법: 인용이 필요한 초안은 Word에서 Zotero로 작성 → 완성 후 HWP로 변환 → HWP에서 최종 편집
2. BibTeX 수동 삽입법: Zotero에서 BibTeX 형식으로 내보내기 → 참고문헌 목록을 별도 생성 → HWP 문서 말미에 붙여넣기
3. CSL JSON 복사법: Zotero에서 선택 항목을 원하는 스타일로 복사(단축키 Ctrl+Shift+C) → HWP에 직접 붙여넣기

## 3. 인용 양식별 빠른 참조

| 항목 | APA 7판 | IEEE | KCI (국문 일반) |
|---|---|---|---|
| 저자 표기 | 성, 이름 이니셜. (예: Kim, J.) | 이름 이니셜 성 (예: J. Kim) | 저자명 (한국어 그대로) |
| 연도 위치 | 저자 바로 뒤 | 참고문헌 번호 순서에 따름 | 발행연도를 문헌 끝에 표기 |
| 본문 인용 형식 | (Kim, 2023) | [1] | (김민수, 2023) |
| 학술지 논문 | 저자. (연도). 제목. *학술지명*, *권*(호), 쪽수. https://doi.org/xxx | 저자, "제목," *학술지명*, vol. 권, no. 호, pp. 쪽수, 연도. | 저자(연도). 제목. 학술지명, 권(호), 쪽수. |
| 단행본 | 저자. (연도). *책 제목*. 출판사. | 저자, *책 제목*. 출판지: 출판사, 연도. | 저자(연도). 책 제목. 출판사. |
| DOI 표기 | https://doi.org/10.xxxx 형식 | DOI 또는 URL 표기 가능 | 국내지 미표기 사례 多 [확인 필요] |
| 한글 저자 복수 | 첫 저자 외 공저자 & 기호 또는 et al. (3인↑) | 3인 이상 *et al.* | 저자1·저자2(2인), 저자1 등(3인↑) |

> 주의: KCI 스타일은 학술지마다 세부 규정이 다릅니다. 투고 전 반드시 해당 학술지 투고 규정을 직접 확인하십시오. [확인 필요]

## 4. AI 활용 시 주의사항

- 서지정보 환각 금지: ChatGPT 등 생성형 AI가 제안한 참고문헌(저자·연도·제목·DOI)은 존재하지 않는 논문을 만들어낼 수 있습니다. 반드시 실제 DB에서 원문을 직접 확인한 후 Zotero에 등록하십시오.
- DOI 환각 위험: AI가 생성한 DOI는 실제로 연결되지 않는 경우가 많습니다. [doi.org](https://doi.org) 에서 유효성을 확인하십시오.
- AI는 Zotero 라이브러리 검색, 인용 스타일 선택, 참고문헌 목록 서식 정리 보조에는 활용할 수 있습니다.
- 최종 참고문헌 목록의 정확성은 연구자가 책임집니다.
