# 다운로드 템플릿

> 워크북의 표를 스프레드시트(Excel·Google Sheets)에서 바로 쓸 수 있도록 만든 CSV 템플릿입니다. 파일을 내려받아 첫 행(헤더)은 두고 아래에 본인 내용을 채우세요.

| 파일 | 용도 | 연결 |
|---|---|---|
| [`문헌비교표.csv`](문헌비교표.csv) | 논문 8칸 분석·여러 편 비교 | [W-2](../workbook/W2_문헌수집과참고문헌관리.md) · [P-4](../prompts/P04_문헌분석.md) |
| [`변수표.csv`](변수표.csv) | 변수 역할·측정·척도 정리 | [W-5](../workbook/W5_데이터수집과분석자동화.md) · [P-8](../prompts/P08_데이터설계.md) |
| [`참고문헌점검표.csv`](참고문헌점검표.csv) | 인용 오류·DOI·실존 확인 | [W-2](../workbook/W2_문헌수집과참고문헌관리.md) · [P-5](../prompts/P05_인용관리.md) |
| [`정부과제추적표.csv`](정부과제추적표.csv) | 공고·마감·서류 추적 | [W-8](../workbook/W8_연구성과사업화전략.md) · [부록 D](../appendix/D_정부과제캘린더.md) |

> CSV는 UTF-8 인코딩입니다. Excel에서 한글이 깨지면 "데이터 → 텍스트/CSV 가져오기"로 UTF-8을 지정해 여세요.
